## Protocol

- Compilation: C `clang -O2 -ffp-contract=off -lm bench/<SOURCE>/c/<name>.c`; YIAN `yianc -O2 lib/src <src>`, with `--raw-pointers` added in raw mode.
- Scale and argv: see `scale` in each benchmark's `specs/<name>.json`; argv only covers the C outer repetition count, consistent with `scale`; the fast profile generates a reduced-scale build copy for benchmarks that declare `scale.fast`, and passes the same value to the C reference as argv, keeping the three states' workloads equal.
- Measurement: after one warmup per state per benchmark (excluded from samples), measure in **round-robin** order C->raw->fat; formal metrics use each state's minimum and record median/IQR/CV/peak RSS.
- Noise reduction: `taskset -c none`; round-robin measurement reduces drift across time; all three artifacts use the same directory and equal-length paths (argv[0] length affects process layout for allocation-heavy benchmarks).
- Semantic guard: C warmup must pass the spec's authoritative check (see `check` in `specs/<name>.json`); raw and fat stdout/exit codes must match byte for byte. A `no` in the report makes that benchmark's ratios unusable.
