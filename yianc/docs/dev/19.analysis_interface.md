# 19 分析接口

CLI 的 `main` 和 LSP 分析入口在收集源码前分别创建本次编译的 `NameInterner`。前端和语义分析共用它。前端成功后，入口持有 `UnitTable` 和包图，并创建 `TypeStore`、`SymbolStore` 和 `HirStore`。`TargetLayout.new(types, ...)` 与 `MiddleEndDriver` 借用同一张类型表，布局类型库通过 `AnalysisOptions.sizes` 提供给语义检查。`MiddleEndDriver.new(units, packages, names, types, symbols, hir, trust, raw_pointers, options, reporter)` 借用共享表和报告器，拥有 `SourceTrust`、源码权限表及定义、worklist、impl 注册表。`run()` 先设置单次运行标志，再分类源权限并在 `analysis.restricted` 前执行 `analysis.classify_sources`。驱动没有多阶段会话状态；第二次调用直接 panic。编译内 ID 只在对应共享表存活期间有效；诊断需要越过源码表生命周期时，调用者复制消息、路径和范围。

`AnalysisOptions` 控制入口检查、HIR 验证和目标布局查询，由驱动在构造时按值保存。选项中的布局尺寸服务和跟踪器引用在分析期间保持有效。`MiddleEndDriver.run()` 在本次同步分析期间借用 `DiagnosticReporter`，warning 在被发现时立即报告；任何用户错误都会立即终止后续 pass 并返回 `Err(error)`。`Ok(output)` 表示分析成功并返回 `AnalysisOutput`；驱动始终只借用共享表。输出拥有 checked/procedure 列表，其中的 `DefId`、`TypeId`、`SymbolId`、`HirId` 和 `UnitId` 依赖调用方继续持有相应的类型、符号、HIR 与单元表。CLI 由进程退出回收入口资源。显式清理时，调用方先释放输出和后端，再释放这些表；布局先于类型表释放。失败时中端清理未完成输出，调用方仍在单元表存活期间报告错误。

`yianc/src/main.an` 的 CLI 报告器在回调内立即渲染并写 stderr，不区分 `--check` 与普通编译。`lsp/src/analysis/compiler.an::analyze` 独立持有 LSP 报告器：分析成功时把警告交给 `CompilerAnalysis`，分析失败时先借仍然有效的单元表复制错误诊断，再在返回过程中释放已收集的警告。

## 命令行与编辑器

`yianc --check` 从磁盘输入运行前端和语义检查，输出文本诊断；检查使用 `TargetLayout` 按真实 LLVM 布局求编译期 `sizeof`，但不构造 `BackendDriver`、CFG 或发布路径。LSP 使用 `lsp/src/analysis/compiler.an` 用同一驻留表把编辑器文档构造成 `SourceFile` 后通过 `SourceTable.from_files` 一次性装入文件表，交给 `FrontendDriver.new`；`run()` 返回 `UnitTable` 后创建独立 `TypeStore`、符号/HIR 表和 `TargetLayout`，再运行严格语义分析。成功时复制按 `UnitId` 排列的 stdlib 标志并释放驱动和布局，然后由 `CompilerAnalysis` 接管单元表、包图、共享语义表、输出、分类位与稳定地址类型表；释放时先释放输出和其引用的表，最后释放类型表。失败时在单元表仍有效时复制诊断，随后清理已创建的驱动、布局和共享表。

LSP 接收 UTF-16 代码单元列坐标，使用标准库的 `LineIndex` 转换至编译器源码坐标。诊断在编译器分析数据释放前转换为 `LspDiagnostic`，由快照持有消息、路径和范围；发布时从同版本快照文本计算 UTF-16 范围，严重级别由诊断码推导。`SourceIndex.build(units: UnitTable&, packages: Option<PackageMap&>, names: NameInterner&, stdlib: Vec<bool>&, std_root: str)` 按 `UnitId` 顺序读取源码和分类位；源码索引重新词法分析和解析时借用 `CompilerAnalysis` 的驻留表。语义索引和查询快照在 `CompilerAnalysis` 有效期间读取编译记录。查询快照返回后，编译分析及临时索引均释放。文档覆盖层、调度、协议和快照范围见[语言服务器](../../../docs/manual/27.language_server.md)。包模式的源码归属与可见性见[依赖图与包图](../../../docs/manual/23.anx_graph.md)。
