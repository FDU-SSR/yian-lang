## 标准库参与编译

`lib/src/` 下的 `.an` 文件与用户源文件一同经历完整的编译管线：lex → parse → desugar → resolve → type_check。它们不是预编译的，而是每次编译时作为普通源文件处理。

## Vec 的存储

`std.core.vec` 内部用私有的非泛型 `RawVec` 保存字节指针、元素容量和元素长度。`Vec<T>` 按目标布局传入元素步长，共用分配、扩缩容和批量搬移。读取和写入元素时恢复 `T*`，元素 trait 仍按 `T` 分派。零大小元素只有逻辑长度，跳过缓冲区的分配与复制。

非重叠的批量复制使用 `@memcpy`，插入和删除的重叠移动使用模块内的 libc `memmove` 包装。胖指针模式下，包装在交出两个地址前校验精确字节视图的跨度与活性。填充未初始化槽位使用公开的 `spare()` 和 `advance_len()`。

## Arena 的存储

`Arena<T>` 的私有非泛型 `RawArena` 持有块根目录、元素总数和每块槽数。每块最多 256 个槽，按目标布局将块的字节数控制在 16 KiB 以内，单个元素超过该大小时独占一块。目录扩容只移动块根指针。索引通过整除和余数定位，读写由类型化门面完成。零大小元素使用同一逻辑分块，目录槽存占位指针。

`clear()` 逐块释放非零大小元素的存储，再释放目录并重置总数。块及目录由 Arena 独占，调用者负责元素资源的清理。

## HashMap 和 HashSet 的存储

私有非泛型 `RawTable` 持有分开的控制区和桶字节存储，以及容量和计数。`HashMap<K, V>` 以目标布局的桶步长共用分配、控制字节初始化、搬移、克隆和释放。哈希、相等比较及键值访问在类型化门面执行。扩表按旧桶索引重哈希，按步长复制各个占用桶，最后释放旧控制区及已分配的桶存储。

整个桶的大小为零时，控制区仍记录逻辑占用，桶根指针使用占位值。`HashMap<K, V>` 的描述符含两个根指针，`HashSet<T>` 内嵌对应的 `HashMap<T, void>`。桶大小由目标布局决定，描述符大小与桶大小无关。

## std 命名空间

`from std.xxx.yyy import ZZZ` 解析到标准库源码根（`lib/src`）下的 `xxx/yyy.an`。
`yianc` 使用输入文件的规范路径及配置的标准库源码根确定其在 `std` 下的模块名。
独立编译时，通过源文件参数显式加入标准库源码；包模式由标准库包的 `sourceRoot` 指定源码根。

## Prelude 自动注入

`yianc/src/analysis/resolution/imports.an` 对非 `lib/src/` 源文件自动注入以下符号。

```text
Option, Result, Vec, String, Range, Ordering, Clone, Ptr, Slice, Array, Never, Drop, exit
```

native 编译器对非标准库模块显式导入这些符号给出 `W502` 警告；警告不阻止编译：

```text
warning[W502]: unnecessary import of 'Option': the prelude already provides it
--> src/main.an:1:29
    from std.core.option import Option;
                                ^^^^^^
```

使用别名（例如 `Vec as MyVec`）会建立不同的绑定，不产生该警告；标准库 `lib/src/` 内部不受此规则影响。

## Intrinsic Types

`yianc/src/analysis/resolution/context.an::ResolutionContext.intrinsic` 按名称查询标准库符号表中的内建类型，并通过 `SourcePermissions.is_stdlib` 确认其来源。
标准库 trait 由源码声明和类型解析登记。
