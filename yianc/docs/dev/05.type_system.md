# 05 类型系统

原生类型模型在 `yianc/src/analysis/ty/model.an`，类型存储在同目录的 `store.an`。分析使用会话内的 `TypeId` 引用类型记录。

## 类型身份

`TypeStore` 对指针、引用、数组、元组和函数指针等结构类型按结构驻留。名义类型通过 `DefId` 和类型实参区分；声明和补全是独立步骤，需要完整字段或变体的数据布局查询使用已补全的定义。

`TypeData` 保存类型构造信息，`DefinitionBody` 保存结构、枚举、trait 或 callable 的定义体。类型关系、属性和可调用签名分别由 `relations.an`、`properties.an` 和 `callable.an` 处理。

## 泛型与目标布局

参数匹配与实参替换使用 `analysis/lowering/conversion.an` 和 `analysis/ty/substitution.an`。类型与 impl 声明完成后，具体过程由中端工作列表检查。对象布局由所选后端目标提供，语义层保存类型身份并在需要即时求值时查询布局。
