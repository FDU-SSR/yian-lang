# 05 类型系统

共享类型模型位于 `yianc/src/types/`：`model.an` 定义类型数据，`space.an` 提供结构驻留的 `TypeSpace`，`key.an` 定义驻留键。分析使用 `TypeId` 引用类型记录。`types/` 不依赖 `analysis/` 或 `codegen/`。

## 类型身份

`TypeSpace` 对指针、引用、数组、元组和函数指针等结构类型按结构驻留。名义类型通过 `DefId` 和类型实参区分；声明和补全是独立步骤，需要完整字段或变体的数据布局查询使用已补全的定义。`TypeSpace` 不保存解析上下文、会话、HIR 或 LLVM 状态。

`TypeData` 保存类型构造信息，`DefinitionBody` 保存结构、枚举、trait 或 callable 的定义体。结构查询在 `types/queries.an`，替换在 `types/substitution.an`，纯属性查询在 `types/properties.an`，显示在 `types/display.an`；类型关系、impl 登记、调用签名调度和声明校验属于中端 `yianc/src/analysis/ty/`。

## 泛型与目标布局

参数匹配与实参替换使用 `analysis/lowering/conversion.an` 和 `types/substitution.an`。类型与 impl 声明完成后，具体过程由中端工作列表检查。对象布局由所选后端目标提供：`types/layout.an` 定义 `TypeSizeProvider`，语义层保存类型身份并在需要即时求值时查询布局。
