# 17 Impl 注册与查找

`yianc/src/analysis/ty/impl_registry.an` 保存本次分析会话的 impl 记录。记录包括目标类型、可选的 trait、泛型条件和方法。注册返回会话内的 `ImplId`，`for_target` 提供目标类型的候选集合。

`analysis/resolution/methods.an` 解析并登记 impl。`analysis/ty/impl_check.an` 验证 trait 实现所需的方法及其签名。`analysis/ty/method_lookup.an` 将目标与适用的 impl 匹配，检查泛型条件并解析方法。

无载荷枚举的同类型 `PartialEq` 由 `analysis/resolution/automatic.an` 提供，显式同类型实现优先。普通方法调用与运算符所需的 trait 约束使用同一分析会话的 impl 数据。
