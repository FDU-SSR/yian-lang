# 07 调用 Lowering

`yianc/src/analysis/lowering/calls.an` 处理函数、可调用值和名义类型构造。检查器取得签名，按形参匹配与转换实参，并生成 `Call`、`Invoke` 或对应的聚合构造 HIR。

`methods.an` 处理方法调用。候选查询由 `analysis/ty/method_lookup.an` 完成，结合接收者类型、trait 约束和实参推断选择具体方法。自动解引用与接收者适配属于该调用路径。trait object 的动态调用保留专用 HIR。

对可解析的具体过程，语义检查会登记需要检查的实例。HIR 保存调用所需的类型与源码位置，后续 CFG 下降使用已经解析的目标和调用约定。
