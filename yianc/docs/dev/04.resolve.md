# 04 全局符号解析

`yianc/src/analysis/driver.an` 调度跨文件解析。首先收集类型与值声明，随后解析导入、名义类型定义和 impl，注册允许的自动实现。相关实现位于 `yianc/src/analysis/resolution/`。

## Import 解析

`imports.an` 在包模式下根据包图与源码归属验证包可见性、目标模块和符号导出。独立模式从编译输入和标准库根解析模块。标准库根及包图的契约见[依赖图与包图](../../../docs/manual/23.anx_graph.md)。

## 作用域与类型

`ResolutionContext` 使用分析会话中的模块和符号记录，`definitions.an` 补全名义类型定义，`methods.an` 解析 impl 目标、方法及其类型条件。符号和类型 ID 的作用域是当前分析会话。

## Prelude

`imports.an` 向标准库以外的模块注入 [prelude](../../../docs/grammar/13.modules.md)。重复显式导入 prelude 符号可产生 `W502`，别名导入保留自己的绑定名称。
