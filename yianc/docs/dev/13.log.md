# 13 日志系统

`yianc/src/telemetry/trace.an` 中的 `CompilerTrace` 协调日志和计时。`telemetry/log.an` 的 `CompilerLog` 拥有日志规则与文件，`telemetry/timing.an` 的 `CompilerTiming` 拥有计时记录。`event(channel, severity, message, path)` 使用 `LogLevel` 枚举。

`CompilerTrace.new(config) -> Self` 按编译器配置初始化；过滤条件或日志文件配置失败时，`CompilerTrace.new` 以 `E602` 报告 `LogConfigError` 并以进程状态 1 退出，不向 `main` 返回错误值。`CompilerTrace.disabled()` 构造禁用实例，调用其观察方法时没有日志、计时或报告输出。计时阶段按标识与活动栈配对；重复活动标识、结束顺序不匹配和空栈结束会记录统计错误，不改变编译结果。profile 报告写出失败时 `finalize` 返回 `ProfileWarning`（`W601`），由 `main` 作为非致命警告输出。

`Off` 禁用输出，`Error`、`Warn`、`Info`、`Debug`、`Trace` 依次扩大允许输出的日志范围，默认阈值为 `Warn`。配置与日志输出使用对应的大写级别名称。

频道按规则顺序匹配。规则匹配完整频道或其以点分隔的子频道，`all` 匹配所有频道。事件带路径时，可用 `@filter` 按路径筛选。通过筛选的消息写入 stderr 和打开的日志文件。

日志和计时默认关闭，分别由 `--log` 和 `--profile` 启用。启用日志时，编译模式的默认文件是 `build/compile.log`。`--log-file` 指定主要日志文件，`YIAN_LOG_FILE` 可指定额外文件。计时阶段使用相同的 trace，启用计时时由记录器保存阶段和子项。配置命令见[编译器命令行指南](../compile_script.md)。
