# 09 类型检查

`yianc/src/analysis/passes/type_check.an::check_procedures` 驱动过程检查。它检查根包或独立输入的过程，并按需检查发现的具体实例。供代码生成选择的过程集合由分析结果单独记录。

每个具体过程通过 `ExprChecker` 将表达式和模式下降为 HIR。检查器在该阶段处理编译期分支的选择、参数与返回值的类型约束、调用实例化与绑定。解析和验证所需的类型、符号及 HIR 信息来自 `MiddleEndDriver` 借用的共享表和 `ResolutionContext`。

地址存储规范化、HIR 验证、模式覆盖检查和确定赋值检查在中端随后的 pass 执行。类型、覆盖和赋值错误沿 `AnalysisError` 返回；`MiddleEndDriver` 收到第一个错误后立即终止后续 pass。warning 在被发现时通过 `ResolutionContext` 同步报告给调用者的 `DiagnosticReporter`。`--check` 与普通编译执行相同的中端检查，只是不构造后端。
