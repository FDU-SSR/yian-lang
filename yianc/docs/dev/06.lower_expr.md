# 06 表达式 Lowering

`yianc/src/analysis/lowering/` 将 AST 表达式检查并下降为带类型、源码范围及 place 信息的 HIR。

| 模块 | 职责 |
| --- | --- |
| `checker.an`、`expression.an` | 表达式检查上下文、分派与 HIR 构造 |
| `conversion.an` | 类型匹配与允许的隐式转换 |
| `operations.an`、`operators.an` | 运算、赋值及对应的 trait 操作 |
| `control_flow.an`、`patterns.an` | 控制流、分支结果和模式绑定 |
| `calls.an`、`methods.an` | 函数、方法及可调用值，见[调用 Lowering](07.lower_call.md) |
| `format.an` | 格式化模板的 HIR 构造 |

赋值检查目标是否为可写 place，并按目标类型检查或转换来源值。编译期分支只下降选中的分支。取地址所需的存储由 HIR 地址存储规范化补齐，再进入 HIR 验证和 CFG 下降。
