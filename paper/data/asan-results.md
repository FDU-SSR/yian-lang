# build/bench/asan-results.md — ASan 交叉对比实测 (asan-cross-compare)
## 0) 环境与协议
- 日期: 2026-08-24
- 机器: x86_64 / x86_64 / 16 逻辑核
- Python: 3.13.2 | clang: /usr/bin/clang
  `Ubuntu clang version 18.1.3 (1ubuntu1)`
  `rustc 1.97.1 (8bab26f4f 2026-07-14)`
- 编译命令:
  - C plain: `clang -O2 -lm bench/c/<name>.c`
  - C ASan: `clang -O2 -fsanitize=address -lm bench/c/<name>.c`
  - .an check: `python3 -m compiler.main -O3 lib bench/shootout/<name>.an`
- ASAN_OPTIONS 主表 (C ASan main 腿) 全文: `detect_leaks=0` (其余为 ASan 运行时默认, 含 quarantine_size_mb=256)。
- ASAN_OPTIONS 敏感性行 (C ASan sens 腿, 仅 binarytree) 全文: `detect_leaks=0:quarantine_size_mb=0` (quarantine 失效, 供 RSS 敏感性对照)。
- **-O 不对称声明**: C 腿 `-O2`, .an check 腿 `-O3` (两编译器各自常规优化档; 跨编译器时间/内存差异不可单纯归因于安全机制)。
- 绑核策略: `taskset -c 4` 绑定单核。
- 规模对齐声明: `bench/c/` 14 个 C 基准与 `bench/shootout/` 同规模 (9 个对齐: bounce/fann/mand/nbody/permute/queen/revcomp/sieve/storage; 5 个原一致: binarytree/fasta/list/spectralnorm/towers)。
- 腿序声明: 每基准固定 [C plain → C ASan main → C ASan sensitivity (仅 binarytree) → .an check] 紧邻执行; 同会话紧邻消除跨会话系统状态漂移, 使 4 腿可互相比较。
- 本次运行: 基准 `binarytree, bounce, fann, fasta, list, mand, nbody, permute, queen, revcomp, sieve, spectralnorm, storage, towers`; --runs 5; --pin 4。

## 3) 敏感性行 (binarytree only)
- C ASan main: `ASAN_OPTIONS=detect_leaks=0` (quarantine 默认活跃)
- C ASan sens: `ASAN_OPTIONS=detect_leaks=0:quarantine_size_mb=0` (quarantine 失效)
- binarytree 是唯一 quarantine 活跃基准 (DeleteTree 逐迭代交错建删); sieve 栈数组零 malloc、storage/list 峰值在释放前, quarantine 差异≈0 不可作证明。
