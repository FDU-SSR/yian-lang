# 学期开发计划

本学期 yian 迭代计划

## 底层内存管理模型

完全套用 C 语言的内存管理模型, 主要表现为:

- 赋值行为为**按位拷贝** (bitwise copy), 如需深拷贝, 自行调用方法
  - 函数传参/返回值传递等行为, 视为赋值行为
- 内存的分配和释放由用户自行管理, 编译器不会自动释放内存, 也不会自动调用析构函数

## 开发实用性

### vscode 插件

目前 yian 仅有一个极其粗糙的代码高亮插件, 但是这个插件只能根据语法简单的对代码着色, 无法感知语义, 因此无法提供更高级的功能, 例如: 代码补全, 语法检查, 代码重构等.

计划为 yian 开发一个语言服务器, 以便在 VS Code 等编辑器中提供更高级的功能.

- 更精确的代码高亮
- 代码补全
- 语法检查
- 代码重构
- 代码跳转
- 等等

Language Server 暂定使用 Python 语言开发.

### anx 包管理器

计划为 yian 开发一个包管理器, 以便在 yian 中方便的管理库之间的依赖关系.

- 初始化一个 yian 项目
- 完整定义一个 yian 项目的目录结构
- 理清楚 yian 项目中的依赖关系, 分为
  - 内部依赖: 通过 `import` 语句导入的模块
  - 外部依赖: 通过配置文件描述的外部库
- 能够以项目为单位, 进行编译

anx 包管理器暂定使用 Python 语言开发.
