# 07 模式匹配

## 基本语法

```yian
match expr {
    pattern1 => { body1 },
    pattern2 => { body2 },
}
```

- arm 之间用逗号 `,` 分隔
- `=>` 左侧是 pattern，右侧是 block `{ }`
- match 必须覆盖所有可能情况
- 来源：`lib/core/option.an`、`lib/core/result.an`

## Enum Pattern

匹配枚举变体：

```yian
let opt: Option<i32> = Option<i32>.Some(42);

match opt {
    None => { return 0; },
    Some => { return 1; },
}
```

来源：`tests/std/core/option.an`

## Payload Pattern（解构）

从枚举变体中提取值：

```yian
let opt: Option<i32> = Option<i32>.Some(42);

match opt {
    None => { return 0; },
    Some(val) => {
        return val;     // val: i32
    },
}
```

- `Some(val)` 将 payload 字段绑定到 `val`
- `val` 的类型是 payload 字段的类型
- 来源：`lib/core/option.an:43-48`

多字段变体：

```yian
enum Result<T, E> {
    Ok { val: T },
    Err { msg: E },
}

match res {
    Ok(val) => { /* val: T */ },
    Err(msg) => { /* msg: E */ },
}
```

来源：`lib/core/result.an`、`tests/std/core/result.an`

## 通配符

```yian
match opt {
    Some(val) => { return val; },
    _ => { return 0; },            // 匹配所有剩余情况
}
```

## 模式中的指针

match 绑定的变量是该字段的**指针**：

```yian
// 在 impl Option<T> 中
match self {
    None => { ... },
    Some(val) => {
        // self: Option<T>&，val: *T（指向 payload 字段的地址）
    },
}
```

需要使用 `*val` 解引用。

来源：`lib/core/option.an`

## Match 作为表达式

```yian
let opt: Option<i32> = Option<i32>.Some(42);
let val: i32 = match opt {
    Some(v) => v,
    None => 0,
};
```

每个 arm 必须产生相同类型（或可强制为同一类型）的值。
