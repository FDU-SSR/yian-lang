# 07 模式匹配

## 基本语法

```yian
match expr {
    pattern1 => { body1 },
    pattern2 => { body2 },
}
```

- arm 之间用逗号 `,` 分隔（逗号可省略）
- `=>` 右侧可以是 block `{ }`，也可以是单个表达式
- 支持整数、字符、布尔和字符串字面量、范围、枚举和结构体解构、元组、数组和切片序列、绑定、备选项及通配符 `_`；子模式可以嵌套
- 编译器检查穷尽性，缺少覆盖时报编译错误；不可达分支产生 `W501` 警告
- 来源：`lib/src/core/option.an`、`lib/src/core/result.an`

## Enum Pattern

匹配枚举变体：

```yian
let opt: Option<i32> = Option<i32>.Some(42);

match opt {
    None => { return 0; },
    Some => { return 1; },
}
```

来源：`tests/basic/std/core/option.an`

模式可用 `|` 列出多个备选项；match arm 顶层还允许用逗号分隔同种字面量。
备选项必须绑定相同名称，且对应名称的类型和引用模式一致。

```yian
match color {
    Red | Blue => "primary",
    Green => "other",
}
```

整数、字符、布尔和枚举模式使用结构化比较。字符串字面量使用字符串的 `PartialEq`
比较；字符串匹配与带守卫的匹配必须以无守卫的 `_ => ...` 或 `name @ _ => ...` 收尾。
任意自定义类型不能通过 `PartialEq` 自动成为字面量模式。

## Payload Pattern（解构）

从枚举变体中提取值：

```yian
let opt: Option<i32> = Option<i32>.Some(42);

match opt {
    None => { return 0; },
    Some(val) => {
        return val;     // val: i32
    },
}
```

- `Some(val)` 将 payload 字段绑定到 `val`
- `val` 的类型是 payload 字段的类型
- 来源：`lib/src/core/option.an:43-48`

多字段变体：

```yian
enum Result<T, E> {
    Ok { val: T },
    Err { msg: E },
}

match res {
    Ok(val) => { /* val: T */ },
    Err(msg) => { /* msg: E */ },
}
```

来源：`lib/src/core/result.an`、`tests/basic/std/core/result.an`

## 通配符

```yian
match opt {
    Some(val) => { return val; },
    _ => { return 0; },            // Match all remaining cases.
}
```

## 引用匹配

通过引用匹配聚合值时，字段绑定使用该字段的**引用**。直接写 `match &value` 会转换为引用匹配；
已有的指针变量不能直接作为匹配对象，需解引用或转换为引用：

```yian
// Inside impl Option<T>.
match self {
    None => { ... },
    Some(val) => {
        // self:Option<T>&,val:T&, referencing the payload field.
    },
}
```

需要使用 `*val` 解引用。

来源：`lib/src/core/option.an`

## Match 作为表达式

```yian
let opt: Option<i32> = Option<i32>.Some(42);
let val: i32 = match opt {
    Some(v) => v,
    None => 0,
};
```

每个 arm 必须产生相同类型（或可强制为同一类型）的值。

## 结构化模式

以下是模式片段，右侧名称在匹配成功的分支内可用：

```yian
0..10                        // Integer range includes zero, excludes ten.
'a'..'z'                     // Character range includes 'a', excludes 'z'.
value @ Some(inner)          // Bind both the whole value and subpattern.
Option<i32>.Some(value)      // Type-qualified enum variant.
Point(x = left, y = right)   // Struct with named fields.
Point(x = left, ..)          // Ignore remaining fields.
(first, second)             // Tuple with the same element count.
[first, .., last]            // Sequence prefix/suffix pattern.
```

枚举 payload 可按声明顺序解构，也可写命名字段；命名字段模式必须列全字段或使用
`..`。字段访问权限同样适用于解构。序列中的 `..` 最多出现一次，不绑定中间片段；
没有 `..` 时要求长度完全一致，有 `..` 时要求至少容纳前缀和后缀。

match 的枚举根模式中，裸名称表示变体；子模式和普通绑定上下文中的裸名称表示变量。
嵌套枚举测试使用带括号的构造模式或限定变体名称，整体绑定使用 `name @ pattern`。

## 守卫

```yian
match option {
    Some(value) if value > 0 => value,
    _ => 0,
}
```

守卫必须为布尔表达式，只在模式匹配成功后求值，可读取该模式绑定的变量。守卫失败时
继续尝试下一个 arm；带守卫的 arm 不构成无条件覆盖。

## 绑定与条件模式

模式也用于 `let`、函数参数、`for` 元素和条件控制流：

```yian
let (left, right) = pair;
let Some(value) = option else { return; };
if let Some(value) = option { consume(value); }
while let Some(value) = iterator.next() { consume(value); }
for (index, value) in items { consume(value); }
fn first((left, right): (i32, i32)) -> i32 { left }
```

这些是上下文片段。普通解构 `let`、函数参数和 `for` 元素要求模式不可失败。
可失败的 `let` 必须提供不返回当前控制流的 `else` 块；绑定名称仅在匹配成功后可用。
`if let`、`elif let` 和 `while let` 允许可失败模式；不可能匹配或始终匹配的条件产生警告。
无条件成功的 `let ... else` 也会产生不可达 else 警告。模式检查在编译期分支选择之后执行。
