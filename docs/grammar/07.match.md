# 07 模式匹配

## 基本语法

```yian
match expr {
    pattern1 => { body1 },
    pattern2 => { body2 },
}
```

- arm 之间用逗号 `,` 分隔（逗号可省略）
- `=>` 右侧可以是 block `{ }`，也可以是单个表达式
- 支持整数、字符、字符串、枚举变体、payload 绑定和通配符 `_`；不支持嵌套或范围模式
- 编译器不检查穷尽性；未匹配输入不会自动进入兜底分支，使用 `_` 明确覆盖其余情况
- 来源：`lib/src/core/option.an`、`lib/src/core/result.an`

## Enum Pattern

匹配枚举变体：

```yian
let opt: Option<i32> = Option<i32>.Some(42);

match opt {
    None => { return 0; },
    Some => { return 1; },
}
```

来源：`tests/basic/std/core/option.an`

枚举变体可用 `|` 列出多个备选项；整数、字符和字符串模式可用逗号分隔多个字面量。
布尔字面量不是模式，枚举 payload 只支持按声明顺序绑定字段，不支持嵌套模式。

```yian
match color {
    Red | Blue => "primary",
    Green => "other",
}
```

整数、字符、枚举以及指向或引用这些类型的值直接按字面量或枚举判别值分派。其他受支持的
匹配路径使用 `PartialEq` 比较各个模式；该路径要求 scrutinee 与模式值可比较，且不支持
payload 绑定。通配符不需要 `PartialEq`。

## Payload Pattern（解构）

从枚举变体中提取值：

```yian
let opt: Option<i32> = Option<i32>.Some(42);

match opt {
    None => { return 0; },
    Some(val) => {
        return val;     // val: i32
    },
}
```

- `Some(val)` 将 payload 字段绑定到 `val`
- `val` 的类型是 payload 字段的类型
- 来源：`lib/src/core/option.an:43-48`

多字段变体：

```yian
enum Result<T, E> {
    Ok { val: T },
    Err { msg: E },
}

match res {
    Ok(val) => { /* val: T */ },
    Err(msg) => { /* msg: E */ },
}
```

来源：`lib/src/core/result.an`、`tests/basic/std/core/result.an`

## 通配符

```yian
match opt {
    Some(val) => { return val; },
    _ => { return 0; },            // 匹配所有剩余情况
}
```

## 模式中的指针

通过引用或指针匹配时，绑定的变量是该字段的**指针**：

```yian
// 在 impl Option<T> 中
match self {
    None => { ... },
    Some(val) => {
        // self: Option<T>&，val: *T（指向 payload 字段的地址）
    },
}
```

需要使用 `*val` 解引用。

来源：`lib/src/core/option.an`

## Match 作为表达式

```yian
let opt: Option<i32> = Option<i32>.Some(42);
let val: i32 = match opt {
    Some(v) => v,
    None => 0,
};
```

每个 arm 必须产生相同类型（或可强制为同一类型）的值。
