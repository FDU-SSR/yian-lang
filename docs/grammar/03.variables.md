# 03 变量与声明

## `let` 声明

Yian 使用 `let` 关键字声明变量：

```yian
let x: i32 = 42;            // Full form: type annotation and initialization.
let y = 42;                 // Type inference; source: tests/basic/let/inference.an.
let z: i32;                 // Declaration without initialization; source: tests/basic/let/no_init.an.
```

仅声明不初始化的 `let` 必须标注类型

```yian
let z;                 // -- Expected: compilation error.
```

来源：`tests/basic/let/no_annotation_no_init.err.an`

## 类型推断

如果初始化表达式能唯一确定类型，可以省略类型标注：

```yian
let a = 42;                 // a:i32, inferred as i32.
let b = 3.14;               // b: f64
let c = true;               // c: bool
let s = "hello";            // s: str
let v = Vec<i32>.new();     // v: Vec<i32>
```

来源：`tests/basic/let/inference.an`

## 模块级常量

常量声明位于模块级，必须显式标注标量类型，可用 `pub` 导出：

```yian
const CAPACITY: u64 = 16u64 * 4u64;
pub const ENABLED: bool = true;
```

支持整数、浮点、布尔、字符、字符串及其类型别名。初始化表达式在编译期求值，
不能依赖运行期变量、普通函数调用或副作用。常量支持前向引用和模块导入，循环依赖
报错；使用点替换为常量值，不生成常量的运行期存储。

## 解构声明

`let` 可以绑定元组、结构体、枚举和序列模式。可能失败的模式需要带有终止当前路径的
`else` 块；具体语法和检查规则见[模式匹配](07.match.md#绑定与条件模式)。

## 变量遮蔽

内层作用域可以声明同名变量，遮蔽外层：

```yian
let x: i32 = 1;
if true {
    let x: i32 = 2;         // Shadow outer x.
    assert x == 2;
}
assert x == 1;
```

## 变量是左值

变量是 place expression（`is_place = true`），可以出现在赋值左侧：

```yian
let x: i32 = 10;
x = 20;                     // OK: x is a place.
```

## 变量与复制语义

变量赋值是**按位复制**（bitwise copy），不存在所有权转移，也无需显式复制调用：

```yian
let v1: Vec<i32> = Vec<i32>.new();
v1.push(42);
let v2: Vec<i32> = v1;      // Direct shallow copy; v1 remains usable.
```

需要独立缓冲区时调用标准库的 `Clone`（如 `Vec::clone`）。详见 [§02 类型系统](02.type_system.md) 的赋值与拷贝语义。
