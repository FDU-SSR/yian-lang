# 03 变量与声明

## `let` 声明

Yian 使用 `let` 关键字声明变量：

```yian
let x: i32 = 42;            // 完整形式：类型标注 + 初始化
let y = 42;                 // 类型推断 — 来源: tests/let/inference.an
let z: i32;                 // 仅声明不初始化 — 来源: tests/let/no_init.an
```

仅声明不初始化的 `let` 必须标注类型

```yian
let z;                 // -- 期望: 编译错误
```

来源：`tests/let/no_annotation_no_init.err.an`

## 类型推断

如果初始化表达式能唯一确定类型，可以省略类型标注：

```yian
let a = 42;                 // a: i32（推断为 i32）
let b = 3.14;               // b: f64
let c = true;               // c: bool
let s = "hello";            // s: str
let v = Vec<i32>.new();     // v: Vec<i32>
```

来源：`tests/let/inference.an`

## 变量遮蔽

内层作用域可以声明同名变量，遮蔽外层：

```yian
let x: i32 = 1;
if true {
    let x: i32 = 2;         // 遮蔽外层 x
    assert x == 2;
}
assert x == 1;
```

## 变量是左值

变量是 place expression（`is_place = true`），可以出现在赋值左侧：

```yian
let x: i32 = 10;
x = 20;                     // OK: x 是 place
```

## 变量与复制语义

变量赋值是**按位复制**（bitwise copy），不存在所有权转移，也无需显式复制调用：

```yian
let v1: Vec<i32> = Vec<i32>.new();
v1.push(42);
let v2: Vec<i32> = v1;      // 直接按位复制，v1 仍可用
```

需要独立副本时使用标准库的显式深拷贝方法（如 `Vec::to_vec`）。详见 [§02 类型系统](02.type_system.md) 的赋值与拷贝语义。
