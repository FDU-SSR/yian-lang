# 03 变量与声明

## `let` 声明

Yian 使用 `let` 关键字声明变量：

```yian
let x: i32 = 42;            // 完整形式：类型标注 + 初始化
let y = 42;                 // 类型推断 — 来源: tests/let/inference.an
let z: i32;                 // 错误: 缺少初始化表达式
```

变量必须初始化。仅声明不初始化的 `let` 会触发编译错误：

```yian
let z: i32;                 // -- 期望: 编译错误
```

来源：`tests/let/no_annotation_no_init.err.an`

## 类型推断

如果初始化表达式能唯一确定类型，可以省略类型标注：

```yian
let a = 42;                 // a: i32（推断为 i32）
let b = 3.14;               // b: f64
let c = true;               // c: bool
let s = "hello";            // s: str

let v: Vec<i32> = Vec<i32>.new();
// 类型标注不可省略 — new() 返回泛型 Self，无法推断 T
```

来源：`tests/let/inference.an`

## 变量遮蔽

内层作用域可以声明同名变量，遮蔽外层：

```yian
let x: i32 = 1;
if true {
    let x: i32 = 2;         // 遮蔽外层 x
    assert x == 2;
}
assert x == 1;
```

## 变量是左值

变量是 place expression（`is_place = true`），可以出现在赋值左侧：

```yian
let x: i32 = 10;
x = 20;                     // OK: x 是 place
```

## 变量与 move 语义

非简单类型的变量赋值会触发 move 语义：

```yian
let v1: Vec<i32> = Vec<i32>.new();
v1.push(42);
let v2: Vec<i32> = v1.move();   // v1 所有权转移
// v1 不再可用 — 来源: tests/assign/move_clone.an
```

简单类型（`i32` 等）的 `move()`/`clone()` 是恒等操作，编译器直接优化为 no-op。详见 [§15 赋值语义](15.assign_semantics.md)。
