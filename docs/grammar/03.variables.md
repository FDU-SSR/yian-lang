# 03 变量与声明

## `let` 声明

Yian 使用 `let` 关键字声明变量：

```yian
let x: i32 = 42;            // Full form: type annotation and initialization.
let y = 42;                 // Type inference; source: tests/basic/let/inference.an.
let z: i32;                 // Declaration without initialization; source: tests/basic/let/inference.an.
```

仅声明不初始化的 `let` 必须标注类型

```yian
let z;                 // -- Expected: compilation error.
```

来源：`tests/basic/let/no_annotation_no_init.err.an`

## 类型推断

如果初始化表达式能唯一确定类型，可以省略类型标注：

```yian
let a = 42;                 // a:i32, inferred as i32.
let b = 3.14;               // b: f64
let c = true;               // c: bool
let s = "hello";            // s: str
let v = Vec<i32>.new();     // v: Vec<i32>
```

来源：`tests/basic/let/inference.an`

## 模块级常量

常量声明位于模块级，必须显式标注类型，可用 `pub` 导出：

```yian
const CAPACITY: u64 = 16 * 4;
pub const ENABLED: bool = true;
const BYTES: u8[3] = [0, 128, 255];
const MATRIX: i32[2][2] = [[1, 2], [3, 4]];
const SEVENS: u8[2] = [7; 2];
const EMPTY: u8[0] = [0; 0];
const N: u64 = BYTES[2];
```

支持整数、浮点、布尔、字符、字符串及其类型别名，并递归支持由这些类型组成的固定
数组。数组常量可用列表、`[value; count]` 重复和嵌套组合；`[]` 仍要求元素类型上下文。
初始化表达式在编译期求值，不能依赖运行期变量、普通函数调用或副作用；重复次数为零
时元素表达式仍须可求值。

常量整数计算逐步检查：未定型中间值必须落在 `[-2^63, 2^64-1]`，已定型运算按目标宽度
检查；溢出、除零、负移位以及越界的整数目标转换都是编译错误，不回绕或截断。常量数组
可用编译期下标提取标量或子数组，越界是用户诊断。类型位置仍通过标量常量中转，例如
`const N: u64 = LENGTHS[0];` 后再写 `u8[N]` 或 `F<N>`。

常量值在使用点复制，声明本身不是可写位置；借用常量或由它衍生的元素、子数组时，按
临时值规则提升为局部存储。常量没有对应的运行期静态对象；直接给常量或元素赋值仍被拒绝。

## 解构声明

`let` 可以绑定元组、结构体、枚举和序列模式。可能失败的模式需要带有终止当前路径的
`else` 块；具体语法和检查规则见[模式匹配](07.match.md#绑定与条件模式)。

## 变量遮蔽

内层作用域可以声明同名变量，遮蔽外层：

```yian
let x: i32 = 1;
if true {
    let x: i32 = 2;         // Shadow outer x.
    assert x == 2;
}
assert x == 1;
```

## 变量是左值

变量是 place expression（`is_place = true`），可以出现在赋值左侧：

```yian
let x: i32 = 10;
x = 20;                     // OK: x is a place.
```

## 变量与复制语义

变量赋值是**按位复制**（bitwise copy），不存在所有权转移，也无需显式复制调用：

```yian
let v1: Vec<i32> = Vec<i32>.new();
v1.push(42);
let v2: Vec<i32> = v1;      // Direct shallow copy; v1 remains usable.
```

需要独立缓冲区时调用标准库的 `Clone`（如 `Vec::clone`）。详见 [§02 类型系统](02.type_system.md) 的赋值与拷贝语义。
