# 01 词法

Yian 的词法规则涵盖标识符、关键字、字面量、注释与运算符。词法分析器在 `python/yianc/frontend/lex/lexer.py` 中实现，采用逐字符扫描。空格、制表符和换行不产生 token，但尖括号的分类依赖前方是否有空白，见本章的空白敏感性说明。

## 标识符

由字母、数字和下划线组成，不能以数字开头，不能是单独的下划线 `_`。

```yian
x  my_var  index2  calculate_growth_left  HashMap  _internal
```

非法：

```yian
_       // Standalone underscore.
2var    // Starts with a digit.
```

来源：`python/yianc/frontend/lex/lexer.py:12-13`（`START_IDENTIFIER` / `IN_IDENTIFIER` 字符集）

## 关键字

以下为保留关键字，不可用作标识符：

```text
fn  struct  enum  trait  impl  typedef  pub  static  const  ffi  extern  opaque  type
comptime  inline  intrinsic
let  return  break  continue  assert
defer
if  elif  else  loop  while  for  in  match  matches
from  import  as  del  typeof
dyn  IS_RAW_MODE
```

基础类型名（`void`、`bool`、`char`、`str`、`i8` 到 `u64`、`f16`/`f32`/`f64`、`int`、`uint`、`float`）、字面量关键字 `true`/`false` 以及单独的下划线 `_` 同样是保留关键字。

`matches` 是中缀模式测试运算符，不能用作标识符。`ArgMatches`、`from_matches` 等更长的标识符不受影响。

来源：`python/yianc/frontend/lex/token.py` KeywordKind 枚举

编译器内置指令使用保留的 `@name` 命名空间；`sizeof`、`bitcast`、`panic`、`assume_init`
等拼写本身是普通标识符。例如：

```yian
let n: u64 = @sizeof(i32);
@panic("unreachable");
```

`@` 后必须跟已知内建名称和调用参数；未知名称或缺少调用括号会在解析阶段报错。
`@bitcast`、`@alloc`、`@memcpy`、`@undef`、`@dangling` 等操作受来源权限限制；
`@ffi_*` 操作只允许在获准的 `ffi fn` 中使用。一般内建操作见 [§08 表达式](08.expressions.md)，
FFI 操作见 [§17 C ABI FFI](17.ffi.md)。
普通代码可以定义与内建指令同名的函数，调用时不带 `@` 即按普通符号解析。

## 字面量

### 整数字面量

```yian
42          // IntLiteral: type inferred from context.
0xFF        // Hexadecimal.
0u64        // Type suffix: u64.
5i32        // Type suffix: i32.
```

- 十进制默认无后缀，类型由上下文确定（`IntLiteralType`）
- 前缀 `0x`、`0o`、`0b` 分别表示十六进制、八进制和二进制
- 后缀 `u8`/`u16`/`u32`/`u64`/`i8`/`i16`/`i32`/`i64`（以及 `int`/`uint`）指定具体类型
- 数字之间可以插入 `_` 作分隔符

来源：`tests/basic/control_flow/for.an`、`tests/basic/std/num/u64.an`

### 浮点字面量

```yian
3.14
0.0
1.5
```

后缀 `f16`/`f32`/`f64`（以及 `float`）指定具体类型，无后缀时由上下文推断。十六进制浮点字面量（如 `0x1.8p1`）也可使用。

来源：`tests/basic/std/num/f64.an`、`tests/basic/literal/`

### 字符字面量

```yian
'A'
'\n'
'中'
```

单引号包围。`char` 是 4 字节 Unicode 码点（`u32` 宽度）。支持转义 `\n`、`\t`、`\r`、`\0`、`\\`、`\'`、`\"`，以及 `\xNN` 十六进制转义和 `\u{...}`/`\U{...}` Unicode 转义。

来源：`tests/basic/literal/`

### 字符串字面量

```yian
"Hello, World!"
""
```

双引号包围。类型为 `str`（不可变 UTF-8 字符串切片）。转义序列与字符字面量相同。

来源：`tests/basic/std/core/str.an`

### f-string

```yian
let name: str = "Yian";
let msg = f"Welcome to {name} v{1}!";
```

`f"..."` 的结果是 `String`。模板按源码顺序处理：每个 `{expr}` 或 `{expr:spec}` 在该位置求值一次并通过 `Format` 写入唯一结果目标，左侧文本先写入，失败后不再求值后续位置。`\{` 和 `\}` 产生字面量花括号，其余转义序列与普通字符串相同。被插入的表达式必须实现 `Format`；插值不会自动解引用指针或引用，`T*` 和 `T&` 都需要显式 `*`。普通字符串字面量中的花括号不解释。

可选的规格在选择表示形式的同时保留 `Format` 的单一写入通路：

```text
field     := "{" expression [ ":" spec ] "}"
spec      := [ alignment ] [ "0" ] [ count ] [ "." count ] [ "f" ]
alignment := "<" | ">"
count     := decimal_digits | "{" expression "}"
```

- 空规格（`{x:}`）与不写规格等价；非空规格只接受 `i8`/`i16`/`i32`/`i64`、`u8`/`u16`/`u32`/`u64`、`f16`/`f32`/`f64`、`char`、`str` 和标准 `String`。`bool`、容器、自定义 `Format` 类型、指针和引用拒绝非空规格。
- `width` 是包含符号、小数点和内容的**最小**宽度，过长不截断；`0`..`65535`。`precision` 只与 `f` 搭配，`0`..`1024`；单独的 `f` 使用六位小数。
- 文本默认左对齐、按 Unicode 标量计宽，数字默认右对齐；`<`、`>` 显式选择方向。`0` 只用于数字补零，`<` 与 `0` 不能组合，负号在补零之前。
- 数字 `count` 之外只允许 ASCII 标记与十进制数字：不接受符号、下划线、类型后缀、空白或其他填充字符。动态 `count` 的花括号内部使用普通表达式规则。
- 字面量 `count` 超界是编译错误；动态 `count` 在运行期按原值范围校验，负的或超界的有符号/无符号参数返回 `IoErrorKind.InvalidInput`，不先转成无符号数。
- 每个字段依次求值：值一次，然后宽度并立即校验，然后精度并立即校验，最后格式化并写出；任一步失败都不写当前字段，前缀保留，后续位置不再求值。
- `f16`/`f32` 的定点输出先无损扩宽到 `f64`；不使用十进制乘倍率，`NaN`、`inf`、`-inf` 保持原拼写并以空格填充，负有限值即使舍入为零仍保留负号。

来源：`tests/basic/fmt/fstring_basic.an`（`case_format_specs`、`case_parameter_order`、`case_fstring_basic`、`case_fstring_escaped_braces`）、`tests/basic/fmt/ordered.an`

### 字节字面量

```yian
b'A'        // u8 value 65.
b'\n'       // u8 value 10.
```

`b` 前缀后跟单字符或转义序列，类型为 `u8`。

来源：`tests/basic/std/core/string.an`

### 布尔字面量

```yian
true
false
```

类型为 `bool`。

YIAN 没有空指针字面量。需要表达可选指针时使用 `Option<T*>`。

`IS_RAW_MODE` 是由编译器提供的保留编译配置名称，只能出现在 `comptime if` 的编译期条件中，不能作为普通变量声明。

## 注释

```yian
// Single-line comment.

/* Block comment
   spanning multiple lines */
```

## 运算符

### 算术

```text
+  -  *  /  %
```

### 比较

```text
==  !=  <  >  <=  >=
```

### 逻辑

```text
&&  ||  !
```

> 逻辑运算使用 `&&` / `||` / `!`；`and` / `or` / `not` 是普通标识符，不是运算符。

### 位运算

```text
&  |  ^  ~  <<  >>
```

### 赋值

```text
=  +=  -=  *=  /=  %=  &=  |=  ^=  <<=  >>=
```

### 其他

```text
.  ..  ->  =>  ;  ,  :  (  )  {  }  [  ]  &  *
```

- `..` — 范围运算符（`0..10`）
- `->` — 返回类型标注
- `=>` — match arm 分隔
- `;` — 语句终止符（可省略，语句边界由语法结构决定）
- `&` — 取地址（作为一元前缀）
- `*` — 解引用（作为一元前缀）

来源：`python/yianc/frontend/parse/operator.py`

## 空白敏感性

词法分析器通过空白上下文区分部分歧义 token：

| 上下文        | Token                          |
| ------------- | ------------------------------ |
| `<` 前无空白  | `LAngle`（泛型括号）           |
| `<` 前有空白  | `Less`（小于运算符）           |
| `>` 前无空白  | `RAngle`（泛型闭括号）         |
| `>` 前有空白  | `Greater`（大于运算符）        |
| `>>` 前无空白 | 两个 `RAngle`（嵌套泛型）      |
| `>>` 前有空白 | `GreaterGreater`（右移运算符） |

这一设计消除了 parser 层面的 C++ 式 `>>` 歧义。
