# 01 词法

Yian 的词法规则涵盖标识符、关键字、字面量、注释与运算符。词法分析器在 `compiler/frontend/lex/lexer.py` 中实现，采用逐字符扫描，**空白字符不敏感**（空格、制表符、换行均被跳过，不产生 token）。

## 标识符

由字母、数字和下划线组成，不能以数字开头，不能是单独的下划线 `_`。

```yian
x  my_var  index2  calculate_growth_left  HashMap  _internal
```

非法：

```yian
_       // 单独下划线
2var    // 数字开头
```

来源：`compiler/frontend/lex/lexer.py:12-13`（`START_IDENTIFIER` / `IN_IDENTIFIER` 字符集）

## 关键字

以下为保留关键字，不可用作标识符：

```text
fn  struct  enum  trait  impl  typedef  pub  static  const
comptime  inline  intrinsic
let  return  break  continue  assert
defer
if  elif  else  loop  while  for  in  match
from  import  as  del  typeof
dyn  IS_RAW_MODE
```

基础类型名（`void`、`bool`、`char`、`str`、`i8` 到 `u64`、`f16`/`f32`/`f64`、`int`、`uint`、`float`）、字面量关键字 `true`/`false` 以及单独的下划线 `_` 同样是保留关键字。

来源：`compiler/frontend/lex/token.py` KeywordKind 枚举

编译器内置指令使用保留的 `@name` 命名空间；`sizeof`、`bitcast`、`panic`、`assume_init`
等拼写本身是普通标识符。例如：

```yian
let n: u64 = @sizeof(i32);
@panic("unreachable");
```

`@` 后必须跟已知内建名称和调用参数；未知名称或缺少调用括号会在解析阶段报错。
`@bitcast`、`@alloc`、`@memcpy`、`@Undef`、`@dangling` 等指令只允许在标准库中使用，
完整列表见 [§08 表达式](08.expressions.md)。
普通代码可以定义与内建指令同名的函数，调用时不带 `@` 即按普通符号解析。

## 字面量

### 整数字面量

```yian
42          // IntLiteral — 类型由上下文推断
0xFF        // 十六进制
0u64        // 带类型后缀: u64
5i32        // 带类型后缀: i32
```

- 十进制默认无后缀，类型由上下文确定（`IntLiteralType`）
- 前缀 `0x`、`0o`、`0b` 分别表示十六进制、八进制和二进制
- 后缀 `u8`/`u16`/`u32`/`u64`/`i8`/`i16`/`i32`/`i64`（以及 `int`/`uint`）指定具体类型
- 数字之间可以插入 `_` 作分隔符

来源：`tests/basic/control_flow/for.an`、`tests/basic/std/num/u64.an`

### 浮点字面量

```yian
3.14
0.0
1.5
```

后缀 `f16`/`f32`/`f64`（以及 `float`）指定具体类型，无后缀时由上下文推断。十六进制浮点字面量（如 `0x1.8p1`）也可使用。

来源：`tests/basic/std/num/f64.an`、`tests/basic/literal/`

### 字符字面量

```yian
'A'
'\n'
'中'
```

单引号包围。`char` 是 4 字节 Unicode 码点（`u32` 宽度）。支持转义 `\n`、`\t`、`\r`、`\0`、`\\`、`\'`、`\"`，以及 `\xNN` 十六进制转义和 `\u{...}`/`\U{...}` Unicode 转义。

来源：`tests/basic/literal/`

### 字符串字面量

```yian
"Hello, World!"
""
```

双引号包围。类型为 `str`（不可变 UTF-8 字符串切片）。转义序列与字符字面量相同。

来源：`tests/basic/std/core/str.an`

### f-string

```yian
let name: str = "Yian";
let msg = f"Welcome to {name} v{1}!";
```

`f"..."` 中的 `{expr}` 会被插入为 `expr.to_string()`；整个 f-string 的类型是 `String`。`\{` 和 `\}` 产生字面量花括号，其余转义序列与普通字符串相同。被插入的表达式必须实现 `ToString`。

来源：`tests/basic/fmt/fstring_basic.an`、`tests/basic/fmt/fstring_escape.an`

### 字节字面量

```yian
b'A'        // u8 值 65
b'\n'       // u8 值 10
```

`b` 前缀后跟单字符或转义序列，类型为 `u8`。

来源：`tests/basic/std/core/string.an`

### 布尔字面量

```yian
true
false
```

类型为 `bool`。

YIAN 没有空指针字面量。需要表达可选指针时使用 `Option<T*>`。

`IS_RAW_MODE` 是由编译器提供的保留编译配置名称，只能出现在 `comptime if` 的编译期条件中，不能作为普通变量声明。

## 注释

```yian
// 单行注释

/* 块注释
   可跨多行 */
```

## 运算符

### 算术

```text
+  -  *  /  %
```

### 比较

```text
==  !=  <  >  <=  >=
```

### 逻辑

```text
&&  ||  !
```

> 逻辑运算使用 `&&` / `||` / `!`；`and` / `or` / `not` 是普通标识符，不是运算符。

### 位运算

```text
&  |  ^  ~  <<  >>
```

### 赋值

```text
=  +=  -=  *=  /=  %=  &=  |=  ^=  <<=  >>=
```

### 其他

```text
.  ..  ->  =>  ;  ,  :  (  )  {  }  [  ]  &  *
```

- `..` — 范围运算符（`0..10`）
- `->` — 返回类型标注
- `=>` — match arm 分隔
- `;` — 语句终止符（可省略，语句边界由语法结构决定）
- `&` — 取地址（作为一元前缀）
- `*` — 解引用（作为一元前缀）

来源：`compiler/frontend/parse/operator.py`

## 空白敏感性

词法分析器通过空白上下文区分部分歧义 token：

| 上下文        | Token                          |
| ------------- | ------------------------------ |
| `<` 前无空白  | `LAngle`（泛型括号）           |
| `<` 前有空白  | `Less`（小于运算符）           |
| `>` 前无空白  | `RAngle`（泛型闭括号）         |
| `>` 前有空白  | `Greater`（大于运算符）        |
| `>>` 前无空白 | 两个 `RAngle`（嵌套泛型）      |
| `>>` 前有空白 | `GreaterGreater`（右移运算符） |

这一设计消除了 parser 层面的 C++ 式 `>>` 歧义。
