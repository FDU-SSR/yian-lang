# 01 词法

Yian 的词法规则涵盖标识符、关键字、字面量、注释与运算符。词法分析器在 `compiler/frontend/lex/lexer.py` 中实现，采用逐字符扫描，**空白字符不敏感**（空格、制表符、换行均被跳过，不产生 token）。

## 标识符

由字母、数字和下划线组成，不能以数字开头，不能是单独的下划线 `_`。

```yian
x  my_var  index2  calculate_growth_left  HashMap  _internal
```

非法：

```yian
_       // 单独下划线
2var    // 数字开头
```

来源：`compiler/frontend/lex/lexer.py:8-9`（`START_IDENTIFIER` / `IN_IDENTIFIER` 字符集）

## 关键字

以下为保留关键字，不可用作标识符：

```text
fn  struct  enum  trait  impl  typedef  pub  static
let  return  break  continue  assert
if  elif  else  loop  while  for  in  match
from  import  as  Self  del  sizeof  bitcast
panic  dyn  assume_init
```

来源：`compiler/frontend/lex/token.py` KeywordKind 枚举

## 字面量

### 整数字面量

```yian
42          // IntLiteral — 类型由上下文推断
0xFF        // 十六进制
0u64        // 带类型后缀: u64
5i32        // 带类型后缀: i32
```

- 十进制默认无后缀，类型由上下文确定（`IntLiteralType`）
- 前缀 `0x` 表示十六进制
- 后缀 `u8`/`u16`/`u32`/`u64`/`i8`/`i16`/`i32`/`i64` 指定具体类型

来源：`tests/control_flow/for.an`、`tests/std/num/u64.an`

### 浮点字面量

```yian
3.14
0.0
1.5
```

后缀 `f32`/`f64` 指定具体类型，无后缀时由上下文推断。

来源：`tests/std/num/f64.an`、`tests/literal/`

### 字符字面量

```yian
'A'
'\n'
'中'
```

单引号包围。`char` 是 4 字节 Unicode 码点（`u32` 宽度）。支持转义 `\n`、`\t`、`\r`、`\\`、`\'`。

来源：`tests/literal/`

### 字符串字面量

```yian
"Hello, World!"
""
```

双引号包围。类型为 `str`（不可变 UTF-8 字符串切片）。

来源：`tests/std/core/str.an`

### 字节字面量

```yian
b'A'        // u8 值 65
b'\n'       // u8 值 10
```

`b` 前缀后跟单字符或转义序列，类型为 `u8`。

来源：`tests/std/core/string.an`

### 布尔字面量

```yian
true
false
```

类型为 `bool`。

## 注释

```yian
// 单行注释

/* 块注释
   可跨多行 */
```

## 运算符

### 算术

```text
+  -  *  /  %
```

### 比较

```text
==  !=  <  >  <=  >=
```

### 逻辑

```text
&&  ||  !
```

> Yian 2026 语法使用 `&&` / `||` / `!`，**不是** `and` / `or` / `not`。

### 位运算

```text
&  |  ^  ~  <<  >>
```

### 赋值

```text
=  +=  -=  *=  /=  %=  &=  |=  ^=  <<=  >>=
```

### 其他

```text
.  ..  ::  ->  =>  ;  ,  :  (  )  {  }  [  ]  &  *
```

- `..` — 范围运算符（`0..10`）
- `->` — 返回类型标注
- `=>` — match arm 分隔
- `;` — 语句终止符（Yian 2026 语法中每句必须以 `;` 结尾）
- `&` — 取地址（作为一元前缀）
- `*` — 解引用（作为一元前缀）

来源：`compiler/frontend/parse/operator.py`

## 空白敏感性

词法分析器通过空白上下文区分部分歧义 token：

| 上下文        | Token                          |
| ------------- | ------------------------------ |
| `<` 前无空白  | `LAngle`（泛型括号）           |
| `<` 前有空白  | `Less`（小于运算符）           |
| `>` 前无空白  | `RAngle`（泛型闭括号）         |
| `>` 前有空白  | `Greater`（大于运算符）        |
| `>>` 前无空白 | 两个 `RAngle`（嵌套泛型）      |
| `>>` 前有空白 | `GreaterGreater`（右移运算符） |

这一设计消除了 parser 层面的 C++ 式 `>>` 歧义。
