# 11 结构体与枚举

## 结构体定义

```yian
pub struct Point<T> {
    x: T,
    y: T,
}
```

- 字段格式：`name: Type,`（逗号分隔）
- `pub` 前缀控制外部可见性
- 可带泛型参数 `<T>` 和常量泛型 `const N: u64`

来源：`lib/core/vec.an`、`lib/core/string.an`

## 结构体构造

```yian
// 位置参数
let p: Point<i32> = Point<i32>(1, 2);

// 命名参数
let q: Point<i32> = Point<i32>(x=1, y=2);
```

来源：`tests/generics/struct.an`

## 字段访问

```yian
let p: Point<i32> = Point<i32>(1, 2);
let px: i32 = p.x;          // 读取
p.x = 10;                   // 写入（需要 p 为 place）
```

## 结构体方法

```yian
impl<T> Point<T> {
    pub fn x_val() -> T {
        return self.x;      // self: *Point<T>, 自动解引用
    }
}
```

详见 [§05 方法](05.methods.md)。

## 枚举定义

```yian
pub enum Option<T> {
    None,
    Some { val: T },
}
```

- 变体之间用逗号分隔
- 无 payload 的变体：`None`
- 有 payload 的变体：`Some { val: T }`（字段格式同 struct）

来源：`lib/core/option.an`、`lib/core/result.an`

## 枚举构造

```yian
let opt: Option<i32> = Option<i32>.Some(42);
let none: Option<i32> = Option<i32>.None;
```

构造语法：`EnumName<Variant>.Variant(args)`。

## 枚举方法

```yian
impl<T> Option<T> {
    pub fn is_some() -> bool {
        match self {
            Option::None => false,
            Option::Some => true,
        }
    }
}
```

来源：`lib/core/option.an`

## 结构体与枚举的复制

结构体和枚举无需注解即可普通赋值。复制会保留每个字段或当前 payload 的浅复制效果：

```yian
struct Inner { value: i32 }
struct Outer { inner: Inner, data: u8* }

let data: u8* = dyn[4] u8;
let first = Outer(Inner(1), data);
let second = first;

assert first.inner.value == second.inner.value;
assert first.data == second.data;
```

来源：`tests/assign/struct_copy.an`、`tests/assign/nested_copy.an`、`tests/assign/enum_copy.an`

普通复制不会自动为指针字段分配新存储。需要深拷贝时，应由类型显式实现 `Clone`，并在实现中定义每个资源字段的复制方式。
