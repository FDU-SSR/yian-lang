# 11 结构体与枚举

## 结构体定义

```yian
pub struct Point<T> {
    x: T,
    y: T,
}
```

- 字段格式：`name: Type,`（逗号分隔）
- `pub` 前缀控制外部可见性
- 可带泛型参数 `<T>` 和常量泛型 `const N: u64`

来源：`lib/core/vec.an`、`lib/core/string.an`

## 结构体构造

```yian
// 位置参数
let p: Point<i32> = Point<i32>(1, 2);

// 命名参数
let q: Point<i32> = Point<i32>(x=1, y=2);
```

来源：`tests/generics/struct.an`

## 字段访问

```yian
let p: Point<i32> = Point<i32>(1, 2);
let px: i32 = p.x;          // 读取
p.x = 10;                   // 写入（需要 p 为 place）
```

## 结构体方法

```yian
impl<T> Point<T> {
    pub fn x_val() -> T {
        return self.x;      // self: *Point<T>, 自动解引用
    }
}
```

详见 [§05 方法](05.methods.md)。

## 枚举定义

```yian
pub enum Option<T> {
    None,
    Some { val: T },
}
```

- 变体之间用逗号分隔
- 无 payload 的变体：`None`
- 有 payload 的变体：`Some { val: T }`（字段格式同 struct）

来源：`lib/core/option.an`、`lib/core/result.an`

## 枚举构造

```yian
let opt: Option<i32> = Option<i32>.Some(42);
let none: Option<i32> = Option<i32>.None;
```

构造语法：`EnumName<Variant>.Variant(args)`。

## 枚举方法

```yian
impl<T> Option<T> {
    pub fn is_some() -> bool {
        match self {
            Option::None => false,
            Option::Some => true,
        }
    }
}
```

来源：`lib/core/option.an`

## `@BitCopy` 注解

`@BitCopy` 注解标记 struct 或 enum 为可逐位拷贝类型：

```yian
@BitCopy
struct Point {
    x: i32,
    y: i32,
}
```

约束：
- 所有字段类型必须是简单类型（或也是 `@BitCopy` 类型）
- 编译器在类型检查时验证——非简单字段会导致编译错误
- `@BitCopy` 类型的 `move()`/`clone()`/`invalidate()` 为 no-op

来源：`tests/assign/bitcopy_struct.an`、`tests/assign/bitcopy_enum.an`
错误示例：`tests/assign/bitcopy_struct_err.err.an`、`tests/assign/bitcopy_enum_err.err.an`

## 嵌套类型

```yian
@BitCopy
struct Inner {
    x: i32,
}

@BitCopy
struct Outer {
    inner: Inner,           // OK: Inner 也是 @BitCopy
    y: i32,
}
```

来源：`tests/assign/bitcopy_nested.an`
