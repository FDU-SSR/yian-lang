# 11 结构体与枚举

## 结构体定义

```yian
pub struct Point<T> {
    x: T,
    y: T,
}
```

- 字段格式：`name: Type,`（逗号分隔）
- `pub` 前缀控制外部可见性
- 可带泛型参数 `<T>` 和常量泛型 `const N: u64`

来源：`lib/src/core/vec.an`、`lib/src/core/string.an`

## 结构体构造

```yian
// Positional arguments.
let p: Point<i32> = Point<i32>(1, 2);

// Named arguments.
let q: Point<i32> = Point<i32>(x=1, y=2);
```

来源：`tests/basic/generics/struct.an`

## 字段访问

```yian
let p: Point<i32> = Point<i32>(1, 2);
let px: i32 = p.x;          // Read.
p.x = 10;                   // Write; p must be a place.
```

## 结构体方法

```yian
impl<T> Point<T> {
    pub fn x_val() -> T {
        return self.x;      // self:Point<T>&, with automatic dereference.
    }
}
```

详见 [§05 方法](05.methods.md)。

## 枚举定义

```yian
pub enum Option<T> {
    None,
    Some { val: T },
}
```

- 变体之间用逗号分隔
- 无 payload 的变体：`None`
- 有 payload 的变体：`Some { val: T }`（字段格式同 struct）

来源：`lib/src/core/option.an`、`lib/src/core/result.an`

全部变体都没有 payload 的枚举自动获得同类型的 `PartialEq`，比较变体身份，支持 `==` 和 `!=`。
显式的同类型 `PartialEq` 实现优先于自动实现。带 payload 的枚举需要自行实现比较。

## 枚举构造

```yian
let opt: Option<i32> = Option<i32>.Some(42);
let none: Option<i32> = Option<i32>.None;
```

构造语法：`EnumName<泛型实参>.Variant(args)`；无泛型参数时写作 `EnumName.Variant(args)`。无 payload 的变体不带参数。

## 枚举方法

```yian
impl<T> Option<T> {
    pub fn is_some() -> bool {
        match self {
            None => false,
            Some => true,
        }
    }
}
```

来源：`lib/src/core/option.an`
