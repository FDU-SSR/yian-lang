# 09 运算符重载

Yian 通过 trait 实现运算符重载。实现对应 trait 即可为自定义类型启用运算符。

所有运算符 trait 定义在 `lib/core/ops.an`，编译器在 `compiler/frontend/parse/operator.py` 中维护运算符到 trait 的映射。

## 算术运算符

| 运算符 | Trait | 方法签名 | 测试 |
|--------|-------|---------|------|
| `+` | `Add<Rhs, Output>` | `fn add(rhs: Rhs) -> Output` | `tests/std/core/ops/arith.an` |
| `-` | `Sub<Rhs, Output>` | `fn sub(rhs: Rhs) -> Output` | 同上 |
| `*` | `Mul<Rhs, Output>` | `fn mul(rhs: Rhs) -> Output` | 同上 |
| `/` | `Div<Rhs, Output>` | `fn div(rhs: Rhs) -> Output` | 同上 |
| `%` | `Rem<Rhs, Output>` | `fn rem(rhs: Rhs) -> Output` | 同上 |
| `-x` | `Neg<Output>` | `fn neg() -> Output` | 同上 |

示例：

```yian
impl Add<Value<i32>, Value<i32>> for Value<i32> {
    fn add(rhs: Self) -> Self {
        return Self(self.value + rhs.value);
    }
}

let a: Value<i32> = Value<i32>(10);
let b: Value<i32> = Value<i32>(20);
let c: Value<i32> = a + b;          // c.value == 30
```

## 比较运算符

| 运算符 | Trait | 方法签名 | 测试 |
|--------|-------|---------|------|
| `==` | `PartialEq<Rhs>` | `fn eq(rhs: Rhs*) -> bool` | `tests/std/core/ops/cmp.an` |
| `!=` | `PartialEq<Rhs>` | `fn ne(rhs: Rhs*) -> bool`（默认 `!self.eq(rhs)`） | 同上 |

所有比较运算符的 rhs 参数是**指针**（`Rhs*`），由编译器自动取地址。

## 排序运算符

| 运算符 | Trait | 方法签名 |
|--------|-------|---------|
| `<` | `PartialOrd<Rhs>` | `fn lt(rhs: Rhs*) -> bool`（默认实现） |
| `>` | `PartialOrd<Rhs>` | `fn gt(rhs: Rhs*) -> bool`（默认实现） |

测试：`tests/std/core/ops/funcs.an`

## Index / Deref

| 运算符 | Trait | 方法签名 | 测试 |
|--------|-------|---------|------|
| `[]` | `Index<Idx, Target>` | `fn index(idx: Idx*) -> Target` | `tests/std/core/ops/index.an` |
| `*` | `Deref<Target>` | `fn deref() -> Target` | `tests/std/core/ops/deref.an` |

### Index 示例

```yian
impl<T> Index<u64, T*> for Vec<T> {
    fn index(index: u64*) -> T* {
        // 返回指向元素的指针
    }
}
let v: Vec<i32> = ...;
let x: i32 = v[0];      // 调用 Index::index(&0)
```

### Deref 示例

```yian
impl Deref<str> for String {
    fn deref() -> str {
        self.as_str()
    }
}
let s: String = String.from(&"hello");
let raw: str = *s;       // 自动解引用
```

Deref 还启用自动解引用链：编译器在方法查找时自动沿 Deref 链搜索。

## `Contains`（`in` 运算符）

| 运算符 | Trait | 方法签名 |
|--------|-------|---------|
| `in` | `Contains<T>` | `fn contains(item: T*) -> bool` |

`x in collection` 被 desugar 为 `collection.contains(x)`。
