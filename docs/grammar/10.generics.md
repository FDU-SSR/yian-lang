# 10 泛型

## 泛型函数

```yian
fn identity<T>(x: T) -> T {
    return x;
}

let a: i32 = identity<i32>(42);     // 显式指定
let b: i32 = identity(42);          // 类型推断 — 来源: tests/generics/func.an
```

## 泛型 struct

```yian
struct Pair<T, U> {
    first: T,
    second: U,
}

let p: Pair<i32, bool> = Pair<i32, bool>(42, true);
```

来源：`tests/generics/struct.an`

## 泛型 enum

```yian
pub enum Option<T> {
    None,
    Some { val: T },
}
```

来源：`lib/core/option.an`

## 泛型 impl

```yian
impl<T> Pair<T, T> {
    fn swap() {
        let tmp: T = self.first;
        self.first = self.second;
        self.second = tmp;
    }
}
```

来源：`tests/generics/inherent_method.an`、`tests/generics/method.an`

## 泛型 trait impl

```yian
trait Summable<T> {
    fn sum(other: T) -> T;
    static fn zero() -> T;
}

impl<T> Summable<Value<T>> for Value<T> {
    fn sum(other: Value<T>) -> Value<T> {
        return Value<T>(data=self.data + other.data);
    }
    static fn zero() -> Value<T> {
        return Value<T>(data=T(0));
    }
}
```

## 常量泛型

```yian
impl<T, const N: u64> T[N] {
    fn get_length() -> u64 {
        N
    }
}
```

`const N: u64` 表示编译期常量，用于数组长度等场景。

来源：`tests/generics/const.an`

## 条件 impl（trait bound）

```yian
impl<T, Src> Into<T> for Src if Src: From<T> {
    fn into() -> T { /* ... */ }
}
```

`if Type: Trait` 约束实现仅在条件满足时生效。这是泛型代码组合的关键机制。

来源：`lib/core/iter.an`（`IntoIterator` blanket impl）

## 泛型推断

```yian
let v: Vec<i32> = Vec<i32>.new();   // T = i32 从类型标注推断
v.push(42);                         // T = i32 已确定

let opt = Option<i32>.Some(10);     // 可从上下文推断 Option 类型
```

编译器使用 `GenericInference`（`compiler/analysis/ty/generic_inference.py`）进行泛型参数推断。

## 字面量泛型

字面量类型参数（如 `IntLiteralType`）由上下文字段类型消解为具体类型：

```yian
let v: Vec<u64> = Vec<u64>.new();
v.push(42);                         // 42: IntLiteral → u64
```

来源：`tests/generics/literal.an`
