# 10 泛型

## 泛型函数

```yian
fn identity<T>(x: T) -> T {
    return x;
}

let a: i32 = identity<i32>(42);     // Explicit argument.
let b: i32 = identity(42);          // Type inference; source: tests/basic/generics/func.an.
```

## 泛型 impl

```yian
impl<T> Pair<T, T> {
    fn swap() {
        let tmp: T = self.first;
        self.first = self.second;
        self.second = tmp;
    }
}
```

## 泛型 trait impl

```yian
trait Summable<T> {
    fn sum(other: T) -> T;
    static fn zero() -> T;
}

impl<T> Summable<Value<T>> for Value<T> {
    fn sum(other: Value<T>) -> Value<T> {
        return Value<T>(data=self.data + other.data);
    }
    static fn zero() -> Value<T> {
        return Value<T>(data=T(0));
    }
}
```

## 常量泛型

```yian
impl<T, const N: u64> T[N] {
    fn get_length() -> u64 {
        N
    }
}
```

`const N: u64` 表示编译期常量，用于数组长度等场景。

数组长度和常量泛型实参可使用具体整数的编译期表达式，包括括号、一元 `-`/`~`、
算术、位运算和移位，也可引用可求值的整数常量。数组长度必须非负。未实例化的常量
泛型可直接用作长度或实参，但涉及它的算术表达式不受支持。

来源：`tests/basic/generics/const.an`

## 条件 impl（trait bound）

```yian
impl<T, Src> Into<T> for Src if Src: From<T> {
    fn into() -> T { /* ... */ }
}
```

`if Type: Trait` 约束实现仅在条件满足时生效。这是泛型代码组合的关键机制。

来源：`lib/src/core/iter.an`（`IntoIterator` blanket impl）

## 泛型推断

```yian
let v: Vec<i32> = Vec<i32>.new();   // Explicit T=i32.
v.push(42);                         // T=i32 is determined.

let opt = Option.Some(10);          // Infer T=i32 from the variant payload.
```

编译器使用 `GenericInference`（`python/yianc/analysis/ty/generic_inference.py`）进行泛型参数推断。若参数无法由
显式类型实参或调用实参确定，编译器会报告无法推断。变体构造也必须得到完整、具体的枚举类型；载荷可以推断
其中用到的参数，例如 `Option.Some(10)`；空载荷变体或未使用某个参数的变体不能确定该参数，应写出完整类型，
例如 `Option<i32>.None`。结构体构造和泛型函数调用同样不能省略未被实参约束的参数。

## 字面量泛型

字面量类型参数（如 `IntLiteralType`）由上下文字段类型消解为具体类型：

```yian
let v: Vec<u64> = Vec<u64>.new();
v.push(42);                         // 42: IntLiteral → u64
```

来源：`tests/basic/generics/literal.an`
