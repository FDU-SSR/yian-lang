# 04 函数

## 定义

函数使用 `fn` 关键字定义。参数格式为 `name: Type`，用逗号分隔。返回类型用 `-> Type` 标注。

有函数体的函数也支持不可失败的解构参数，例如 `(left, right): (i32, i32)`；
trait 方法的无函数体声明使用普通命名参数。规则见[模式匹配](07.match.md)。

```yian
fn add(a: i32, b: i32) -> i32 {
    return a + b;
}
```

无返回值的函数可以不写 `-> Type`（等价于 `-> void`）：

```yian
fn log(msg: str) {
    // No return value.
}
```

## `main` 函数

程序入口必须是名为 `main` 的函数，返回 `void`：

```yian
fn main() {
}
```

- `main` 不能有泛型参数
- standalone 模式从输入中选择唯一的 `main`；package 模式只在根包声明的入口模块中选择，依赖包可有同名普通函数
- 需要返回非零退出码时调用 prelude 提供的 `exit(code)`
- 来源：全部 `tests/` 下的可编译文件

## `return` 语句

```yian
fn abs(x: i32) -> i32 {
    if x >= 0 {
        return x;
    }
    return -x;
}
```

如果函数以表达式结尾（不带分号），该表达式的值作为返回值：

```yian
fn add(a: i32, b: i32) -> i32 {
    a + b                   // Return the tail expression without return.
}
```

来源：`tests/basic/expr_oriented/`

## 参数传递

参数按值传递。所有类型都直接按位复制传入，无需显式 move：

```yian
fn consume(v: Vec<i32>) {
    // v is a shallow copy of the argument.
}
let v: Vec<i32> = Vec<i32>.new();
consume(v);             // Pass directly.
// v remains usable, sharing the underlying buffer.
```

来源：`tests/basic/assign/functions.an`

## 泛型函数

```yian
fn first<T>(a: T, b: T) -> T {
    return a;
}

let x: i32 = first<i32>(1, 2);  // Explicit generic argument.
let y: i32 = first(1, 2);       // Type inference; source: tests/basic/generics/func.an.
```

详见 [§10 泛型](10.generics.md)。

## 函数指针

函数可以作为值传递，类型为函数指针：

```yian
fn apply(f: fn(i32) -> i32, x: i32) -> i32 {
    return f(x);
}

fn double(x: i32) -> i32 {
    return x * 2;
}

let result: i32 = apply(&double, 21);
assert result == 42;
```

来源：`tests/basic/call/func.an`

## 函数变量

除了函数指针，函数还可以直接绑定到变量，成为**函数变量**。函数变量的类型是该函数的
**函数项类型 (function item type)**，它与函数指针有本质区别：

- **每个函数的类型都是唯一的**，即使两个函数签名相同，它们的函数项类型也不同。
- **函数项类型是 ZST（零大小类型）**：函数身份编码在类型里，变量本身不占运行期空间，
  调用被编译为对目标函数的**直接调用**，无运行期开销。
- **声明不能标注类型**，函数项类型不可书写，只能由编译器推断。

```yian
fn add1(x: i32) -> i32 { return x + 1; }

fn main() {
    let f = add1;        // Infer f as add1's function-item type, a ZST.
    assert f(41) == 42;  // Call add1 directly.
}
```

来源：`tests/basic/func_var/bind_call.an`

### 传递、返回与存储（经由泛型）

由于函数项类型不可命名，把函数变量作为参数、返回值或存入数据结构时都通过**泛型**承载，
类型由推断得到：

```yian
fn add1(x: i32) -> i32 { return x + 1; }

// Passing: generic F binds the function-item type.
fn apply<F>(f: F, n: i32) -> i32 { return f(n); }

// Return through the generic type.
fn identity_fn<F>(f: F) -> F { return f; }

// Store in a generic field.
struct Holder<F> { f: F }

fn main() {
    assert apply(add1, 41) == 42;
    let g = identity_fn(add1);
    assert g(41) == 42;
    let h = Holder(f = add1);
    assert (h.f)(41) == 42;   // See call syntax below.
}
```

来源：`tests/basic/func_var/pass_generic.an`

### 调用存储在数据结构中的函数

- 结构体字段：`h.f(x)` 会被解析为**方法调用**，因此用括号形式 `(h.f)(x)`，
  或先绑定 `let g = h.f; g(x)`。
- 元组 / 数组元素：用索引语法 `t[i](x)`、`arr[i](x)`。

```yian
fn add1(x: i32) -> i32 { return x + 1; }

fn main() {
    let t = (add1, 5);
    assert t[0](41) == 42;

    let arr = [add1, add1];
    assert arr[0](41) == 42;
}
```

来源：`tests/basic/func_var/array_hold.an`

### 与函数指针的区别

| | 函数变量（函数项） | 函数指针 `fn(...)->...` |
| --- | --- | --- |
| 获取方式 | `let f = foo;`（推断） | `&foo`（显式取地址） |
| 类型是否唯一 | 每个函数唯一 | 按签名相同即相同 |
| 是否 ZST | 是（零开销） | 否（携带地址） |
| 可否标注类型 | 否，必须推断 | 可，如 `f: fn(i32)->i32` |
| 调用 | 直接调用 | 间接调用 |

### 常见错误

```yian
fn foo() -> void { return; }
fn bar() -> void { return; }

let f: fn()->void = foo;  // Error: function-item types cannot be annotated and differ from function-pointer types.
let g = foo; g = bar;     // Error: each function type is unique; cannot rebind to another function.
```

来源：`tests/basic/func_var/annotate_fn.err.an`、`reassign_diff.err.an`

## 闭包

闭包用显式捕获表与参数表定义，捕获表达式在构造时求值并按浅层值复制存入环境：

```yian
let bias: i32 = 10;
let add_bias = |captured_bias = bias| (value: i32) -> i32 {
    captured_bias + value
};
let result: i32 = add_bias(5);
```

无捕获写作 `|| (参数) { ... }`。捕获引用可写 `|p = &value|`，其有效期由调用者管理。
闭包有独立的不可书写类型，使用推断或泛型承载；不能标注为函数指针类型。
泛型透传可以返回或存储闭包；直接函数返回类型不能书写闭包的独立类型。

来源：`tests/basic/closure/`，调用字段中的闭包与函数项一样使用 `(holder.field)(args)`。
