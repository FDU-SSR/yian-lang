# 04 函数

## 定义

函数使用 `fn` 关键字定义。参数格式为 `name: Type`，用逗号分隔。返回类型用 `-> Type` 标注。

```yian
fn add(a: i32, b: i32) -> i32 {
    return a + b;
}
```

无返回值的函数可以不写 `-> Type`（等价于 `-> void`）：

```yian
fn log(msg: str) {
    // 无返回值
}
```

## `main` 函数

程序入口必须是名为 `main` 的函数，返回 `i32`（退出码）：

```yian
fn main() -> i32 {
    return 0;               // 0 表示成功
}
```

- `main` 不能有泛型参数
- 每个程序只能有一个 `main`
- 来源：全部 `tests/` 下的可编译文件

## `return` 语句

```yian
fn abs(x: i32) -> i32 {
    if x >= 0 {
        return x;
    }
    return -x;
}
```

如果函数以表达式结尾（不带分号），该表达式的值作为返回值：

```yian
fn add(a: i32, b: i32) -> i32 {
    a + b                   // 尾表达式返回，无需 return
}
```

来源：`tests/expr_oriented/`

## 参数传递

参数按值传递。所有类型都直接按位复制传入，无需显式 move：

```yian
fn consume(v: Vec<i32>) {
    // v 是参数的按位复制
}
let v: Vec<i32> = Vec<i32>.new();
consume(v);             // 直接传参
// v 仍可用（共享底层缓冲）
```

来源：`tests/assign/functions.an`

## 泛型函数

```yian
fn first<T>(a: T, b: T) -> T {
    return a;
}

let x: i32 = first<i32>(1, 2);  // 显式指定泛型参数
let y: i32 = first(1, 2);       // 类型推断 — 来源: tests/generics/func.an
```

详见 [§10 泛型](10.generics.md)。

## 函数指针

函数可以作为值传递，类型为函数指针：

```yian
fn apply(f: fn(i32) -> i32, x: i32) -> i32 {
    return f(x);
}

fn double(x: i32) -> i32 {
    return x * 2;
}

let result: i32 = apply(&double, 21);
assert result == 42;
```

来源：`tests/call/func_ptr.an`

## 函数变量

除了函数指针，函数还可以直接绑定到变量，成为**函数变量**。函数变量的类型是该函数的
**函数项类型 (function item type)**，它与函数指针有本质区别：

- **每个函数的类型都是唯一的**，即使两个函数签名相同，它们的函数项类型也不同。
- **函数项类型是 ZST（零大小类型）**：函数身份编码在类型里，变量本身不占运行期空间，
  调用被编译为对目标函数的**直接调用**，无运行期开销。
- **声明不能标注类型**，函数项类型不可书写，只能由编译器推断。

```yian
fn add1(x: i32) -> i32 { return x + 1; }

fn main() -> i32 {
    let f = add1;        // 推断 f 的类型为 add1 的函数项类型（ZST）
    assert f(41) == 42;  // 直接调用 add1
    return 0;
}
```

来源：`tests/func_var/bind_call.an`

### 传递、返回与存储（经由泛型）

由于函数项类型不可命名，把函数变量作为参数、返回值或存入数据结构时都通过**泛型**承载，
类型由推断得到：

```yian
fn add1(x: i32) -> i32 { return x + 1; }

// 传递：泛型参数 F 绑定到函数项类型
fn apply<F>(f: F, n: i32) -> i32 { return f(n); }

// 返回：泛型透传
fn identity_fn<F>(f: F) -> F { return f; }

// 存储：泛型字段
struct Holder<F> { f: F }

fn main() -> i32 {
    assert apply(add1, 41) == 42;
    let g = identity_fn(add1);
    assert g(41) == 42;
    let h = Holder(f = add1);
    assert (h.f)(41) == 42;   // 见下方调用语法
    return 0;
}
```

来源：`tests/func_var/pass_generic.an`、`return_generic.an`、`struct_field.an`

### 调用存储在数据结构中的函数

- 结构体字段：`h.f(x)` 会被解析为**方法调用**，因此用括号形式 `(h.f)(x)`，
  或先绑定 `let g = h.f; g(x)`。
- 元组 / 数组元素：用索引语法 `t[i](x)`、`arr[i](x)`。

```yian
fn add1(x: i32) -> i32 { return x + 1; }

fn main() -> i32 {
    let t = (add1, 5);
    assert t[0](41) == 42;

    let arr = [add1, add1];
    assert arr[0](41) == 42;
    return 0;
}
```

来源：`tests/func_var/tuple_hold.an`、`array_hold.an`

### 与函数指针的区别

| | 函数变量（函数项） | 函数指针 `fn(...)->...` |
| --- | --- | --- |
| 获取方式 | `let f = foo;`（推断） | `&foo`（显式取地址） |
| 类型是否唯一 | 每个函数唯一 | 按签名相同即相同 |
| 是否 ZST | 是（零开销） | 否（携带地址） |
| 可否标注类型 | 否，必须推断 | 可，如 `f: fn(i32)->i32` |
| 调用 | 直接调用 | 间接调用 |

### 常见错误

```yian
fn foo() -> void { return; }
fn bar() -> void { return; }

let f: fn()->void = foo;  // 错误：函数项类型不可标注（与函数指针是不同类型）
let g = foo; g = bar;     // 错误：每个函数类型唯一，不能改绑到别的函数
```

来源：`tests/func_var/annotate_fn.err.an`、`reassign_diff.err.an`
