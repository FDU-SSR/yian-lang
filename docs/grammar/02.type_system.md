# 02 类型系统

## 基础类型

Yian 提供以下内置基础类型。

### 整数

| 类型  | 宽度   | 有符号 | 示例               |
| ----- | ------ | ------ | ------------------ |
| `i8`  | 1 字节 | 是     | `127i8`            |
| `i16` | 2 字节 | 是     |                    |
| `i32` | 4 字节 | 是     | `42i32`            |
| `i64` | 8 字节 | 是     |                    |
| `u8`  | 1 字节 | 否     | `255u8`            |
| `u16` | 2 字节 | 否     |                    |
| `u32` | 4 字节 | 否     |                    |
| `u64` | 8 字节 | 否     | `0u64`             |

无后缀的整数字面量（如 `42`）具有 `IntLiteralType`，由上下文推断具体类型。

来源：`lib/src/num/i32.an`、`lib/src/num/u64.an`

### 浮点数

| 类型  | 宽度   | 示例      |
| ----- | ------ | --------- |
| `f16` | 2 字节 | `1.5_f16` |
| `f32` | 4 字节 | `3.14f32` |
| `f64` | 8 字节 | `3.14`    |

来源：`lib/src/num/f64.an`、`tests/basic/std/num/f64.an`

### 其他基础类型

| 类型    | 说明                              | 示例            |
| ------- | --------------------------------- | --------------- |
| `bool`  | 布尔值                            | `true`、`false` |
| `char`  | Unicode 码点（4 字节）            | `'A'`、`'中'`   |
| `str`   | 不可变 UTF-8 字符串切片           | `"hello"`       |
| `void`  | 空类型（函数无返回值）            | —               |
| `Never` | 无返回值类型（`@panic`、无限循环） | —               |

## 指针 `T*`

```yian
let x: i32 = 42;
let p: i32* = &x;       // -- Source: tests/basic/pointer/
assert *p == 42;
```

来源：`tests/basic/pointer/`、`tests/basic/std/core/pointer.an`

用于 C ABI 的 `cptr<T>` 是不同类型：它是单个原生指针，不携带 YIAN 的边界和生命周期元数据，也不隐式转换成 `T*`。其权限和封送规则见 [C ABI FFI](17.ffi.md)。

在 native `yianc` 的默认 fat 模式中，非 ZST `T*` 的 LLVM 表示为
`{data, word, offset_bytes, extent_bytes}`，大小为 24 字节。`data` 是授权范围的基址，
`word` 打包锁槽位置和当前身份，末两项是 32 位字节数。有效地址为 `data + offset_bytes`，
字节范围上限是 `0xFFFF_FFFF` B。使用 `--raw-pointers` 时，`T*` 是 8 字节裸数据指针，
LLVM IR 使用 opaque pointer `ptr`。

## 数组 `T[N]`

```yian
let arr: i32[5] = [1, 2, 3, 4, 5];  // -- Source: tests/basic/array/assign.an
let first: i32 = arr[0];
```

数组长度是编译期常量，数组常量本身也可以声明为模块级常量：

```yian
const BYTES: u8[3] = [0, 128, 255];
const EMPTY: u8[0] = [0; 0];
const LENGTHS: u64[2] = [3, 5];
const N: u64 = LENGTHS[0];
let sized: u8[N] = [1, 2, 3];
```

常量数组的元素类型按同一规则递归封闭。来源：`tests/basic/array/`、
`tests/basic/control_flow/comptime_const_items.an`

## 切片 `T[]`

```yian
let arr: i32[5] = [1, 2, 3, 4, 5];
let slice: i32[] = arr[1u64..4];     // -- Source: tests/basic/std/core/slice.an
assert slice.len() == 3;
```

切片是对数组的"视图"，本身不拥有数据。在 fat 模式中，`T[]` 的表示为
`{data, word, len}`，大小为 24 字节。在 `--raw-pointers` 模式中表示为 `{ptr, u64}`，
大小为 16 字节。`len` 以元素为单位，包括零大小元素。`str` 的长度以 UTF-8 字节为单位。
fat 视图继承原对象的生命周期字。

来源：`tests/basic/std/core/slice.an`、`lib/src/core/slice.an`

## 引用 `T&`

`T&` 是后缀引用类型。它表示一个可通过自动解引用访问 `T` 的地址值，但不提供借用检查、生命周期推导或别名限制。格式化插值不使用这种自动解引用，`T&` 需要显式 `*`。

```yian
fn read(value: i32&) -> i32 {
    *value
}

let value: i32 = 42;
let reference: i32& = &value;
assert read(reference) == 42;
```

在默认 fat 模式中，非 ZST 具体类型的 `T&` 表示为 `{data, word}`，大小为
16 字节。形成引用时，空间检查确认地址满足目标类型的完整跨度要求。
在 `--raw-pointers` 模式中，`T&` 退化为 8 字节裸数据指针，LLVM IR 使用 opaque pointer `ptr`。
这些是当前编译器的表示约定，不改变引用没有借用检查或生命周期推导的语言语义。

当 `T` 是 trait 时，`Trait&` 表示 trait object，而不是普通的 `RefType<Trait>`。
在当前 64 位布局中，trait object 在 fat 模式保存数据地址、生命周期元数据和
vtable（24 字节），raw 模式保存数据指针和 vtable（16 字节）。语法仍是后缀引用形式，
普通类型的 `T&` 仍表示普通引用；`Trait*` 不是可存储的运行期类型。
trait object 的构造和调用规则见 [Trait 与 Impl](12.traits_impls.md#trait-object)。

## `str` 与 `String`

```yian
// str: immutable string view.
let s: str = "hello";                    // -- Source: tests/basic/std/core/str.an
let bytes: u8[] = s.as_slice();

// String: mutable, heap-allocated string.
let name: String = String.from(&"Yian");  // -- Source: tests/basic/std/core/string.an
name.push('!');
```

- `str` 是内置类型；fat 模式布局为 `{data, word, size}`，大小为 24 字节，
  其中 `data` 是 `i8*`、`word` 打包锁槽位置与键、`size` 是字节长度；
  `--raw-pointers` 模式布局为 `{i8*, u64}`，大小为 16 字节
- `String` 是 `lib/src/core/string.an` 中定义的结构体，内部持有 `Vec<u8>`
- `String` 实现 `Deref<str>`，可作为 `str` 使用

来源：`tests/basic/std/core/str.an`、`tests/basic/std/core/string.an`、`lib/src/core/str.an`、`lib/src/core/string.an`

## 结构体

```yian
pub struct Point<T> {
    x: T,
    y: T,
}

let p: Point<i32> = Point<i32>(1, 2);     // Positional construction.
let q: Point<i32> = Point<i32>(x=3, y=4); // Named construction.
let px: i32 = p.x;                        // Field access.
```

来源：`tests/basic/generics/struct.an`、`lib/src/core/vec.an`

## 枚举

```yian
pub enum Option<T> {
    None,
    Some { val: T },
}

let opt: Option<i32> = Option<i32>.Some(42);
let none: Option<i32> = Option<i32>.None;
```

变体通过 `EnumName.Variant(args)` 构造。有 payload 的变体使用 `{ field: Type, }` 语法。

来源：`lib/src/core/option.an`、`tests/basic/std/core/option.an`

## 类型别名

```yian
typedef ErrorCode = u64;
let code: ErrorCode = 1;
```

来源：`tests/basic/type/`

类型别名是透明的：使用点解析为目标类型，不建立新的运行期类型身份。别名可以带类型和
常量泛型参数；参数数量与类别必须匹配，循环别名会报错。声明、悬停和导航仍保留别名名称。
常量参数的类型可以依赖前面声明的类型参数；实例化时先替换该类型，再校验常量实参。

## 赋值与拷贝语义

YIAN 的赋值、传参与返回均为**按位复制**（bitwise copy）语义：所有类型的值都可以直接赋值，不存在"简单类型 / 非简单类型"之分，也无需显式复制调用。

```yian
struct Point {
    x: i32,
    y: i32,
}

let a: Point = Point(1, 2);
let b: Point = a;   // Direct shallow copy.
```

堆分配类型（`Vec<T>`、`String` 等）的按位复制会共享底层缓冲；需要独立缓冲区时调用标准库的 `Clone`（如 `Vec::clone`），它只复制容器自己管理的缓冲区，元素自己拥有的资源不会被递归复制。具体的资源有效性和运行时检查不属于赋值规则本身。
