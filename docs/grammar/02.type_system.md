# 02 类型系统

## 基础类型

Yian 的内置基础类型在 `compiler/analysis/ty/space.py:__add_intrinsic_types` 中注册：

### 整数

| 类型  | 宽度   | 有符号 | 示例               |
| ----- | ------ | ------ | ------------------ |
| `i8`  | 1 字节 | 是     | `-128i8` ~ `127i8` |
| `i16` | 2 字节 | 是     |                    |
| `i32` | 4 字节 | 是     | `42i32`            |
| `i64` | 8 字节 | 是     |                    |
| `u8`  | 1 字节 | 否     | `255u8`            |
| `u16` | 2 字节 | 否     |                    |
| `u32` | 4 字节 | 否     |                    |
| `u64` | 8 字节 | 否     | `0u64`             |

无后缀的整数字面量（如 `42`）具有 `IntLiteralType`，由上下文推断具体类型。

来源：`lib/src/num/i32.an`、`lib/src/num/u64.an`

### 浮点数

| 类型  | 宽度   | 示例      |
| ----- | ------ | --------- |
| `f16` | 2 字节 | `1.5_f16` |
| `f32` | 4 字节 | `3.14f32` |
| `f64` | 8 字节 | `3.14`    |

来源：`lib/src/num/f64.an`、`tests/basic/std/num/f64.an`

### 其他基础类型

| 类型    | 说明                              | 示例            |
| ------- | --------------------------------- | --------------- |
| `bool`  | 布尔值                            | `true`、`false` |
| `char`  | Unicode 码点（4 字节）            | `'A'`、`'中'`   |
| `str`   | 不可变 UTF-8 字符串切片           | `"hello"`       |
| `void`  | 空类型（函数无返回值）            | —               |
| `never` | 无返回值类型（`@panic`、无限循环） | —               |

## 指针 `T*`

```yian
let x: i32 = 42;
let p: i32* = &x;       // -- 来源: tests/basic/pointer/
assert *p == 42;
```

来源：`tests/basic/pointer/`、`tests/basic/std/core/pointer.an`

在当前编译器的默认 fat 模式中，非 ZST `T*` 的 LLVM 表示为
`{data, lock_ptr, key, index, size}`，大小为 40 字节；`data` 是元素指针，
其余字段是生命周期和范围元数据。使用 `--raw-pointers` 时，`T*` 退化为带
具体 pointee 类型的 8 字节裸指针，不携带这些元数据或安全检查。

## 数组 `T[N]`

```yian
let arr: i32[5] = [1, 2, 3, 4, 5];  // -- 来源: tests/basic/array/assign.an
let first: i32 = arr[0];
```

数组长度是编译期常量。来源：`tests/basic/array/`

## 切片 `T[]`

```yian
let arr: i32[5] = [1, 2, 3, 4, 5];
let slice: i32[] = arr[1u64..4];     // -- 来源: tests/basic/std/core/slice.an
assert slice.len() == 3;
```

切片是对数组的"视图"，本身不拥有数据。在 fat 模式中，`T[]` 的表示为
`{data, lock_ptr, key, size}`，大小为 32 字节；在 `--raw-pointers` 模式中，
表示为 `{T*, u64}`，大小为 16 字节。`size` 是元素数量，生命周期字段继承
被视图引用的对象。

来源：`tests/basic/std/core/slice.an`、`lib/src/core/slice.an`

## 引用 `T&`

`T&` 是后缀引用类型。它表示一个可通过自动解引用访问 `T` 的地址值，但不提供借用检查、生命周期推导或别名限制。

```yian
fn read(value: i32&) -> i32 {
    *value
}

let value: i32 = 42;
let reference: i32& = &value;
assert read(reference) == 42;
```

在默认 fat 模式中，非 ZST 的 `T&` 表示为 `{data, lock_ptr, key}`，大小为
24 字节；它不携带 `index`/`size`，因为引用必须指向一个已确认存在的元素。
在 `--raw-pointers` 模式中，`T&` 退化为带具体 pointee 类型的 8 字节裸指针。
这些是当前编译器的表示约定，不改变引用没有借用检查或生命周期推导的语言语义。

## `str` 与 `String`

```yian
// str — 不可变字符串切片
let s: str = "hello";                    // -- 来源: tests/basic/std/core/str.an
let bytes: u8[] = s.as_slice();

// String — 可变、堆分配的字符串
let name: String = String.from(&"Yian");  // -- 来源: tests/basic/std/core/string.an
name.push('!');
```

- `str` 是内置类型；fat 模式布局为 `{data, lock_ptr, key, size}`，大小为 32 字节，
  其中 `data` 是 `i8*`、`size` 是字节长度；`--raw-pointers` 模式布局为
  `{i8*, u64}`，大小为 16 字节
- `String` 是 `lib/src/core/string.an` 中定义的结构体，内部持有 `Vec<u8>`
- `String` 实现 `Deref<str>`，可作为 `str` 使用

来源：`tests/basic/std/core/str.an`、`tests/basic/std/core/string.an`、`lib/src/core/str.an`、`lib/src/core/string.an`

## 结构体

```yian
pub struct Point<T> {
    x: T,
    y: T,
}

let p: Point<i32> = Point<i32>(1, 2);     // 位置参数构造
let q: Point<i32> = Point<i32>(x=3, y=4); // 命名参数构造
let px: i32 = p.x;                        // 字段访问
```

来源：`tests/basic/generics/struct.an`、`lib/src/core/vec.an`

## 枚举

```yian
pub enum Option<T> {
    None,
    Some { val: T },
}

let opt: Option<i32> = Option<i32>.Some(42);
let none: Option<i32> = Option<i32>.None;
```

变体通过 `EnumName.Variant(args)` 构造。有 payload 的变体使用 `{ field: Type, }` 语法。

来源：`lib/src/core/option.an`、`tests/basic/std/core/option.an`

## 赋值与拷贝语义

YIAN 的赋值、传参与返回均为**按位复制**（bitwise copy）语义：所有类型的值都可以直接赋值，不存在"简单类型 / 非简单类型"之分，也无需显式复制调用。

```yian
struct Point {
    x: i32,
    y: i32,
}

let a: Point = Point(1, 2);
let b: Point = a;   // 直接按位复制
```

堆分配类型（`Vec<T>`、`String` 等）的按位复制会共享底层缓冲；需要独立副本时由标准库提供显式深拷贝方法（如 `Vec::to_vec`）。具体的资源有效性和运行时检查不属于赋值规则本身。

（历史注记：早期版本区分简单/非简单类型，要求对非简单类型在赋值前显式复制（move/clone 调用）；该机制已于 2026-08-23 移除。）
