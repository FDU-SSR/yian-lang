# 15 赋值语义

Yian 区分**简单类型**和**非简单类型**，赋值行为不同。

## 简单类型 = 逐位拷贝

```yian
let a: i32 = 10;
let b: i32 = a;             // 逐位拷贝 — 来源: tests/assign/simple.an
assert a == 10;             // a 仍然有效
```

简单类型列表见 [§02 类型系统 — 简单类型 vs 非简单类型](02.types.md#简单类型-vs-非简单类型)。

## 非简单类型的赋值约束

`Vec`、`String`、`HashMap` 等堆分配类型**不能**直接赋值：

```yian
let v1: Vec<i32> = Vec<i32>.new();
v1.push(42);
let v2: Vec<i32> = v1;      // 编译错误 — 来源: tests/assign/direct_assign_err.err.an
```

错误信息：`type 'Vec<i32>' does not support simple assignment; use .clone() or .move()`

## `.clone()` — 深拷贝

```yian
let v1: Vec<i32> = Vec<i32>.new();
v1.push(42);
let v2: Vec<i32> = v1.clone();  // 深拷贝 — 来源: tests/assign/move_clone.an
assert v2[0] == 42;
assert v1.is_valid();           // v1 仍然可用
```

## `.move()` — 所有权转移

```yian
let v1: Vec<i32> = Vec<i32>.new();
v1.push(42);
let v2: Vec<i32> = v1.move();   // 所有权转移 — 来源: tests/assign/move_clone.an
// v1 不再可用: v1.is_valid() == false
```

## `Move` Trait 方法

```yian
pub trait Move {
    fn move() -> Self {         // 默认: bitcopy + invalidate
        let res = bitcopy(*self);
        self.invalidate();
        res
    }
    fn invalidate();            // 标记为失效
    fn is_valid() -> bool;      // 查询是否有效
    fn validity_assert() {      // 若失效则 panic
        if !self.is_valid() { panic("use of invalidated value"); }
    }
}
```

来源：`lib/core/move.an`

## 简单类型的 Move 优化

对于简单类型，编译器在 lowering 阶段直接优化 `move()`/`clone()`/`invalidate()`/`is_valid()`：

- `e.move()` → `e`（恒等）
- `e.clone()` → `e`（恒等）
- `e.invalidate()` → `Nop`（空操作）
- `e.is_valid()` → `true`（字面量）

因此简单类型无需 `Move`/`Clone` trait 的显式 impl。

## 允许的赋值源

非简单类型的目标可以通过以下源安全赋值（`check_simple_assign_source`）：

| 源类型          | 示例                                |
| --------------- | ----------------------------------- |
| 字面量          | `let s: String = "hello";`          |
| 构造表达式      | `let v: Vec<i32> = Vec<i32>.new();` |
| 函数/方法调用   | `let v: Vec<i32> = make_vec();`     |
| `bitcopy(expr)` | `let v: Vec<i32> = bitcopy(other);` |

函数调用的返回值是"新创造的值"，不存在所有权冲突。

来源：`tests/assign/construction.an`、`tests/assign/functions.an`

## 传参与赋值约束

非简单类型的值作为函数参数、struct/enum 构造字段、数组/元组元素、`return` 值、`break` 值时，同样受赋值约束：

```yian
fn consume(v: Vec<i32>) { }
let v: Vec<i32> = Vec<i32>.new();
consume(v);                 // 编译错误 — 来源: tests/assign/functions_err.err.an
consume(v.move());          // OK
```

来源：`tests/assign/functions_err.err.an`、`tests/assign/construction_err.err.an`

## `@BitCopy` 类型

`@BitCopy` 注解使自定义类型支持直接逐位赋值：

```yian
@BitCopy
struct Point {
    x: i32,
    y: i32,
}
let p1: Point = Point(1, 2);
let p2: Point = p1;             // OK: 逐位拷贝 — 来源: tests/assign/bitcopy_struct.an
```

详见 [§11 — `@BitCopy` 注解](11.structs_enums.md#bitcopy-注解)。

## `bitcopy()` 内置函数

```yian
let v1: Vec<i32> = Vec<i32>.new();
let v2: Vec<i32> = bitcopy(v1); // 强制逐位拷贝（慎用）
```

`bitcopy` 跳过所有权检查，直接复制字节。适用于性能关键路径，但应确保源值在被拷贝后不再使用。
