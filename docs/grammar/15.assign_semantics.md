# 15 赋值与显式内存管理语义

Yian 对所有可存储值采用统一的浅复制语义。赋值、传参、返回、聚合值构造以及表达式分支合流都会复制值本身；这些操作不会使来源失效，也不会隐式分配、深拷贝或释放资源。

“按位复制”描述可观察的浅复制效果，不要求编译器复制填充字节，也不限定必须生成逐字节复制指令。

## 普通复制

```yian
struct Buffer {
    data: u8*,
    len: u64,
}

let data: u8* = dyn[4] u8;
let first = Buffer(data, 4);
let second = first;

assert first.len == 4 && second.len == 4;
assert first.data == second.data; // 指针目标共享
```

结构体、枚举、数组、元组、指针、切片和标准库容器都遵循同一规则。复制聚合值时，每个成员也按其值表示进行浅复制。来源在复制后仍可读取；自赋值同样合法。

覆盖一个已有变量或字段只写入新值，不会自动清理旧值原先持有的资源。离开块作用域或函数返回时，编译器也不会自动调用 `Drop`。

## 传参、返回与构造

按值参数和返回值都使用普通复制：

```yian
struct Pair { left: i32, right: i32 }

fn pass(value: Pair) -> Pair {
    value
}

let source = Pair(1, 2);
let result = pass(source);
assert source.left == 1;
assert result.right == 2;
```

同一规则适用于方法参数、函数值和闭包调用、显式及尾表达式返回、struct/enum 构造、数组与元组元素，以及 `if`、`match`、块表达式和带值 `break` 的结果。

类型兼容、赋值目标必须是左值、可见性和确定赋值检查仍然生效。统一复制语义不允许读取未初始化值。

## 容器复制与别名

`Vec<T>`、`String`、`HashMap<K, V>` 等拥有型容器的普通赋值只复制指针、长度、容量等描述字段。两个副本的描述字段彼此独立，但底层存储相同：

```yian
let first = Vec<i32>.new();
first.push(10);
let second = first;

assert first.len() == 1 && second.len() == 1;
assert &first[0] == &second[0];
```

一个副本扩容、重新分配或释放底层存储后，其他副本及此前取得的元素指针可能失效。语言不会自动同步这些副本，也不会替程序员选择释放责任；程序员必须协调别名的修改和清理。不要分别对共享同一资源的多个浅副本执行清理。

## 显式 `Clone`

需要独立数据时，显式调用标准库 `Clone` trait：

```yian
let first = String.from(&"hello");
let second = first.clone();
second.push('!');

assert first == "hello";
assert second == "hello!";

first.drop();
second.drop();
```

`String.clone()` 分配独立字符存储，`Vec<T>.clone()` 分配独立缓冲区并调用每个元素的 `Clone`。数组、元组、`Option` 和 `Result` 按元素或当前有效分支克隆。`HashMap<K, V>.clone()` 与 `HashSet<T>.clone()` 创建等容量新表，并深克隆每一对键值（键与值的类型需实现 `Clone`）。用户定义的结构体和枚举不会自动派生 `Clone`，复制深度由其实现决定。

整数、浮点数、布尔值、字符和 `void` 有显式的标准库 `Clone` 实现。原始指针、切片和 `str` 视图没有默认 `Clone`；复制这些视图直接使用普通赋值，需要拥有型数据时分别使用目标类型提供的构造或转换接口。指针自身同样没有 `Clone` 实现；对指针调用 `clone()` 时，方法查找沿常规 deref 链自动解引用并克隆指针指向的值，即 `ptr.clone()` 等价于 `(*ptr).clone()`，返回克隆出的值。

## `del` 与 `Drop`

`del p` 释放 `p` 指向的分配块。它不会调用对象或成员的 `drop()`，也不会递归释放成员指针指向的存储：

```yian
struct Outer { member: i32* }

let member: i32* = dyn i32(41);
let outer: Outer* = dyn Outer(member);
let saved = outer.member;

del outer;
*saved += 1;
assert *saved == 42;
del saved;
```

`.drop()` 是普通的显式方法调用，按照该类型的 `Drop` 实现清理资源，可以递归清理有效成员。例如 `Vec.drop()` 先清理当前有效元素，再释放缓冲区。语言不会在 `del`、赋值、覆盖或作用域退出时自动插入这一调用。

释放对象后，程序可以把自身字段重置为空状态，以防对同一描述对象重复清理；这一修改不会同步到之前产生的浅副本。

## 已移除的旧接口

`Move` trait、`.move()`、`bitcopy()` 内建和 `@BitCopy` 注解已经移除。普通赋值本身就是统一的浅复制操作，不再需要绕过复制限制的特殊接口。
