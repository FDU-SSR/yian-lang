# 08 表达式

## 字面量

```yian
42              // IntLiteral
3.14            // FloatLiteral
'A'             // CharLiteral
"hello"         // StrLiteral
true            // BoolLiteral
```

详见 [§01 词法](01.lexicon.md)。

## 变量引用

```yian
let x: i32 = 42;
let y: i32 = x;         // x 作为 rvalue
x = 10;                 // x 作为 lvalue
```

## 算术表达式

```yian
let a: i32 = 10 + 5;    // 15
let b: i32 = 10 - 5;    // 5
let c: i32 = 10 * 5;    // 50
let d: i32 = 10 / 3;    // 3 (整数除法)
let e: i32 = 10 % 3;    // 1 (取模)
```

来源：`tests/op/`

## 比较表达式

```yian
let eq: bool = a == b;

let gt: bool = a > b;
let le: bool = a <= b;

```

来源：`tests/std/core/ops/cmp.an`

## 逻辑表达式

```yian
let a: bool = true;
let b: bool = false;
let and: bool = a && b;     // false
let or: bool = a || b;      // true
let not: bool = !a;         // false
```

`&&` 和 `||` 是短路求值的。

## 位运算

```yian
let a: i32 = 0x0F;          // 00001111
let b: i32 = 0x3C;          // 00111100
let and: i32 = a & b;       // 00001100
let or: i32 = a | b;        // 00111111
let xor: i32 = a ^ b;       // 00110011
let not: i32 = ~a;          // 11110000
let shl: i32 = a << 2;      // 00111100
let shr: i32 = b >> 2;      // 00001111
```

来源：`tests/std/core/ops/bitwise.an`

## 范围表达式 `a..b`

```yian

```

## 编译期条件 `comptime if`

`comptime if` 要求条件能够在中端编译期求值，并且必须带有 `else` 分支。条件成立时只保留前一个分支，否则只保留后一个分支；未选择的分支在生成 CFG 前被移除。

```yian
let slice: i32[] = comptime if IS_RAW_MODE {
    source
} else {
    source
};
```

当前支持布尔值、整数值、`sizeof`、已实例化常量泛型值、整数/布尔转换，以及无副作用的整数、布尔运算。运行期变量、函数调用和其他有副作用的表达式不能作为条件。

## 关键字指令

```yian

```

