# 08 表达式

## 字面量

```yian
42              // IntLiteral
3.14            // FloatLiteral
'A'             // CharLiteral
"hello"         // StrLiteral
true            // BoolLiteral
```

详见 [§01 词法](01.lexicon.md)。

## 变量引用

```yian

```

## 逻辑表达式

```yian
let a: bool = true;
let b: bool = false;
let and: bool = a && b;     // false
let or: bool = a || b;      // true
let not: bool = !a;         // false
```

`&&` 和 `||` 是短路求值的。

## 类型构造

```yian
// Struct positional arguments.
let p: Point<i32> = Point<i32>(1, 2);

// Struct named arguments.
let q: Point<i32> = Point<i32>(x=1, y=2);

// Enum variant.
let opt: Option<i32> = Option<i32>.Some(42);
let none: Option<i32> = Option<i32>.None;

// Source: tests/basic/std/core/option.an.
```

类型名后带单个参数也可表示显式类型转换。布尔值不能显式转换为整数，例如 `i32(true)` 会报类型错误；
编译期表达式遵循相同规则。

## 数组重复表达式

`[value; count]` 创建长度为编译期常量 `count` 的数组，并把一次求值所得的 `value`
按浅复制语义放入每个元素。`count` 也可以是实例化后的常量泛型参数。

```yian
let zeros: i32[4] = [0; 4];
```

来源：`tests/basic/control_flow/for.an`、`tests/basic/pointer/array.an`

## 指针与引用协调

需要具体类型引用的上下文可接收同类型的 `T*` 或 `T[]`；fat 模式在实际访问时检查指针的边界与
生命周期。fat 模式支持 `T*` 到 `T[]` 的隐式转换；raw 模式的 `T*` 不携带长度，因此不能隐式
转换为 `T[]`。`T&` 不会隐式转换回 `T*`。

## 后缀错误传播 `?`

`value?` 提取成功载荷，失败时通过残差转换提前返回当前函数、方法或闭包。
它要求操作数实现 `Try`，返回类型实现对应的 `FromResidual`。标准库提供 Option 与 Result 支持：
值形式产生载荷值，引用形式产生载荷引用，例如 `(&result)?`。
错误路径与普通 `return` 一样展开活动的 `defer`；`?` 不能出现在可调用体之外。
具体转换规则见[标准库 Try 接口](14.standard_library.md#coretry--错误传播)。

## 编译期条件 `comptime if`

`comptime if` 要求条件能够在类型检查过程中求值为布尔值，并且必须带有 `else` 分支。编译器只对选中的分支进行类型检查和 HIR lowering；未选中的分支仍须满足词法、语法和受限操作权限规则，但不参与分支结果类型合并、匹配穷尽性和确定赋值检查。

```yian
let slice: i32[] = comptime if IS_RAW_MODE {
    source
} else {
    source
};
```

编译期求值支持标量常量、`@sizeof`、已实例化常量泛型值、`IS_RAW_MODE`、标量转换和无副作用的整数、浮点及布尔运算。运行期变量、普通函数调用和其他有副作用的表达式不能作为条件。

## 内置指令

所有编译器内置指令使用保留的 `@name` 命名空间。普通代码只能使用 `@sizeof` 和 `@panic`：

```yian
@sizeof(T)                  // Type size in bytes.
@panic("msg")               // Runtime error.
```

其余指令只允许在标准库中使用；用户代码调用会得到编译错误 `E501 restricted operation ... is only allowed in the standard library`：

```yian
@undef<T>()                 // Undefined value of type T.
@dangling<T>()              // Dangling pointer to T, using its nonzero alignment as the address.
@bitcast<T>(expr)           // Reinterpret a pointer/reference as pointer type T.
@alloc<T>(count)            // Allocate count elements of T on the heap.
@assume_init(expr)          // Assume expr is initialized.
@memcpy(dest, src, count)   // Copy bytes.
@runtime_fail("S001")       // Terminate with the specified error code.
@sqrt(x)                    // Square root.
@sys_read(fd, buf)          // Read.
@sys_write(fd, buf)         // Write.
@open(path, flags)          // Open a file.
@close(fd)                  // Close a file.
@slice_from_parts(ptr, len) // Construct a slice from pointer and length.
@slice_get_ptr(s)           // Slice data pointer.
@slice_get_len(s)           // Slice length.
@str_from_parts(ptr, len)   // Construct str from pointer and length.
@str_get_ptr(s)             // str data pointer.
@str_get_len(s)             // str byte length.
@argc()                     // Process argument count.
@arg_bytes(index)           // Process argument byte view.
@exit(code)                 // Exit immediately.
```

来源：`compiler/frontend/parse/ast.py`（`BuiltinKind`）、`compiler/analysis/passes/restricted_ops.py`、`compiler/analysis/lowering/call_dispatcher.py`
