# 08 表达式

## 字面量

```yian

3.14            // FloatLiteral
'A'             // CharLiteral
"hello"         // StrLiteral
true            // BoolLiteral
```

详见 [§01 词法](01.lexicon.md)。

## 变量引用

```yian

```

## 逻辑表达式

```yian
let a: bool = true;
let b: bool = false;
let and: bool = a && b;     // false
let or: bool = a || b;      // true
let not: bool = !a;         // false
```

`&&` 和 `||` 是短路求值的。

## 编译期条件 `comptime if`

`comptime if` 要求条件能够在中端编译期求值，并且必须带有 `else` 分支。条件成立时只保留前一个分支，否则只保留后一个分支；未选择的分支在生成 CFG 前被移除。

```yian
let slice: i32[] = comptime if IS_RAW_MODE {
    source
} else {
    source
};
```

支持布尔值、整数值、`@sizeof`、已实例化常量泛型值、`IS_RAW_MODE`、整数/布尔转换，以及无副作用的整数、布尔运算。运行期变量、函数调用和其他有副作用的表达式不能作为条件。

## 内置指令

所有编译器内置指令使用保留的 `@name` 命名空间。普通代码只能使用 `@sizeof` 和 `@panic`：

```yian
@sizeof(T)                  // 类型大小（字节）
@panic("msg")               // 运行时错误
```

其余指令只允许在标准库中使用；用户代码调用会得到编译错误 `E501 restricted operation ... is only allowed in the standard library`：

```yian
@Undef<T>()                 // 类型为 T 的未定义值
@dangling<T>()              // 指向 T 的悬垂指针，地址取 T 的对齐值（非零）
@bitcast<T>(expr)           // 把指针/引用重解释为指针类型 T
@alloc<T>(count)            // 分配 count 个 T 的堆块
@assume_init(expr)          // 假定 expr 已初始化
@memcpy(dest, src, count)   // 按字节复制
@runtime_fail("S001")       // 以指定编号的错误终止
@sqrt(x)                    // 平方根
@sys_read(fd, buf)          // 读取
@sys_write(fd, buf)         // 写入
@open(path, flags)          // 打开文件
@close(fd)                  // 关闭文件
@slice_from_parts(ptr, len) // 由指针和长度构造切片
@slice_get_ptr(s)           // 切片的数据指针
@slice_get_len(s)           // 切片的长度
@str_from_parts(ptr, len)   // 由指针和长度构造 str
@str_get_ptr(s)             // str 的数据指针
@str_get_len(s)             // str 的字节长度
@argc()                     // 进程参数数量
@arg_bytes(index)           // 进程参数字节视图
@exit(code)                 // 立即退出
```

来源：`compiler/frontend/parse/ast.py`（`BuiltinKind`）、`compiler/analysis/passes/restricted_ops.py`、`compiler/analysis/lowering/call_dispatcher.py`
