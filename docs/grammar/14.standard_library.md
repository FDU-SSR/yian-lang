# 14 标准库

Yian 标准库的包根是 `lib/`（清单 `lib/package.anx`），源码根是 `lib/src/`，通过 `std` 包名访问。

## `core::option` — `Option<T>`

可选值：`Some(val)` 或 `None`。

```yian
from std.core.option import Option;

let some: Option<i32> = Option<i32>.Some(42);
let none: Option<i32> = Option<i32>.None;

assert some.is_some();
assert !none.is_some();
assert *some.unwrap() == 42;
assert *some.unwrap_or(&0) == 42;
assert *none.unwrap_or(&0) == 0;
```

方法：`is_some()`, `is_none()`, `unwrap() -> T&`, `unwrap_or(default: T*) -> T&`, `take()`, `replace(val)`, `clone()`。

`unwrap`/`unwrap_or` 返回载荷的引用（不是指针），值上下文用 `*` 取载荷；`unwrap_or` 的 `default` 是指针参数，调用点写 `&值`。

来源：`lib/src/core/option.an`、`tests/basic/std/core/option.an`

## `core::result` — `Result<T, E>`

成功 `Ok(val)` 或错误 `Err(msg)`。

```yian
from std.core.result import Result;

let ok: Result<i32, u64> = Result<i32, u64>.Ok(42);
let err: Result<i32, u64> = Result<i32, u64>.Err(1);

assert ok.is_ok();
assert err.is_err();
assert *ok.unwrap() == 42;
assert *err.unwrap_err() == 1;
```

方法：`is_ok()`, `is_err()`, `unwrap() -> T&`, `unwrap_or(default: T*) -> T&`, `unwrap_err() -> E&`, `unwrap_or_err(default: E*) -> E&`, `ok()`, `err()`, `clone()`。

`unwrap` 系列返回载荷的引用；`unwrap_*` 的 `default` 是 `T*`/`E*`。

来源：`lib/src/core/result.an`、`tests/basic/std/core/result.an`

## `core::vec` — `Vec<T>`

动态数组。

```yian
from std.core.vec import Vec;

let v: Vec<i32> = Vec<i32>.new();
v.push(1);
v.push(2);
v.push(3);
assert v.len() == 3;
assert v[0] == 1;
assert *v.pop().unwrap() == 3;
```

方法：`new()`, `with_capacity(n)`, `push(v)`, `pop()`, `insert(i, v)`, `remove(i)`, `swap_remove(i)`, `extend(other)`, `extend_from_slice(s)`, `truncate(n)`, `clear()`, `reserve(n)`, `spare(n)`, `advance_len(n)`, `shrink_to_fit()`, `as_slice()`, `len()`（经 `Deref<T[]>`）, `capacity()`, `is_empty()`, `clone()`。

`Vec<T>` 的普通赋值是浅复制；`clone()` 只复制 Vec 自己管理的元素缓冲区，元素自己拥有的资源不递归复制。`clear()`、`truncate()` 和显式 `drop()` 只管理 Vec 自身的存储，不会调用元素的 `Drop`；需要释放元素资源时由调用者在元素仍可访问时显式处理。`pop()`、`remove()` 和 `swap_remove()` 返回元素，调用者可自行清理。

`extend()` 和 `extend_from_slice()` 通过 `@memcpy` 复制元素缓冲区，不做逐元素 `Clone`。

`new()` 与 `with_capacity(0)` 不分配堆块：容量为 0 时数据指针是 `@dangling<T>()`（地址取 `align_of::<T>()`，恒非零），可参与零长度的指针算术与传递，但不能解引用；首次 `push()` 或 `reserve()` 才分配缓冲区。

实现 `Index<u64, T&>`、`Deref<T[]>`、`Add<Vec<T>, Vec<T>>`、`PartialEq<Vec<T>>`、`From<T[]>`、`Into<Vec<T>>`、`Clone`、`Drop`。

来源：`lib/src/core/vec.an`、`tests/basic/std/core/vec/`

## `core::string` — `String`

可变 UTF-8 字符串。

```yian
from std.core.string import String;

let s: String = String.from(&"Hello");
s.push_str(" World");
s.push('!');
assert s == "Hello World!";
s += "!";
```

方法：`new()`, `with_capacity(n)`, `from(str*)`, `push_str(s)`, `push(c)`, `pop()`, `as_str()`, `as_slice()`, `len()`, `capacity()`, `is_empty()`, `trimmed()`, `clear()`, `reserve(n)`, `shrink_to_fit()`。

实现 `Deref<str>`、`From<str>`、`Add<String>`、`Add<str>`、`Add<char>`、`AddAssign<String>`、`AddAssign<str>`、`AddAssign<char>`、`PartialEq<String>`、`PartialEq<str>`、`Index<Range<u64>, str>`、`ToString`、`Clone`、`Drop`。

`String.clone()` 创建独立的字符存储；普通赋值仍是按位复制，可能共享底层缓冲区。

来源：`lib/src/core/string.an`、`tests/basic/std/core/string.an`

## `core::str` — `str`

不可变 UTF-8 字符串切片（内置类型）。

```yian
let s: str = "hello";
let bytes: u8[] = s.as_slice();
let chars: CharIter = s.chars();
```

函数/方法：`from_slice(bytes) -> Option<Self>`（带 UTF-8 验证）、`from_slice_unchecked(bytes) -> Self`、`as_slice()`, `chars()`, `char_indices()`, `is_char_boundary(i)`, `starts_with(prefix)`, `starts_with_char(c)`, `ends_with(suffix)`, `ends_with_char(c)`, `find(needle)`, `rfind(needle)`, `contains(needle)`, `contains_char(c)`, `find_char(c)`, `split(sep)`, `trim()`, `parse<T>()`。

`from_slice` 内部用 `is_valid_utf8` 校验，ASCII 段落按 8 字节整字跳过。`chars()` 返回 `CharIter`，其 `rev()` 返回 `RevCharIter`；两者按 UTF-8 序列解码字符，不提供 `len` 成员。`char_indices()` 返回产生 `(u64, char)` 的 `CharIndicesIter`。`split(sep)` 返回实现 `Iterator<str>` 的 `SplitIter`，`sep` 不能为空。

实现 `From<u8[]>`、`Into<u8[]>`、`PartialEq<str>`、`Index<Range<u64>, str>`、`Hash<Murmur3Hasher>`、`ToString`。

来源：`lib/src/core/str.an`、`tests/basic/std/core/str.an`

## `core::slice` — `T[]`

切片（视图类型）。

```yian
let arr: i32[5] = [1, 2, 3, 4, 5];
let s: i32[] = arr[1u64..4];
assert s.len() == 3;
assert **s.get(0).unwrap() == 2;
let v: Vec<i32> = s.to_vec();
```

函数/方法：`len()`, `get(i)`, `first()`, `last()`, `to_vec()`, `ptr()`（模块内部还有 `as_struct()`）。
模块不导出从裸地址构造切片的普通函数；受限的 `@slice_from_parts(ptr, len)` 仅供
经过可信来源检查的标准库内部代码使用。

实现 `IntoIterator`、`PartialEq`、`Index<u64, T*>`、`Index<Range<u64>, T[]>`。

来源：`lib/src/core/slice.an`、`tests/basic/std/core/slice.an`

## `core::clone` / `core::drop`

```yian
pub trait Clone { fn clone() -> Self; }
pub trait Drop { fn drop(); }
```

标量类型由标准库显式实现 `Clone`，但不提供空操作的 `Drop`；只有需要释放自身资源的类型才实现 `Drop`。`String`、`Vec<T>` 等类型按自身接口约定复制自己管理的缓冲区并清理自身资源，容器的 `Drop` 不会递归调用元素的 `Drop`。原始指针、切片和 `str` 没有默认 `Clone`。语言不会自动调用 `Drop`。

来源：`lib/src/core/clone.an`、`lib/src/core/drop.an`

## `collections::hash_map` / `hash_set`

```yian
let map: HashMap<MyKey, i64> = HashMap<MyKey, i64>.new();
map.insert(key, 100);
assert **map.get(&key).unwrap() == 100;

let set: HashSet<i64> = HashSet<i64>.new();
set.insert(42);
assert set.contains(&42);
```

哈希容器的 `clear()` 和删除只更新控制区，显式 `drop()` 释放自身表存储；这些操作都不会调用键或值的 `Drop`，元素资源由调用者显式清理。`HashMap<K, V>.clone()` 与 `HashSet<T>.clone()` 复制容器自己管理的控制区和桶存储，键值自己拥有的资源不递归复制；普通赋值仍是浅复制。

来源：`lib/src/collections/hash_map.an`、`lib/src/collections/hash_set.an`、`tests/basic/std/collections/`
