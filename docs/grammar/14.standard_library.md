# 14 标准库

Yian 标准库位于 `lib/` 目录，通过 `std::` 命名空间访问。

## `core::option` — `Option<T>`

可选值：`Some(val)` 或 `None`。

```yian
from std.core.option import Option;

let some: Option<i32> = Option<i32>.Some(42);
let none: Option<i32> = Option<i32>.None;

assert some.is_some();
assert !none.is_some();
assert *some.unwrap() == 42;
assert *some.unwrap_or(&0) == 42;
assert *none.unwrap_or(&0) == 0;
```

方法：`is_some()`, `is_none()`, `unwrap() -> T*`, `unwrap_or(default: T*) -> T*`, `take()`, `replace(val)`, `clone()`。

来源：`lib/core/option.an`、`tests/std/core/option.an`

## `core::result` — `Result<T, E>`

成功 `Ok(val)` 或错误 `Err(msg)`。

```yian
from std.core.result import Result;

let ok: Result<i32, u64> = Result<i32, u64>.Ok(42);
let err: Result<i32, u64> = Result<i32, u64>.Err(1);

assert ok.is_ok();
assert err.is_err();
assert *ok.unwrap() == 42;
assert *err.unwrap_err() == 1;
```

方法：`is_ok()`, `is_err()`, `unwrap()`, `unwrap_or()`, `unwrap_err()`, `unwrap_or_err()`, `ok()`, `err()`, `clone()`。

来源：`lib/core/result.an`、`tests/std/core/result.an`

## `core::vec` — `Vec<T>`

动态数组。

```yian
from std.core.vec import Vec;

let v: Vec<i32> = Vec<i32>.new();
v.push(1);
v.push(2);
v.push(3);
assert v.len() == 3;
assert v[0] == 1;
assert *v.pop().unwrap() == 3;
```

方法：`new()`, `with_capacity(n)`, `push(v)`, `pop()`, `insert(i, v)`, `remove(i)`, `swap_remove(i)`, `extend(other)`, `extend_from_slice(s)`, `truncate(n)`, `clear()`, `reserve(n)`, `shrink_to_fit()`, `as_slice()`, `len()`, `capacity()`, `is_empty()`, `clone()`。

`Vec<T>` 的普通赋值是浅复制；`clone()` 按元素调用 `Clone` 并创建独立缓冲区。`clear()`、`truncate()` 和显式 `drop()` 会清理当前容器中的有效元素，`pop()`、`remove()` 和 `swap_remove()` 返回的元素不会被容器提前清理。

实现 `Index<u64, T*>`、`Deref<T[]>`、`Add`、`PartialEq`。

来源：`lib/core/vec.an`、`tests/std/core/vec/`

## `core::string` — `String`

可变 UTF-8 字符串。

```yian
from std.core.string import String;

let s: String = String.from(&"Hello");
s.push_str(" World");
s.push('!');
assert s == "Hello World!";
s += "!";
```

方法：`new()`, `with_capacity(n)`, `from(str*)`, `push_str(s)`, `push(c)`, `pop()`, `as_str()`, `as_slice()`, `len()`, `capacity()`, `is_empty()`, `trimmed()`, `clear()`, `reserve(n)`, `shrink_to_fit()`。

实现 `Deref<str>`、`Add<String>`、`Add<str>`、`Add<char>`、`AddAssign<String>`、`AddAssign<str>`、`AddAssign<char>`、`PartialEq<String>`、`PartialEq<str>`、`Index<Range<u64>, str>`、`ToString`。

来源：`lib/core/string.an`、`tests/std/core/string.an`

## `core::str` — `str`

不可变 UTF-8 字符串切片（内置类型）。

```yian
let s: str = "hello";
let bytes: u8[] = s.as_slice();
let chars: CharIter = s.chars();
```

函数/方法：`from_slice(bytes) -> Option<Self>`（带 UTF-8 验证）、`from_slice_unchecked(bytes) -> Self`、`as_slice()`, `chars()`, `char_indices()`, `is_char_boundary(i)`, `starts_with(prefix)`, `contains_char(c)`, `trim()`, `parse<T>()`。

实现 `PartialEq<str>`、`Index<Range<u64>, str>`、`Hash`、`ToString`。

来源：`lib/core/str.an`、`tests/std/core/str.an`

## `core::slice` — `T[]`

切片（视图类型）。

```yian
let arr: i32[5] = [1, 2, 3, 4, 5];
let s: i32[] = arr[1u64..4];
assert s.len() == 3;
assert *s.get(0).unwrap() == 2;
let v: Vec<i32> = s.to_vec();
```

函数/方法：`len()`, `get(i)`, `first()`, `last()`, `to_vec()`, `as_struct()`, `ptr()`。Module-level: `from_raw_parts(ptr, len) -> T[]`。

实现 `IntoIterator`、`PartialEq`、`Index<u64, T*>`、`Index<Range<u64>, T[]>`。

来源：`lib/core/slice.an`、`tests/std/core/slice.an`

## `core::clone` / `core::drop`

```yian
pub trait Clone { fn clone() -> Self; }
pub trait Drop  { fn drop(); }
```

标量类型的 `Clone` 和 `Drop` 由标准库显式实现。`String`、`Vec<T>` 等类型按自身接口约定实现深克隆和资源清理。原始指针、切片和 `str` 没有默认 `Clone`。语言不会自动调用 `Drop`。

来源：`lib/core/clone.an`、`lib/core/drop.an`

## `collections::hash_map` / `hash_set`

```yian
let map: HashMap<MyKey, i64> = HashMap<MyKey, i64>.new();
map.insert(key, 100);
assert *map.get(&key).unwrap() == 100;

let set: HashSet<i64> = HashSet<i64>.new();
set.insert(42);
assert set.contains(&42);
```

哈希容器通过 `clear()` 和显式 `drop()` 清理有效元素与内部缓冲区。`HashMap<K, V>.clone()` 与 `HashSet<T>.clone()` 创建等容量新表并深克隆全部键值，副本之间互不影响。`insert` 遇到与已有键相等的传入键时直接丢弃该传入副本，不调用 `drop()`——传入副本可能只是调用方数据的浅复制，释放它会使容器中保留的键悬垂（同一变量重复插入即为释放后使用）；已有键原样保留，只清理容器内的旧值并写入新值。`HashSet.insert` 对重复值同样丢弃副本并返回 `false`。扩容只转移有效条目，不清理已经转入新缓冲区的键值。普通赋值仍为浅复制，多个副本共享内部存储，释放和扩容后的别名协调由程序员负责。

来源：`lib/collections/hash_map.an`、`lib/collections/hash_set.an`、`tests/std/collections/`
