# 12 Trait 与 Impl

## Trait 定义

```yian
pub trait Iterator<T> {
    fn next() -> Option<T>;
}
```

- trait 方法声明以 `;` 结尾（无 body）
- 可带泛型参数 `<T>`
- `pub` 控制外部可见性

来源：`lib/core/iter.an`、`lib/core/ops.an`

## Trait 默认方法

```yian
pub trait Move {
    fn move() -> Self {
        let res = bitcopy(*self);
        self.invalidate();
        res
    }
    fn invalidate();
    fn is_valid() -> bool;
}
```

- 有 body 的方法是**默认方法**，impl 可选择不覆盖
- 无 body 的方法是**header 方法**，impl 必须提供实现

来源：`lib/core/move.an`

## Impl 实现

```yian
impl<T> Clone for Vec<T> {
    pub fn clone() -> Self {
        return Self(data=self.data.clone());
    }
}
```

- `impl<generics> TraitName for TypeName { }` 语法
- 方法签名必须与 trait 声明匹配
- 编译器自动验证签名一致性（`compiler/analysis/ty/impl.py:__check_impl`）

来源：`tests/impl/`、`tests/trait/`

## Inherent Impl（无 trait 的方法）

```yian
impl<T> Vec<T> {
    pub fn push(value: T) { /* ... */ }
    pub fn len() -> u64 { /* ... */ }
}
```

直接为类型添加方法，无需 trait。

来源：`lib/core/vec.an`

## 条件 Impl

```yian
impl<T, const N: u64> Clone for T[N] if T: Clone {
    fn clone() -> Self { /* ... */ }
}
```

`if Type: Trait` 约束——仅在类型满足 trait bound 时 impl 生效。

来源：`lib/core/clone.an`、`lib/core/iter.an`（`IntoIterator` blanket impl）

## 静态方法

```yian
impl<T> Vec<T> {
    static pub fn new() -> Self { /* ... */ }
}
```

- `static fn` 不接收 `self`
- 调用方式：`Vec<i32>.new()` 或 `TypeName.method()`

## Self 类型

在 impl 块内，`Self` 指代当前实现的目标类型：

```yian
impl<T> Clone for Vec<T> {
    pub fn clone() -> Self {        // Self = Vec<T>
        return Self(data=self.data.clone());
    }
}
```

## 方法调用约定

- `self` 在方法体内是**指针**（`*Self`）
- 返回 `Self` 时使用 `*self` 解引用
- 调用 `.move()` 或 `.clone()` 时需要显式操作

```yian
impl String {
    pub fn as_str() -> str {
        self.validity_assert();
        str.from(&self.data.as_slice())
    }
}
```

来源：`lib/core/string.an`

## 可见性

- `pub` 方法可在模块外调用
- 无 `pub` 的方法仅限当前模块和 impl 块内使用
- `pub` trait 可在任何地方实现
