# 12 Trait 与 Impl

## Trait 定义

```yian
pub trait Iterator<T> {
    fn next() -> Option<T>;
}
```

- trait 方法声明以 `;` 结尾（无 body）
- 可带泛型参数 `<T>`
- `pub` 控制外部可见性

来源：`lib/src/core/iter.an`、`lib/src/core/ops.an`

## Trait 默认方法

trait 方法可以带默认实现，impl 块可以选择覆盖或不覆盖：

```yian
trait Shape {
    fn area() -> i32;

    // 有默认实现
    fn move_by(dx: i32, dy: i32) {
        print("Nothing to do\n");
    }
}
```

- 有 body 的方法是**默认方法**，impl 可选择不覆盖
- 无 body 的方法是**header 方法**，impl 必须提供实现

来源：`tests/basic/trait/default.an`

## Trait object

后缀引用语法 `Trait&` 在 `Trait` 是 trait 类型时表示 trait object；普通具体类型上的
`T&` 仍是常规引用。trait 名称必须带齐泛型实参，例如 `Compare<i32>&`。裸 trait 类型
是 unsized 类型，不能作为运行期变量、字段、数组元素、参数或返回值；这些位置使用 `Trait&`。

```yian
trait Measure {
    fn value() -> i32;
}

struct Counter { value: i32 }

impl Measure for Counter {
    fn value() -> i32 { return self.value; }
}

fn read(value: Measure&) -> i32 {
    value.value()
}

fn main() {
    let counter: Counter = Counter(value=42);
    let object: Measure& = &counter;
    assert read(object) == 42;
}
```

trait object 由指向具体值的 `T*` 或 `T&` 转换得到；具体类型必须实现完整的 trait 实例。
转换不分配或拥有具体值的存储，fat 模式保留数据引用的生命周期元数据，raw 模式使用裸
数据指针；两种模式都在对象中保存 vtable。fat 模式下的动态方法调用检查数据引用的有效性。
trait 类型不能直接用 `Trait*` 表示；取临时值的地址不能用于构造对象，trait object 之间的
upcast 也不受支持。

对象安全的实例方法不能有额外泛型参数，也不能在参数或返回类型（包括嵌套类型）中使用
`Self`。静态方法不通过 trait object 动态调用。`Self` 表示实现 trait 的具体类型，impl
实例化时由实现类型替换；trait 自身的名称仍解析为 trait 类型，因此 `Trait&` 可用于
trait 默认方法的签名，例如返回当前对象。

trait object 可以作为变量、字段、数组元素、参数和返回值存储及传递；方法调用通过 vtable
动态分派。动态调用只支持对象安全的实例方法。

## Impl 实现

```yian
impl Shape for Circle {
    fn area() -> i32 {
        return 3 * self.radius * self.radius;
    }
}
```

- `impl<generics> TraitName for TypeName { }` 语法
- 方法签名必须与 trait 声明匹配
- 编译器自动验证签名一致性（`compiler/analysis/ty/impl.py:__check_impl`）

来源：`tests/basic/impl/`、`tests/basic/trait/`

## Inherent Impl（无 trait 的方法）

```yian
impl<T> Vec<T> {
    pub fn push(value: T) { /* ... */ }
    pub fn len() -> u64 { /* ... */ }
}
```

直接为类型添加方法，无需 trait。

来源：`lib/src/core/vec.an`

## 条件 Impl

```yian
trait MyClone {
    fn my_clone() -> Self;
}

struct Wrapper<T> {
    value: T,
}

impl<T> MyClone for Wrapper<T> if T: MyClone {
    fn my_clone() -> Self {
        let v = self.value.my_clone();
        Wrapper(v)
    }
}
```

`if Type: Trait` 约束——仅在类型满足 trait bound 时 impl 生效。

来源：`tests/basic/impl/conditional.an`、`lib/src/core/iter.an`（`IntoIterator` blanket impl）

## 静态方法

```yian
impl<T> Vec<T> {
    static pub fn new() -> Self { /* ... */ }
}
```

- `static fn` 不接收 `self`
- 调用方式：`Vec<i32>.new()` 或 `TypeName.method()`

## Self 类型

在 impl 块内，`Self` 指代当前实现的目标类型：

```yian
impl<T> Vec<T> {
    static pub fn with_capacity(capacity: u64) -> Self {   // Self = Vec<T>
        return Self(raw_vec=RawVec<T>.with_capacity(capacity), len=0);
    }
}
```

## 方法调用约定

- `self` 在方法体内是**引用**（`Self&`）
- 返回 `Self` 时使用 `*self` 解引用

```yian
impl String {
    pub fn as_str() -> str {
        str.from_slice_unchecked(self.data.as_slice())
    }
}
```

来源：`lib/src/core/string.an`

## 可见性

- 模块级项（函数、类型、常量）只有带 `pub` 才能被其他模块导入
- 方法查找不检查 `pub`，带或不带 `pub` 的方法都可调用
- `pub` trait 可在任何地方实现
