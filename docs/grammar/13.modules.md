# 13 模块系统

## Import 语法

```yian
// Import by package name in package mode.
from myapp.utils.math import add;
from utils.strings import join;

// Standard-library import.
from std.core.drop import Drop;

// Import multiple symbols.
from std.core.ops import Add, Sub, Mul;

// With an alias.
from std.core.vec import Vec as MyVec;
```

- import 语句以 `;` 结尾
- 路径使用 `.` 分隔（`std.core.option`）

## 导入路径解析

### Package 模式（anx 项目）

通过 `anx build` 构建时，第一段路径是包名，编译器从 `package.anx` 和依赖中解析：

```text
from myapp.utils.math import add    →  myapp 包的 src/utils/math.an
from utils.strings import join      →  utils 依赖包的 src/strings.an
from std.core.io import eprint       →  lib/src/core/io.an（stdlib）
```

包名→根目录映射由 anx 自动生成 `pkg.json` 并传入 `--packages`。

### Standalone 模式（直接调用编译器）

不传 `--packages` 时，import 按相对路径解析。

## From-Import

```yian
from path.to.module import Item;
```

## `pub` 可见性

```yian
// lib/src/core/vec.an
pub struct Vec<T> { ... }       // Externally accessible.

impl<T> Vec<T> {
    pub fn push(value: T) { }
    fn internal_helper() { }
}
```

- `pub` 前缀使模块级项对外部模块可见（可被 `from ... import` 导入）
- 无 `pub` 的模块级项仅在定义模块内可见
- 方法查找不检查 `pub`

来源：`tests/package/errors/no_pub/app/`（导入非 `pub` 函数）、`tests/package/migrated/pierr/`（导入非 `pub` struct）；正向用例见 `tests/package/migrated/pimport/`

## 私有字段

```yian
pub struct Foo {
    pub x: i32,     // Externally readable/writable.
    y: i32,         // Readable/writable only within the module.
}
```

来源：`tests/package/migrated/pferr/`（访问私有字段）；正向用例见 `tests/package/migrated/pfield/`

## `std` 命名空间

编译器将 `from std.xxx` 映射到标准库的源码根 `lib/src/`：

```text
from std.core.option    → lib/src/core/option.an
from std.core.vec       → lib/src/core/vec.an
from std.collections.x  → lib/src/collections/x.an
from std.num.u64        → lib/src/num/u64.an
```

映射逻辑在 `python/yianc/analysis/passes/global_resolve.py:__build_std_lookup` 中。

## Prelude 自动注入

以下符号自动注入非 `lib/src/` 文件的编译上下文：

```yian
Option, Result, Vec, String, Range, Ordering, Clone, Ptr, Slice, Array, Never, print, println
```

无需显式 `import`。native 实现在 `yianc/src/analysis/resolution/imports.an`，Python 恢复编译器对应
`python/yianc/analysis/passes/prelude.py`。

native 编译器对非标准库模块显式导入上述符号给出 `W502` 警告；警告不阻止编译：

```text
warning[W502]: unnecessary import of 'Option': the prelude already provides it
--> src/main.an:1:29
    from std.core.option import Option;
                                ^^^^^^
```

使用别名（例如 `Vec as MyVec`）会建立不同的绑定，不产生该警告；标准库 `lib/src/` 内部不受此规则影响。

## 循环依赖

编译器在全局解析阶段检测类型之间的循环依赖：

```yian
// Error example; source: tests/basic/error/circular_dependency1.err.an.
struct A { b: B, }
struct B { a: A, }      // Compilation error: circular dependency.
```

使用指针可以打破循环：

```yian
struct A { b: B*, }     // OK: pointer types do not create circular dependencies.
struct B { a: A, }
```

来源：`tests/basic/error/circular_dependency3.an`
