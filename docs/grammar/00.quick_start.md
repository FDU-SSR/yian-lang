# 00 Quick Start

30 分钟内跑通 Yian 的核心语法。每个示例均可编译运行。

编译方式：
- **单文件**：`yianc lib/src <file>`
- **多文件项目**：使用 anx 包管理器（`anx build`）

## 1. Hello World

```yian
// hello.an
fn main() {
}
```

```bash
yianc lib/src hello.an && ./build/a.out
```

## 2. 变量与类型

```yian
fn main() {
    let x: i32 = 42;
    let y = x + 1;              // 类型推断
    let flag: bool = true;
    let c: char = 'A';
    assert y == 43;
}
```

来源：`tests/basic/array/assign.an`

## 3. 函数

```yian
fn add(a: i32, b: i32) -> i32 {
    return a + b;
}

fn main() {
    let result: i32 = add(1, 2);
    assert result == 3;
}
```

## 4. 控制流

```yian
fn main() {
    let x: i32 = 10;
    let kind: i32 = 0;

    if x > 0 {
        kind = 1;
    } elif x < 0 {
        kind = -1;
    } else {
        kind = 0;
    }
    assert kind == 1;
}
```

## 8. 枚举与 match

```yian
from std.core.option import Option;

fn main() {
    let opt: Option<i32> = Option<i32>.Some(42);

    let val: i32 = match opt {
        Some(v) => v,
        None => 0,
    };
    assert val == 42;           // -- 来源: tests/basic/std/core/option.an
}
```

## 9. Vec 动态数组

```yian
from std.core.vec import Vec;

fn main() {
    let v: Vec<i32> = Vec<i32>.new();

    v.push(20);
    v.push(30);
    assert v.len() == 3;        // -- 来源: tests/basic/std/core/vec/main.an
```

## 12. 运算符重载

```yian
from std.core.ops import Add;

struct Value<T> { pub value: T }

impl<T> Add<Value<T>, Value<T>> for Value<T> {
    fn add(rhs: Self) -> Self {
        return Self(self.value + rhs.value);
    }
}

fn main() {
    let a: Value<i32> = Value<i32>(10);
    let b: Value<i32> = Value<i32>(20);
    assert (a + b).value == 30;     // -- 来源: tests/basic/std/core/ops/arith.an
}
```

## 13. 模块导入

```yian
    assert s.len() == 0;

```

## 14. 包管理（anx）

对于多文件项目，使用 anx 包管理器：

```bash
# 创建项目
anx new myapp
cd myapp

# 创建库并配置依赖
anx new --lib mylib
# 编辑 myapp/package.anx，在 [dependencies] 中声明 mylib = { path = "../mylib" }

# 构建并运行
anx run
```

anx 项目使用包名导入替代相对路径：

```yian
from myapp.utils.math import add;      // 同包导入
from mylib.strings import join;        // 依赖包导入
from std.core.io import print;         // stdlib
```
