# 06 控制流

## `if` / `elif` / `else`

```yian
let x: i32 = 10;

if x > 0 {
    return 1;
} elif x < 0 {
    return -1;
} else {
    return 0;
}
```

- 条件必须是 `bool` 类型
- `elif` 可链式使用任意次
- 不使用 `else if` —— Yian 2026 语法统一为 `elif`

来源：`tests/control_flow/`

### `if` 作为表达式

```yian
let x: i32 = 10;
let sign: i32 = if x >= 0 { 1 } else { -1 };
```

- 每个分支必须返回值
- 无 `else` 的 `if` 表达式返回 `void`
- 来源：`tests/expr_oriented/`

## `loop`

无限循环，用 `break` 退出：

```yian
let i: i32 = 0;
loop {
    if i >= 10 { break; }
    i += 1;
}
```

### `loop` 作为表达式

```yian
let i: i32 = 0;
let result: i32 = loop {
    if i >= 5 { break i; }
    i += 1;
};
assert result == 5;
```

`break value` 使 `loop` 返回该值。来源：`tests/expr_oriented/`

## `while`

条件循环：

```yian
let i: i32 = 0;
while i < 10 {
    i += 1;
}
```

`while` 在 desugar 阶段被转换为 `loop { if !cond { break; } body; }`。

## `for`-`in`

遍历实现 `IntoIterator` 的类型：

```yian
// 遍历 range
let sum: i32 = 0;
for i in 0..10 {
    sum += i;
}
assert sum == 45;           // -- 来源: tests/control_flow/for.an

// 遍历数组
let arr: i32[3] = [1, 2, 3];
for elem in arr {
    // elem: i32*
}
```

### `for`-`in` 的 desugar

编译器将 `for item in iterable { body }` 转换为：

```yian
let %iter = iterable.into_iter();
loop {
    match %iter.next() {
        Some(item) => { body },
        None => { break },
    }
}
```

因此 `for`-`in` 可用于任何实现 `IntoIterator` 的类型：range、数组、切片、`Vec`、`HashMap` 等。

来源：`tests/control_flow/forin.an`、`tests/array/forin.an`

### 迭代 Vec 的所有权

```yian
let vec: Vec<i32> = Vec<i32>.new();
// 借引用迭代（不消耗 vec）
for x in &vec { /* x: i32* */ }
```

来源：`tests/std/core/vec/iter.an`

## `break` / `continue`

```yian
for i in 0..100 {
    if i % 2 == 0 { continue; }  // 跳过偶数 — 来源: tests/control_flow/continue_for.an
    if i > 10 { break; }         // 提前退出 — 来源: tests/control_flow/break_for.an
}
```

## `assert`

```yian
assert x > 0;                           // 简单断言
assert x > 0: "x must be positive";    // 带消息 — 来源: tests/control_flow/
```

失败时调用 `panic`，输出消息。

## 嵌套控制流

```yian
for i in 0..10 {
    if i % 2 == 0 { continue; }
    let j: i32 = 0;
    while j < i {
        j += 1;
    }
}
```

来源：`tests/control_flow/nested.an`

## `panic`

```yian
panic("unreachable");
```

类型为 `never`，可用于任何期望值的位置：

```yian
fn fail() -> i32 {
    panic("not implemented");   // 不需要 return
}
```

## `delete`

```yian
let p: i32* = ...;
del p;                          // 释放 p 指向的内存
```

来源：`tests/dyn/`
