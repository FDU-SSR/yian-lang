# 05 方法

方法是与类型关联的函数，通过 `impl` 块定义。

## Inherent Impl

直接为类型添加方法（不关联 trait）：

```yian
struct Counter {
    count: i32,
}

impl Counter {
    pub fn inc() {
        self.count += 1;
    }

    pub fn value() -> i32 {
        return self.count;
    }
}
```

调用：

```yian
let c: Counter = Counter(0);
c.inc();
c.inc();
assert c.value() == 2;
```

来源：`tests/impl/`

## `self` 的含义

在方法体内，`self` 是 `Self&`（对接收者的引用）：

```yian
impl Counter {
    pub fn value() -> i32 {
        return self.count;       // self: Counter&, 自动解引用
    }
}
```

- 读取字段：`self.field`（编译器自动解引用 `(*self).field`）
- 修改字段：`self.field = value`（通过引用写入）
- 返回 `Self`：`*self`（解引用得到值）
- `del self`：`delete` 的目标可以是 `T*` 或 `T&`；`self` 的类型是 `Self&`。

## 静态方法

使用 `static fn` 声明，不接收 `self`：

```yian
impl<T> Vec<T> {
    static pub fn new() -> Self {
        return Self(data=RawVec<T>.new(), len=0);
    }
}

let v: Vec<i32> = Vec<i32>.new();   // 通过类型调用
```

来源：`lib/core/vec.an`

## Trait 方法实现

```yian
trait Shape {
    fn area() -> i32;
}

impl Shape for Circle {
    fn area() -> i32 {
        return 3 * self.radius * self.radius;
    }
}
```

详见 [§12 Trait 与 Impl](12.traits_impls.md)。

## `pub` 可见性

```yian
impl<T> Vec<T> {
    pub fn push(value: T) { }   // 外部可调用
    fn helper() { }             // 仅模块内可见
}
```

无 `pub` 的方法不能在模块外部调用。

## 方法调用与 Deref

编译器在方法查找时自动沿 `Deref` 链搜索：

```yian
let s: String = String.from(&"hello");
let len: u64 = s.len();         // String 无 len()，但 Deref<str> → 找到 str 的方法
```

来源：`lib/core/string.an`（`Deref<str>`）

## 示例：完整的 impl 块

来源 `lib/core/option.an`：

```yian
impl<T> Option<T> {
    pub fn is_some() -> bool {
        match self {
            None => false,
            Some => true,
        }
    }

    pub fn unwrap() -> T* {
        match self {
            None => panic("Called unwrap on a None value"),
            Some(val) => val,
        }
    }

    pub fn take() -> Option<T> {
        match self {
            None => Option<T>.None,
            Some(val) => {
                let out = *val;
                *self = Option<T>.None;
                Option<T>.Some(out)
            },
        }
    }
}
```
