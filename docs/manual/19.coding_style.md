# 19 编码规范

## Python

### 文件头

```python
"""模块描述。"""

from __future__ import annotations
```

每个 `.py` 文件以 docstring 开头，紧跟 `from __future__ import annotations`。所有类型标注不再需要引号。

### Import 顺序

1. `from __future__ import annotations`
2. 标准库 import
3. 第三方库 import
4. 项目 import（`from compiler.xxx import yyy`）

```python
from __future__ import annotations

import sys
from pathlib import Path

from compiler.analysis.error import AnalysisError
from compiler.frontend.lex.position import SrcSpan
```

### TYPE_CHECKING

仅用于类型标注的 import 放在 `TYPE_CHECKING` 块中：

```python
from typing import TYPE_CHECKING

if TYPE_CHECKING:
    from collections.abc import Callable, Iterator
    from compiler.frontend.lex.position import SrcSpan
```

### 禁止事项

- 不使用 `Any`、`object` 类型
- 不使用 `hasattr()`
- `import` 不可放在函数体内——必须在文件顶部
- 不使用 `Optional[...]`，用 `| None`

### 命名

| 类别      | 风格               | 示例                                |
| --------- | ------------------ | ----------------------------------- |
| 类        | `PascalCase`       | `ExprChecker`, `TypeCtx`            |
| 函数/方法 | `snake_case`       | `handle_call`, `check_block`        |
| 私有成员  | `__` 双下划线前缀  | `__type_ctx`, `__handle_named_call` |
| 常量      | `UPPER_SNAKE_CASE` | `BUILTIN_NAMES`, `SEP_COMMA`        |
| 变量      | `snake_case`       | `type_id`, `src_files`              |
| 模块      | `snake_case`       | `expr_checker.py`, `type_ops.py`    |

私有成员使用双下划线 `__` 前缀，**不要**使用单下划线 `_`。

模块级别的私有函数也用双下划线。注意：在 class 内部引用模块级双下划线函数时，Python 会做 name mangling——此时应改用 lambda 或将辅助逻辑内联。

### 类型标注

```python
# 参数和返回值必须标注
def coerce(self, expr: HIR.Expr, expected: int) -> HIR.Expr:

# 使用 | None，不用 Optional
def lookup(self, name: str) -> Symbol | None:

# 使用 list[T], dict[K, V], tuple[A, B]，不用 List, Dict, Tuple
def collect(self) -> list[Token]:

# TypeAlias 用于联合类型
Expr: TypeAlias = Binary | Unary | Call | ...
```

### Dataclass

AST 节点、IR 节点、类型表示均使用 `@dataclass`：

```python
@dataclass
class VarDecl:
    span: SrcSpan
    name: Identifier
    var_type: ASTType | None
    init_expr: Expr | None
```

- 必需字段在前，有默认值的字段在后
- 定义 `__repr__` 用于可读输出（非 `__str__`）

### Match 语句

优先使用 `match`/`case` 而非 `if`/`elif` 链进行节点类型分发：

```python
match expr:
    case AST.Binary():
        return self.__handle_binary(expr)
    case AST.Call():
        return self.__handle_call(expr)
    case _:
        raise AnalysisError(f"unhandled: {type(expr).__name__}")
```

`match` 必须穷尽匹配: 要么列出所有可能的类型，要么使用 `case _` 捕获剩余情况。

### 错误处理

- 用户可见错误：`AnalysisError/ParseError/CodegenError(message, span)` — 带 `SrcSpan` 定位源码
- 内部断言：`assert` 用于 `isinstance` 后的类型收窄
- 致命错误：`CompilerError(message)` — 编译器内部错误

### 类结构

1. `__init__` — 依赖注入，存储为私有属性
2. Public 方法 — 按逻辑分组，组间用 `# ── group name ──` 分隔
3. Private 方法 — `__` 前缀
4. Handler map 模式：`dict[type, Callable]` 替代长 match 链

```python
class ExprChecker:
    def __init__(self, ctx: SemCtx):
        self.__ctx = ctx
        self.__call_dispatcher = CallDispatcher(ctx, self)

    # ── public ────────────────────────────────────────────────────────

    def value(self, expr: AST.Expr) -> HIR.Expr:
        ...

    # ── handlers ──────────────────────────────────────────────────────

    def __handle_binary(self, node: AST.Binary) -> HIR.Expr:
        ...
```

### Docstring

```python
def build_assign(self, ...) -> HIR.Binary:
    """Build a HIR.Binary(Assign) with full validation.

    1. Verify target is a place expression.
    2. Coerce value to target's type.
    3. Enforce assignment constraint.
    4. Return the HIR assignment node.
    """
```

- `"""triple-quoted"""`，类与 public 方法必须有
- 简短一行即可；复杂逻辑用多行概述步骤

### 注释

- 稀疏原则——代码应通过命名和结构自解释
- 注释解释"为什么"，不解释"做什么"

## Yian

### 文件头

```yian
// 模块描述
//
// Expected output: 0    (测试文件)
```

### 命名

| 类别              | 风格               | 示例                             |
| ----------------- | ------------------ | -------------------------------- |
| struct/enum/trait | `PascalCase`       | `Vec`, `HashMap`, `IntoIterator` |
| 函数/方法         | `snake_case`       | `push`, `is_empty`, `into_iter`  |
| 变量              | `snake_case`       | `raw_vec`, `src_files`           |
| 常量泛型          | `UPPER_SNAKE_CASE` | `const N: u64`                   |

### Impl 结构

```yian
// =============================================================================
// Construction
// =============================================================================

impl<T> Vec<T> {
    static pub fn new() -> Self { ... }
    static pub fn with_capacity(capacity: u64) -> Self { ... }
}

// =============================================================================
// Mutation
// =============================================================================

impl<T> Vec<T> {
    pub fn push(value: T) { ... }
    pub fn pop() -> Option<T> { ... }
}
```

- 同一类型的多个 `impl` 块按功能分组（构造 / 查询 / 修改 / trait impl）
- 每组用 `// ====` 分隔注释
- `pub` 方法在前，私有方法在后

### 注释

```yian
// 单行注释

// =============================================================================
```

### 资源状态守卫

需要防止对已关闭或已释放的同一描述对象重复操作时，使用与资源领域直接对应的状态，例如 `File.fd == -2` 或 `RawVec.cap == 0`。资源清理后同步重置字段。这类守卫只保护当前描述对象，不会自动更新共享底层资源的浅副本。
