# 01 编译管线概览

## 管线图

```text
.an 源文件
  │
  ▼
┌──────────────────────────┐
│ Lexer (lex/lexer.py)     │  字符流 → Token 列表
│ - CharStream 逐字符扫描   │
│ - 空白跳过, 不产生 token  │
│ - 空白敏感性上下文分发     │
└──────────────────────────┘
  │  list[Token]
  ▼
┌──────────────────────────┐
│ Parser (parse/parser.py) │  Token 列表 → AST Program
│ - 递归下降, Pratt 表达式  │
│ - 顶层声明 + 表达式       │
└──────────────────────────┘
  │  AST.Program
  ▼
┌──────────────────────────┐
│ Desugar (desugar.py)     │  AST → AST (语法糖展开)
│ - for→into_iter+loop     │
│ - while→loop+if break    │
│ - assert→if+panic        │
│ - a..b→Range(a,b)        │
│ - elif→嵌套 if           │
└──────────────────────────┘
  │  AST.Program
  ▼
┌──────────────────────────┐
│ GlobalResolve             │  跨文件符号解析
│ (global_resolve.py)      │  - import 路径映射
│                          │  - 符号注册到 TypeCtx
│                          │  - 类型定义解析
│                          │  - Prelude 自动注入
└──────────────────────────┘
  │  UnitData (AST + symbol_ctx)
  ▼
┌──────────────────────────┐
│ TypeCheck (type_check.py)│  AST → HIR (类型检查)
│ - Worklist 从 main() 出发 │  - ExprChecker: AST→HIR
│ - 按需入队可达 def        │  - OpBuilder: 运算符 lowering
│                          │  - CallDispatcher: 方法/函数调用
│                          │  - assign_check: 赋值约束
└──────────────────────────┘
  │  DefPoint (HIR body + type_id)
  ▼
┌──────────────────────────┐
│ CfgTranslator             │  HIR → CFG IR
│ (cfg/translator.py)      │  - CfgBuilder: 单函数翻译
│                          │  - SSA 构造, basic block
│                          │  - 控制流结构化
└──────────────────────────┘
  │  CFG Function
  ▼
┌──────────────────────────┐
│ LLTranslator              │  CFG IR → LLVM IR
│ (llvm/translator.py)     │  - LLBuilder: 指令翻译
│                          │  - LLTypeCtx: 类型映射
│                          │  - Intrinsic 声明
└──────────────────────────┘
  │  llvmlite IR Module
  ▼
┌──────────────────────────┐
│ Emitter (llvm/emit.py)   │  LLVM IR → 目标文件
│ - ll/bc/obj/asm/exe      │  - clang 链接 (exe)
└──────────────────────────┘
  │
  ▼
build/a.out (或其他目标)
```

## main() 函数

`compiler/main.py:main()` 串联全部阶段：

```python
def main(argv=None) -> int:
    args = parse_cli(argv)          # 1. 解析 CLI 参数
    CompilerLog.init(...)           # 2. 初始化日志
    src_files = collect_an_files()  # 3. 收集 .an 文件
    token_lists = __lex(src_files)  # 4. Lex
    programs = __parse(token_lists) # 5. Parse
    programs = __desugar(programs)  # 6. Desugar
    inject_prelude(...)             # 7. Prelude 注入
    unit_datas = ...               # 8. 构建 UnitData
    type_ctx = TypeCtx()           # 9. 创建类型上下文
    GlobalResolve(...).run()       # 10. 全局符号解析
    TypeCheck(...).run()           # 11. 类型检查 → HIR
    def_points = ...               # 12. 导出 DefPoint
    cfg_functions = __cfg(...)     # 13. HIR → CFG IR
    llvm_module = __llvm_codegen() # 14. CFG → LLVM IR
    Emitter().emit_module(...)     # 15. 输出目标文件
```

## 关键数据结构

| 阶段 | 输入 | 输出 |
|------|------|------|
| Lex | `CharStream` | `list[Token]` |
| Parse | `list[Token]` | `AST.Program` |
| Desugar | `AST.Program` | `AST.Program` |
| Resolve | `UnitData` × N | 注册到 `TypeCtx` |
| TypeCheck | `UnitData` → `DefPoint` | `HIR.Block` body |
| CFG | `DefPoint` | `CFG_IR.Function` |
| LLVM | `CFG_IR.Function` | `ir.Module` |
| Emit | `ir.Module` | 目标文件 |

## 中间产物

所有中间产物写入 `build/`：

| 文件 | 阶段 | 说明 |
|------|------|------|
| `build/tokens.txt` | Lex 后 | 全文 token 列表 |
| `build/ast.txt` | Parse 后 | AST 树形 dump |
| `build/hir.txt` | TypeCheck 后 | HIR bundle dump |
| `build/cfg.txt` | CFG 后 | 各函数 CFG dump |
| `build/ir.ll` | LLVM 后 | LLVM IR 文本 |
| `build/compile.log` | 全流程 | 日志消息 |
| `build/a.out` | Emit | 可执行文件 (exe) |
