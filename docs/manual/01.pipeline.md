# 01 编译管线概览

## 管线图

```text
.an 源文件
  │
  ▼
┌──────────────────────────┐
│ Lexer (lex/lexer.py)     │  字符流 → Token 列表

  ▼

│ Parser (parse/parser.py) │  Token 列表 → AST Program
│ - 递归下降, Pratt 表达式  │

  │  AST.Program
  ▼
┌──────────────────────────┐
│ Desugar (desugar.py)     │  AST → AST (语法糖展开)

  │  AST.Program
  ▼
┌──────────────────────────┐
│ RestrictedOpCheck        │  检查受限底层操作

  │  AST.Program
  ▼
┌──────────────────────────┐

└──────────────────────────┘
  │  UnitData (AST + symbol_ctx)
  ▼
┌──────────────────────────┐

└──────────────────────────┘
  │
  ▼

  ▼

  ▼
```

## main() 函数

`compiler/main.py:main()` 串联全部阶段：

```python
def main(argv=None) -> int:
    args = parse_cli(argv)              # 1. 解析 CLI 参数
    CompilerLog.init(...)               # 2. 初始化日志
    src_files = collect_an_files(...)   # 3. 收集 .an 文件
    token_lists = __lex(src_files)      # 4. Lex
    programs = __parse(token_lists)     # 5. Parse
    programs = __desugar(programs)      # 6. Desugar
    unit_datas = ...                    # 7. 构建 UnitData
    source_trust = build_source_trust() # 8. 标注标准库 / 受限操作权限
    inject_prelude(unit_datas.values()) # 9. Prelude 注入
    check_restricted_ops(...)           # 10. 受限操作检查
    type_ctx = TypeCtx(raw_pointers=…)  # 11. 创建类型上下文
    ctx = SemCtx(type_ctx, ...)         # 12. 中端共享上下文
    GlobalResolve(ctx).run()            # 13. 全局符号解析
    type_ctx.finalize()                 # 14. 封闭类型与 impl 注册
    TypeCheck(ctx, require_entry=…).run()  # 15. 类型检查 → HIR
    ComptimeIfSpecializer(ctx, ...).run()  # 16. 编译期条件专门化
    ClosureLowering(ctx).run()             # 17. 闭包 lowering
    DefiniteAssignment(ctx).run()          # 18. 定值分析
    cfg_functions = __cfg(ctx)          # 19. HIR → CFG IR
    llvm_module = __llvm_codegen(...)   # 20. CFG → LLVM IR
    Emitter().emit_module(...)          # 21. 输出目标文件
```

## 关键数据结构

| 阶段 | 输入 | 输出 |
|------|------|------|
| Lex | `CharStream` | `list[Token]` |
| Parse | `list[Token]` | `AST.Program` |
| Desugar | `AST.Program` | `AST.Program` |
| Resolve | `UnitData` × N | 注册到 `TypeCtx` |
| TypeCheck | `UnitData` → `DefPoint` | `HIR.Block` body |
| CFG | `DefPoint` | `CFG_IR.Function` |
| LLVM | `CFG_IR.Function` | `ir.Module` |
| Emit | `ir.Module` | 目标文件 |

## 中间产物

所有中间产物写入 `build/`：

| 文件 | 阶段 | 说明 |
|------|------|------|
| `build/tokens.txt` | Lex 后 | 全文 token 列表 |
| `build/ast.txt` | Desugar 后 | AST 树形 dump |
| `build/hir.txt` | CFG 前 | HIR bundle dump |
| `build/cfg.txt` | CFG 后 | 各函数 CFG dump |
| `build/ir.ll` | 代码生成时 | LLVM IR 文本 |
| `build/compile.log` | 全流程 | 日志消息 |
| `build/a.out` | Emit | 可执行文件 (exe) |
