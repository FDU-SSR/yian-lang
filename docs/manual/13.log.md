# 13 日志系统

`compiler/utils/log.py` — 结构化、可配置的编译器日志框架。

## 架构

```text
CompilerLog (单例)
  ├── 配置解析 (--log-spec / YIAN_LOG)
  ├── LogChannel 工厂 (懒创建 + 缓存)
  └── LogOutput 后端 (stderr / file / multi)

LogChannel (每个编译阶段一个实例)
  ├── 级别过滤 (enabled)
  ├── LogFilter (可选, 按源位置过滤)
  ├── LogFormatter (格式化)
  └── LogOutput (写入)
```

## LogLevel

```python
class LogLevel(Enum):
    OFF   = 0   # 无输出
    ERROR = 1
    WARN  = 2
    INFO  = 3   # 默认
    DEBUG = 4   # 含 dump
    TRACE = 5   # 每条指令
```

## LogChannel

每个编译阶段/子系统持有一个 `LogChannel` 实例：

```python
class LogChannel:
    # 日志方法 — msg 可以是 str 或 Callable[[], str] (惰性)
    def error(self, msg, span=None) -> None
    def warn (self, msg, span=None) -> None
    def info (self, msg, span=None) -> None
    def debug(self, msg, span=None) -> None
    def trace(self, msg, span=None) -> None

    # 级别判断
    def enabled(self, level: LogLevel) -> bool

    # 缩进
    def push_indent() / pop_indent()
    def indent() → context manager

    # 计时
    def scope(label, level) → context manager  # → label / ← label (ms)

    # 结构化 dump
    def dump_tokens(label, tokens)
    def dump_ast   (label, program)
    def dump_hir   (label, block)
    def dump_cfg   (label, func)
    def dump_ir    (label, module_text)
```

## CompilerLog — 单例

```python
class CompilerLog:
    @classmethod
    def init(cls, spec, file, *, noop=False)  # CLI 初始化
    @classmethod
    def instance(cls)                          # ENV 初始化
    @classmethod
    def get(cls, name) -> LogChannel          # 获取频道
    def channel(self, name) -> LogChannel      # 实例方法
    def configure(self, spec)                  # 运行时重配置
```

**初始化顺序**：
1. 模块首次访问 `CompilerLog.instance()` → 读 `YIAN_LOG` ENV 变量
2. `main.py` 调用 `CompilerLog.init(spec, file)` → CLI 参数覆盖 ENV
3. 各模块通过 `CompilerLog.get("channel_name")` 获取频道

## 配置格式

```text
"channel1=LEVEL,channel2=LEVEL@filter"
```

- `all=INFO` — 所有频道默认 INFO
- `type_check=DEBUG` — type_check 及其子频道（`type_check.expr`）为 DEBUG
- `type_check=TRACE@is_char_boundary` — 只在 span 包含 `is_char_boundary` 时输出

**前缀匹配**：`type_check=DEBUG` 匹配 `type_check`、`type_check.expr`、`type_check.coerce`。

## 频道列表

| 频道 | 模块 | 说明 |
|------|------|------|
| `main` | `main.py` | 编译管线主流程 |
| `lex` | `lexer.py` | 每个 token |
| `parse` | `parser.py` | 每个顶层声明 |
| `desugar` | `desugar.py` | 每次变换 |
| `type_check` | `type_check.py` | def 入队/出队 |
| `type_check.expr` | `expr_checker.py` | 每个 AST 表达式 |
| `type_check.coerce` | `expr_checker.py` | 每次类型强制 |
| `call_dispatch` | `call_dispatcher.py` | 每次方法调度 |
| `cfg.block` | `cfg/builder.py` | block 创建/终结 |
| `cfg.logical` | `cfg/builder.py` | `&&`/`||` 展开 |
| `llvm` | `llvm/translator.py` | 每条 CFG 指令 |

## NoopChannel

```python
class NoopChannel:
    """Release 模式 — 所有方法空操作。"""
```

当 `spec="all=OFF"` 或 `noop=True` 时，`CompilerLog.channel()` 返回 `NoopChannel` 实例。

## LogOutput

```python
class LogOutput(ABC):
    def write(self, text: str) -> None: ...

class StderrOutput(LogOutput): ...   # sys.stderr
class FileOutput(LogOutput): ...     # 文件 (行缓冲)
class MultiOutput(LogOutput): ...    # 同时写入多个后端
```

默认输出：`build/compile.log` + stderr。可通过 `--log-file` 或 `YIAN_LOG_FILE` 覆盖。

## 使用方式

```python
# 模块顶部
from compiler.utils.log import CompilerLog
ch = lambda: CompilerLog.get("my_channel")

# 在函数中
ch().debug(f"processing {name}")
ch().trace(lambda: f"detail: {expensive()}")
with ch().scope("heavy work"):
    do_work()
```

使用 lambda 延迟获取 channel，确保 `CompilerLog.init()` 已调用后才创建 channel。
