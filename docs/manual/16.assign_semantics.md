## is_simple_type

```python
def is_simple_type(self, type_id: int) -> bool:
    type_id = self.resolve_aliases(type_id)
    ty = self[type_id]

    # 基础类型 → True
    if isinstance(ty, (IntType, FloatType, BoolType, CharType, StrType,
                       PointerType, FunctionPointerType, SliceType)):
        return True

    # 组合类型 → 递归检查元素
    if isinstance(ty, ArrayType):   return self.is_simple_type(ty.element_type)
    if isinstance(ty, TupleType):   return all(self.is_simple_type(et) for et in ty.element_types)

    # @BitCopy struct/enum → 验证后返回 True
    if isinstance(ty, StructType) and ty.custom_def.is_bitcopy:
        self.__validate_bitcopy_struct(type_id)
        return True
    if isinstance(ty, EnumType) and ty.custom_def.is_bitcopy:
        self.__validate_bitcopy_enum(type_id)
        return True

    return False
```

`@BitCopy` 验证遍历所有字段/变体 payload，递归检查是否全部简单。结果缓存于 `__simple_type_cache`。

## build_assign — 三步验证

```python
def build_assign(type_ctx, coerce, span, target, value) -> HIR.Binary:
    # 1. l-value 检查
    check_assign_target(target, span)        # target.is_place 必须为 True

    # 2. 类型强制
    if value.type_id != type_ctx.never_id:
        value = coerce(value, target.type_id)

    # 3. 非简单类型源约束
    if not type_ctx.is_simple_type(target.type_id):
        check_simple_assign_source(value, type_ctx, span)

    return HIR.Binary(Assign, target, value)
```

## check_simple_assign_source

```python
def is_simple_assign_source(expr: HIR.Expr) -> bool:
    # 字面量: IntLiteral, FloatLiteral, CharLiteral, StrLiteral, BoolLiteral, NullptrLiteral
    # 构造表达式: StructConstruct, VariantConstruct, Array, ArrayRepeat, Tuple
    # 调用: Call, MethodCall, Invoke
    # 内置: BitCopy
    return isinstance(expr, (HIR.IntLiteral, ...))
```

四种合法源类型允许赋值给非简单目标，因为它们是"新创造的值"。
