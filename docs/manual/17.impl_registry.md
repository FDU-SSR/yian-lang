# 17 Impl 注册与查找

`compiler/analysis/ty/impl.py` — 管理所有 trait impl 和 inherent impl 的注册、缓存与查找。

## Impl

```python
@dataclass
class Impl:
    span: SrcSpan
    generics: list[int]                # 泛型参数 type_id
    target: int                        # impl 的目标类型 type_id
    trait: int | None                  # trait type_id (None = inherent impl)
    methods: dict[str, int]            # method_name → method_type_id
    conditions: dict[int, list[int]]   # generic_id → [required_trait_id]
```

## ImplRegistry

```python
class ImplRegistry:
    def register_impl(self, span, generics, target, trait, conditions) -> Impl
    def check_impls(self)                                      # 验证所有 impl
    def find_deref_target(self, type_id) -> int | None        # Deref trait 解析
    def check_conditions(self, impl, substs) -> bool           # trait bound 验证
    def has_impl(self, type_id, trait_id) -> bool              # 类型是否实现 trait
    def iter_candidate_impls(self, type_id) -> list[Impl]      # 候选 impl 收集
```

## 缓存层级

`check_impls()` 后，所有 impl 按四层缓存：

```python
# 非泛型 inherent impl → __impl_cache[target_id]
# 非泛型 trait impl   → __trait_impl_cache[target_id]
# 泛型 inherent impl  → __generic_impl_cache (flat list)
# 泛型 trait impl     → __trait_generic_impl_cache (flat list)
```

## iter_candidate_impls

```python
def iter_candidate_impls(self, type_id: int) -> list[Impl]:
    exact = __impl_cache[type_id] + __trait_impl_cache[type_id]
    generic = __generic_impl_cache + __trait_generic_impl_cache
    return exact + generic
```

所有泛型 impl 不加名称过滤地作为候选返回，由下游 `method_lookup` 中的 `GenericInference.constrain` 进行实际匹配。

## check_conditions — Trait Bound 验证

```python
def check_conditions(self, impl: Impl, substs: dict[int, int]) -> bool:
    for generic_id, required_traits in impl.conditions.items():
        concrete_type_id = substs.get(generic_id, generic_id)
        # 若类型仍为泛型，延迟检查
        if isinstance(type_ctx[concrete_type_id], GenericType):
            continue
        for trait_id in required_traits:
            substed_trait = type_ctx.instantiate(trait_id, substs)
            if not self.has_impl(concrete_type_id, substed_trait):
                return False
    return True
```

泛型延迟检查：当 condition 涉及的泛型尚未被推断为具体类型时，跳过该 condition（返回 True），等具体化后再验证。

## has_impl

```python
def has_impl(self, type_id: int, trait_id: int) -> bool:
    # 1. 精确匹配 (非泛型 impl)
    for impl in __trait_impl_cache[type_id]:
        if impl.trait == trait_id and check_conditions(impl, {}):
            return True

    # 2. 泛型 impl 匹配
    for impl in __trait_generic_impl_cache:
        if impl.trait.custom_def is trait.custom_def:
            inference.constrain(impl.target, type_id)
            if check_conditions(impl, substs):
                return True

    return False
```

## find_deref_target

沿 `Deref` trait 查找类型的解引用目标：

```python
def find_deref_target(self, type_id: int) -> int | None:
    # 1. 精确 Deref impl
    for impl in __trait_impl_cache[type_id]:
        if is_deref_impl(impl):
            return resolve_deref_target(impl, {})

    # 2. 泛型 Deref impl
    for impl in __trait_generic_impl_cache:
        if is_deref_impl(impl) and constraint matches:
            return resolve_deref_target(impl, substs)

    return None
```

## __check_impl — 方法签名验证

```python
def __check_impl(self, impl: Impl):

        if method_name in impl.methods:
```

**默认方法继承** (`__clone_trait_method_as_impl`)：将 trait 中带 body 的默认方法深拷贝到 impl，替换 `Self` 为具体目标类型。

## Impl 条件语法

```yian
trait MyClone {
    fn my_clone() -> Self;
}

impl<T> MyClone for Wrapper<T> if T: MyClone {
    fn my_clone() -> Self {
        let v = self.value.my_clone();
        Wrapper(v)
    }
}
```

在 `global_resolve.py` 中解析 `if T: MyClone` 为 `conditions = {T_id: [MyClone_trait_id]}`。

> 历史注记：早期版本还有"简单类型自动满足 Move / Clone"的隐式规则（`has_impl` 第 3 步）；该规则已于 2026-08-23 随 clone/move trait 一并移除。
