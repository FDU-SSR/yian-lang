# 04 全局符号解析

`compiler/analysis/passes/global_resolve.py` — 跨文件符号解析，将所有顶层声明注册到 `TypeCtx`。

## 三阶段解析

```
Phase 1: collect  — 收集所有单元的顶层符号
Phase 2: import   — 解析跨文件 import
Phase 3: resolve  — 解析类型定义（字段、方法签名）
```

## Import 解析

`from std.core.option import Option` 映射为 `lib/core/option.an`。

在 Standalone 模式下，`from adder import adder` 相对于导入文件的父目录查找 `adder.an`。

在 Package 模式下（`--packages`），第一段路径被作为包名解析：

```text
from myapp.utils.math import add    →  {myapp_root}/utils/math.an
from std.core.io import print        →  {lib}/core/io.an
```

包名→根目录的映射由 `--packages pkg.json` 传入：

```json
{
  "myapp": "/path/to/myapp/src",
  "utils": "/path/to/yian-utils/src",
  "std": "/path/to/yian/lib"
}
```

实现见 `__resolve_import_path()` 和 `__strict_pkg`。

## 类型定义解析

`__resolve_struct` / `__resolve_enum` / `__resolve_trait` / `__resolve_impl` 将 AST 类型定义转为 `TypeCtx` 中的类型对象。

## Impl 条件解析

`impl<T> Foo for T if T: Bar` 中的 `if T: Bar` 解析为 `conditions = {T_generic_id: [Bar_trait_type_id]}`，存储在 `Impl.conditions`。
