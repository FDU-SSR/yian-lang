## 函数调用：handle_call

```python
def handle_call(self, node):
    if callee is TypeItem:
        return handle_type_call()       # e.g. bitcast<T>(expr)
    if callee is Identifier:
        symbol = symbol_ctx.lookup(name)
        if name in BUILTIN_NAMES:       # sizeof, panic, bitcopy, ...
            return handle_builtin()
        match symbol.kind:
            case Function:  return handle_function_call()
            case Variable:  return handle_invocation()   # 函数指针
            case Type:      return handle_type_call()    # 类型构造
```

**内置函数** (`BUILTIN_NAMES`)：`sizeof`、`bitcast`、`sys_read`、`sys_write`、`panic`、`bitcopy`、`open`、`close`、`assume_init`、`drop_value`、`free`。

### 函数变量（函数项）的调用

若被调者的静态类型是 `FunctionType`（函数项，见 `05.type_system.md`）——例如
`let f = foo` 后的 `f()`、`(h.f)(x)`、`arr[i](x)`——走 `__handle_fn_item_call`：

- **固定签名直接派发**：实参按函数项已固定的参数类型协调，**不做泛型推断、不接受
  泛型实参**（与函数指针调用一致）。
- 生成 `HIR.Invoke`（携带被调表达式以保留其副作用）；CFG 中 `__resolve_invoke`
  发现被调者类型为 `FunctionType` 时，先求值被调表达式，再发**直接** `IR.Call`
  （被调身份来自具体静态类型）。
- 因函数项是 ZST，被调值不占运行期空间，整体为零开销直接调用。

绑定泛型参数未解析的函数（`let f = generic_fn;`）会报错：函数变量必须绑定具体函数。

## 方法调用：handle_method_call

```python
def handle_method_call(self, node):
    receiver = self.__expr.value(node.receiver)
    if receiver is HIR.Ty:                       # Self.method() / Type.method()
        return handle_static_or_variant_method_call()
    if method_name in ("move","clone","invalidate","is_valid"):
        if is_simple_type: return trivial_result # 编译器优化
    return handle_instance_method_call()
```

### 简单类型优化

对 `is_simple_type` 返回 true 的类型，编译器直接优化掉 Move/Clone trait 方法调用：

| 方法 | 替换为 |
|------|--------|
| `move()` / `clone()` | receiver 自身（追踪指针层级后解引用） |
| `invalidate()` | `HIR.Nop` |
| `is_valid()` | `HIR.BoolLiteral(true)` |

## dispatch_method_call — 核心流程

```python
def dispatch_method_call(self, span, receiver, method_name, generic_args, args, context_name):
    # 1. 方法查找
    lookup = type_ctx.method_lookup(receiver, method_name, generic_args, args)

    # 2. 静态调用检查
    if receiver is HIR.Ty and not method.is_static:
        raise AnalysisError("cannot call instance method as static")

    # 3. Auto-deref: 沿 deref chain 自动解引用
    for _ in range(lookup.deref_count):
        if PointerType:  receiver = Deref(receiver)
        else:            receiver = call deref() trait method

    # 4. 构建 HIR.MethodCall
    return build_method_call(span, receiver, lookup, args, context_name)
```

## Deref Chain

```python
def deref_chain(self, type_id):
    chain = [type_id]
    while True:
        next_ty = self.try_deref(current)
        if next_ty is None: break
        chain.append(next_ty)
    return chain

def try_deref(self, type_id):
    ty = self[type_id]
    if PointerType: return ty.pointee_type          # 指针解引用
    return impl_registry.find_deref_target(type_id) # Deref trait
```
