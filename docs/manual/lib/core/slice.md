# `T[]` 类型

`T[]` 是切片类型, 用于表示一个连续的元素序列. 切片是对底层数据的视图, 不拥有数据本身, 因此它们是轻量级的.

## 访问

提供以下方法来访问切片中的元素:

- `get(u64 index) -> Option<T>`: 返回指定索引处元素的引用. 如果索引越界, 则返回 `None`.
- `first() -> Option<T>`: 返回第一个元素的引用. 如果 `Vec` 为空, 则返回 `None`.
- `last() -> Option<T>`: 返回最后一个元素的引用. 如果 `Vec` 为空, 则返回 `None`.

## 视图

提供以下方法来获取切片的视图:

- `len() -> u64`: 返回切片的长度.
