# `str` 类型

`str` 类型表示一个 UTF-8 编码的字符串的引用, 为 yian 内置类型, 此文档描述其相关的操作和方法.

## 创建

- `str.from_slice(u8[] s) -> str`: 从一个字节切片创建一个 `str` 引用. 注意, 这不检查字节序列是否为有效的 UTF-8 编码.

## 视图

- `as_bytes() -> u8[]`: 返回一个字节切片, 代表 `str` 的内容.

## 索引

- `s[start..end] -> str`: 按字节范围返回一个子 `str` 视图.
- `start` 和 `end` 必须都落在 UTF-8 字符边界上, 否则运行时会 panic.
