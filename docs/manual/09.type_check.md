# 09 类型检查

`compiler/analysis/passes/type_check.py` — Worklist 驱动的类型检查，从 `main()` 出发，按需入队可达函数/方法。

## Worklist 机制

```python
class TypeCheck:
    def run(self):
        self.__find_main()          # 将 main() 加入 worklist
        while self.__worklist:
            def_point = self.__worklist.pop()
            if def_point.type_id in processed: continue
            processed.add(def_point.type_id)
            self.__type_check_def(def_point)
```

## DefPoint 入队

```python
def __report_def_point(self, type_id: int):
    """当 lowering 发现新的可达函数/方法时调用。"""
    if type_id in self.__def_points: return
    dp = DefPoint(type_id=type_id, ...)
    self.__worklist.append(dp)
```

入队触发点：`SemCtx.report_def(type_id)`，由 `build_method_call` 和 `handle_function_call` 调用。

## __type_check_def

```python
def __type_check_def(self, def_point: DefPoint):
    ty = type_ctx[def_point.type_id]
    if isinstance(ty, FunctionType):
        def_point.body = self.__check_function(def_point)
    elif isinstance(ty, MethodType):
        def_point.body = self.__check_method(def_point)
```

## __check_function / __check_method

1. 调用 `SemCtx.begin_def()` 设置当前函数的符号上下文
2. 将泛型参数注入符号上下文（`T` → `Type`、`const N: u64` → `ConstGeneric`）
3. 对于方法：注册 `self` 为 `Self&` 类型的变量；调用 ABI 使用与 `Self*` 相同的数据指针表示
4. 调用 `ExprChecker.check_block(ast_body)` 执行 HIR lowering
5. 返回 `HIR.Block`

## 泛型实例化

当 lowering 遇到泛型调用 `foo<i32>(42)` 时：
1. `GenericInference` 约束泛型参数 = 具体类型参数
2. `inference.instantiate()` 产生实例化的函数/方法 type_id
3. `report_def()` 将实例化版本加入 worklist
4. 实例化版本的 body 被独立类型检查

## 与 Lowering 模块的协作

`TypeCheck` 持有 `ExprChecker`，后者持有 `CallDispatcher` 和 `OpBuilder`。三者协作完成 AST → HIR 翻译。
