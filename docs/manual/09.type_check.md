# 09 类型检查

`yianc/src/analysis/passes/type_check.an::check_procedures` 驱动过程检查。它检查根包或独立输入的过程，并按需检查发现的具体实例。供代码生成选择的过程集合由分析结果单独记录。

每个具体过程通过 `ExprChecker` 将表达式和模式下降为 HIR。检查器在该阶段处理编译期分支的选择、参数与返回值的类型约束、调用实例化与绑定。解析和验证所需的类型信息来自当前 `AnalysisSession`。

地址存储规范化、HIR 验证、模式覆盖检查和确定赋值检查在中端随后的 pass 执行。可恢复的类型、覆盖和赋值错误由产生点通过 `ResolutionContext` 同步报告给调用者的 `DiagnosticReporter`，致命失败沿 `AnalysisError` 返回。类型检查按诊断码和源码起始位置对本次运行去重；`--check` 按发现顺序输出可恢复错误。
