# 08 HIR

HIR (High-level IR) 是带类型标注的 AST，由类型检查阶段产生。

本章的节点实现和 `python/yianc/` 路径描述 Python recovery HIR。原生 `yianc` 在完成具体过程
的类型及上下文转换后，还会先规范化数据地址和隐式存储消费者，再运行 HIR 验证与后续分析；
该原生阶段见[完整编译管线](30.bootstrap.md#完整编译管线)。

## 源文件

- `python/yianc/analysis/unit/hir.py` — HIR 节点定义
- `python/yianc/analysis/unit/def_point.py` — `DefPoint`，类型检查单元
- `python/yianc/analysis/unit/unit_data.py` — `UnitData`，编译单元

## HIR 节点

HIR 表达式节点为 `@dataclass`，携带 `span`、`type_id` 和 `is_place` 字段；模式、arm 和捕获记录有各自的数据字段。

控制流：`Block`、`Return`、`If`、`Loop`、`Break`、`Continue`、`Defer`、`Match`

表达式：`Binary`、`Unary`、`Call`、`MethodCall`、`Invoke`、`StructConstruct`、`VariantConstruct`、`FieldAccess`、`TupleAccess`、`ArrayAccess`、`SliceAccess`、`Cast`、`BitCast`、`Closure`、`Builtin`

变量与内存：`Var`、`Let`、`PatternLet`、`Delete`

字面量：`IntLiteral`、`FloatLiteral`、`CharLiteral`、`StrLiteral`、`BoolLiteral`、`Ty`

内建指令：统一的 `Builtin` 保存 `BuiltinKind`、类型 ID 实参、已检查的值实参和结果类型。
`sizeof`、分配、复制、IO、数学函数、终止与 FFI 封送均使用此节点。

聚合：`Tuple`、`Array`、`ArrayRepeat`

动态分配语法：`DynValue`、`DynBuffer`

```python
Expr = Binary | Unary | Call | StructConstruct | Invoke | Cast
     | MethodCall | VariantConstruct | FieldAccess | TupleAccess
     | ArrayAccess | SliceAccess
     | DynValue | DynBuffer | BitCast | Builtin
     | Tuple | Array | ArrayRepeat | Var | Literal | Ty | Closure
     | Block | Return | Break | Continue | Defer | If | Loop
     | Delete | Match | Semi | Let | PatternLet
```

`HIR.Defer` 保存已经类型检查的 `action`，但自身类型固定为 `void`。CFG lowering 按照词法作用域展开它。

上面的联合是主要节点的示意；完整定义还包含 trait object 节点，FFI 操作属于 `Builtin`。`comptime if`
在 AST lowering 时选择分支，因此 HIR 保存选中分支的块。`Match` 保存结构化模式、可选守卫
和 arm 来源；`PatternLet` 保存解构绑定及可选 else。模式遍历共用 `hir_traversal.py`。

## DefPoint

```python
@dataclass
class DefPoint:
    type_id: int          # Function/method type_id.
    unit_id: int          # Owning UnitData.
    ast_body: AST.Block   # Original AST body for lowering.
    symbol_ctx: SymbolCtx # Symbol context.
    body: HIR.Block | None = None  # HIR body populated by lowering.
    locals: list[int]     # Local-variable symbol_id list.
    params: list[int]     # Parameter symbol_id list, including self for methods.
```

## UnitData

```python
@dataclass
class UnitData:
    unit_id: int                 # Unit ID.
    program: AST.Program         # AST
    path: Path                   # Source-file path.
    symbol_ctx: SymbolCtx        # Top-level symbol context.
    is_stdlib: bool              # Whether part of the standard library.
    allows_restricted_ops: bool  # Whether restricted operations are permitted.
    allows_ffi: bool             # Whether FFI declarations are permitted.
```
