# 08 HIR

HIR (High-level IR) 是带类型标注的 AST，由类型检查阶段产生。

## 源文件

- `compiler/analysis/unit/hir.py` — HIR 节点定义
- `compiler/analysis/unit/def_point.py` — `DefPoint`，类型检查单元
- `compiler/analysis/unit/unit_data.py` — `UnitData`，编译单元

## HIR 节点

所有 HIR 节点为 `@dataclass`，携带 `span`、`type_id` 和 `is_place` 字段。

控制流：`Block`、`Return`、`If`、`Loop`、`Break`、`Continue`、`Match`、`Panic`

表达式：`Binary`、`Unary`、`Call`、`MethodCall`、`Invoke`、`StructConstruct`、`VariantConstruct`、`FieldAccess`、`TupleAccess`、`Cast`、`SizeOf`、`BitCast`、`BitCopy`

变量与内存：`Var`、`Let`、`Delete`、`AssumeInit`、`Nop`

字面量：`IntLiteral`、`FloatLiteral`、`CharLiteral`、`StrLiteral`、`BoolLiteral`、`NullptrLiteral`、`Ty`

聚合：`Tuple`、`Array`、`ArrayRepeat`

系统：`DynValue`、`DynBuffer`、`SysRead`、`SysWrite`、`Open`、`Close`

```python
Expr = Binary | Unary | Call | StructConstruct | Invoke | Cast
     | MethodCall | VariantConstruct | FieldAccess | TupleAccess
     | DynValue | DynBuffer | SizeOf | BitCast | SysRead | SysWrite
     | Open | Close | Tuple | Array | ArrayRepeat | Var | Literal | Ty
     | Block | Return | Break | Continue | If | Loop | Panic | Delete
     | Match | Semi | Let | BitCopy | AssumeInit | Nop
```

## DefPoint

```python
@dataclass
class DefPoint:
    type_id: int          # 函数/方法 type_id
    unit_id: int          # 所属 UnitData
    ast_body: AST.Block   # 原始 AST body (供 lowering)
    body: HIR.Block       # Lowering 后填充的 HIR body
    symbol_ctx: SymbolCtx # 符号上下文
    locals: list[int]     # 局部变量 symbol_id 列表
    params: list[Parameter]
    validity: ...         # 定值分析结果
```

## UnitData

```python
@dataclass
class UnitData:
    program: AST.Program     # AST
    path: Path               # 源文件路径
    unit_id: int             # 单元 ID
    symbol_ctx: SymbolCtx    # 顶层符号上下文
```
