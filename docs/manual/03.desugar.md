# 03 AST 去糖

`compiler/analysis/passes/desugar.py` — 两遍遍历将语法糖展开为基本 AST 结构。

## 两遍设计

```python
class Desugar:
    def run(self):
        for item in program.items:
            match item:
                case FuncDef():   process(item.body)
                case Impl():      for m in item.items: process(m.body)
                case TraitDef():  for m in item.items: process(m.body)
```

**Pass 1** (`__process_control_flow`)：`for`、`while`、`assert`、`elif` 链 → 基本控制流。

**Pass 2** (`__process_expr_rewrite`)：`a..b` 范围、`x in y` 成员测试 → 等价表达式。

## 变换规则

| 原始 | 展开为 |
|------|--------|
| `for item in iterable { body }` | `let %iter = iterable.into_iter(); loop { match %iter.next() { Some(item) => { body }, None => { break } } }` |
| `while cond { body }` | `loop { if !cond { break; } body }` |
| `assert cond: msg` | `if !cond { panic(msg) }` |
| `if a { } elif b { } else { }` | `if a { } else { if b { } else { } }` |
| `a..b` | `Range(a, b)` |
| `x in y` | `y.contains(x)` |

## 遍历机制

**`__recurse_blocks`**：对嵌套 block 递归应用 processor。

**`__apply_expr_visitor`**：对语句中的表达式应用 visitor 函数（`__desugar_range` / `__desugar_member_test`）。

每个 visitor 先递归遍历子表达式（`__walk_expr_children`），再对当前节点做变换。
