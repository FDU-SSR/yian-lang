# 11 CFG 构建

`compiler/codegen/cfg/passes/translator.py` 与下降簇目录 `compiler/codegen/cfg/lower/` — 将 HIR 定义翻译为 CFG `Function`。CFG 侧分三段 pass，由 `compiler/main.py::__cfg` 编排：`CfgTranslator`（HIR → CFG IR）→ `InsertChecks`（检查插入）→ `Cleanup`（去死块、RPO 排序、终止保护）。

## CfgTranslator

```python
class CfgTranslator:
    def __init__(self, type_ctx: TypeCtx, raw_pointers: bool = False)
    def run(self, def_points: dict[int, DefPoint]) -> None
    def export(self) -> dict[int, IR.Function]
    @property
    def ctx(self) -> CfgCtx
```

`run()` 为每个 `DefPoint` 构造一个私有的 `_CfgBuilder(ctx, dp)`，逐个降成 CFG 函数后登记进 `CfgCtx` 的共享函数表；`export()` 返回 `type_id → IR.Function`。下降机器（各下降簇与它们共用的句柄）在 `cfg/lower/`。

### build() 流程

```python
def build(self) -> IR.Function:
    # 1. 创建 entry block, 绑定当前函数
    # 2. 注册参数 symbol_id
    # 3. 注册 local variables (VarRef)
    # 4. translate HIR block body → CFG stmts
    body_val = self.__stmts.translate_block(dp.body)
    # 5. 当前块未终止且返回类型非 void → Ret(body_val)
    # 6. 记录帧锁实体化状态 (func.frame_lock)
```

## HIR → CFG 翻译

### ExprLowerer.resolve_val — 核心 dispatch

```python
def resolve_val(self, expr: HIR.Expr) -> IR.Value:
    match expr:
        case HIR.Binary():   return self.resolve_binary(expr)
        case HIR.Unary():    return self.resolve_unary(expr)
        case HIR.Call():     return self.__host.calls.resolve_call(expr)
        case HIR.Var():      return self.resolve_var(expr)
        case HIR.Let():      return self.__host.stmts.translate_let(expr)
        case HIR.Defer():    return self.__host.stmts.translate_defer(expr)
        case HIR.If():       return self.__host.stmts.translate_if(expr)
        case HIR.Loop():     return self.__host.stmts.translate_loop(expr)
        case HIR.Match():    return self.__host.stmts.translate_match(expr)
        case HIR.Dangling(): return self.__host.values.resolve_dangling(expr)
        ...
```

### 赋值翻译 (ExprLowerer.resolve_assign)

```python
def resolve_assign(self, expr: HIR.Binary) -> IR.Value:
    lhs_addr = self.__host.values.resolve_addr(expr.left)   # 目标地址
    rhs_val  = self.resolve_val(expr.right)                 # 源值
    if rhs_val.type_id != never_id:
        self.__host.memory.build_store(rhs_val, lhs_addr)   # store value → address
    return rhs_val
```

### 地址解析 (ValueLowerer.resolve_addr)

```python
def resolve_addr(self, expr: HIR.Expr) -> IR.Value:
    if not expr.is_place:
        val = self.__host.resolve_val(expr)
        return self.build_alloca(val, fat=False)  # rvalue → 临时变量
    match expr:
        case HIR.Var():         → var_addr (取变量地址)
        case HIR.FieldAccess(): → field_ptr (字段偏移)
        case HIR.Unary(Deref):  → 不 load, 直接返回指针值
        case HIR.TupleAccess(): → 元组字段偏移
        case HIR.Ty():          → 函数指针
```

`resolve_addr_fat` 是惰性左值路径：显式 `&x` 与方法 receiver 走它，变量地址一律合成胖指针并在首次取址时实体化帧锁。

### 变量翻译

```python
def resolve_var(self, expr: HIR.Var) -> IR.Value:
    addr = self.__host.values.resolve_var_addr(expr)  # VarPtr 指令
    return self.__host.memory.build_load(addr)        # Load 指令

def resolve_var_addr(self, expr: HIR.Var, *, fat=False) -> IR.Value:
    var_ref = func.local_vars[expr.symbol_id]
    result = IR.Reg(type_id=alloc_pointer(var_ref.type_id))
    return IR.VarPtr(result=result, var_ref=var_ref).result
```

## 短路逻辑 (ExprLowerer.resolve_logical)

`&&` 和 `||` 通过条件跳转实现短路求值：

```python
def resolve_logical(self, expr: HIR.Binary) -> IR.Value:
    cond_val = self.resolve_val(expr.left)
    rhs_block  = self.__host.emitter.new_block("logical.rhs")
    merge_block = self.__host.emitter.new_block("logical.merge")

    if expr.op == LogicalAnd:
        # a && b: if false → short-circuit to false
        self.__host.set_terminator(CondBr(cond_val, rhs_block, merge_block))
        short_circuit_value = BoolLiteral(False)
    else:
        # a || b: if true → short-circuit to true
        self.__host.set_terminator(CondBr(cond_val, merge_block, rhs_block))
        short_circuit_value = BoolLiteral(True)

    # rhs block
    self.__host.switch_to(rhs_block)
    rhs_val = self.resolve_val(expr.right)
    rhs_end_block = self.__host.emitter.current_block  # 嵌套逻辑后的实际 block
    if rhs_end_block.terminator is None:
        self.__host.set_terminator(Br(merge_block))

    # merge block
    self.__host.switch_to(merge_block)
    result = self.__host.emitter.emit_phi([(entry_block, short_circuit_value),
                                           (rhs_end_block, rhs_val)])
    cont_block = self.__host.emitter.new_block("logical.cont")
    self.__host.set_terminator(Br(cont_block))
    self.__host.switch_to(cont_block)
    return result
```

## Block 管理

每次进入 `HIR.Block` 时 `StmtLowerer` 压入一个延迟操作列表。`HIR.Defer` 只把已经 lowering 的 `action` 登记到当前列表，不立即生成指令；块自然结束时先保存尾表达式值，再逆序解析列表。`return` 展开全部活动列表，`break`/`continue` 展开到对应循环建立时记录的作用域深度，因而不会误清理循环外层作用域。这里不增加 CFG 或 LLVM 节点。

块与 SSA 名由 `FunctionEmitter` 统一分配：

```python
def new_block(self, label: str) -> IR.Block:
    block = IR.Block(f"{label}.{counter}")
    counter += 1
    func.blocks.append(block)
    return block

def position(self, block: IR.Block):
    self.current_block = block

def terminate(self, term: IR.Terminator):
    self.current_block.terminator = term
```

## 终止检查 (_guard_termination, Cleanup)

```python
def _guard_termination(func: IR.Function, facts: FuncFacts) -> None:
    for block in func.blocks:
        if block.terminator is None:
            if facts.return_type == TypeCtx.void_id:
                block.terminator = Ret(facts.new_void_value())   # 自动补 Ret
            else:
                raise CodegenError("unterminated block")          # 非 void 必须显式 return
```

## 正则化

- **Dead code elimination**：`_eliminate_dead_code` 从 entry block 开始 BFS，移除不可达 block，清理 phi 节点中来自已删除 block 的条目
- **RPO 排序**：`_sort_blocks_rpo` 按逆后序排列 block，保证 phi 节点的前驱 block 在 phi 之前定义

两段都在 `Cleanup.run()` 里逐函数执行（去死块 → RPO 排序 → 终止检查）。

## 三段 pass 的编排

`CfgTranslator`、`InsertChecks`、`Cleanup` 三段依次运行，共享同一个 `CfgCtx`（函数表 + 每函数事实）：

```python
cfg_lower = CfgTranslator(type_ctx, raw_pointers=...)
cfg_lower.run(def_points)
InsertChecks(cfg_lower.ctx).run()
Cleanup(cfg_lower.ctx).run()
functions = cfg_lower.export()          # dict[int, IR.Function]
```
