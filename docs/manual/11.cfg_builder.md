# 11 CFG 构建

`compiler/codegen/cfg/pipeline.py` 与 `compiler/codegen/cfg/lower/` — 将 HIR 定义翻译为 CFG `Function`。
`CfgPipeline` 依次运行 `CfgTranslator`（HIR → CFG IR）、`InsertChecks`（将安全检查请求具体化）和
`Cleanup`（去死块、RPO 排序、终止保护）。

## CfgTranslator

```python
class CfgTranslator:
    def __init__(self, type_ctx: TypeCtx, raw_pointers: bool = False)
    def run(self, def_points: dict[int, DefPoint]) -> None
    @property
    def module(self) -> CfgModule
```

`run()` 为每个生成用 `DefPoint` 构造函数记录并登记到 `CfgModule`。`CfgPipeline.run()` 在共享
`CfgModule` 上执行检查插入和清理，最终返回 `type_id → IR.Function`。逐函数下降按职责拆在
`cfg/lower/`：session 与类型映射、表达式/值/调用/语句下降、CFG 发射状态分别位于独立模块。

### build() 流程

```python
def FunctionBuilder.build(self) -> CfgFunction:
    # 1. 创建 entry block, 绑定当前函数
    # 2. 注册参数 symbol_id；闭包函数先添加隐藏环境引用 receiver
    # 3. 注册 local variables (VarRef)
    # 4. translate HIR block body → CFG stmts
    body_val = self.__stmts.translate_block(dp.body)
    # 5. 当前块未终止且返回类型非 void → Ret(body_val)
    # 6. 记录帧锁实体化状态 (func.frame_lock)
```

闭包在这一阶段具体化。`HIR.Closure` 的捕获值按字段次序构造成环境结构体；闭包 body 的捕获变量
映射到隐藏环境 receiver 的结构体字段地址。闭包 callable 的 CFG 签名使用其普通调用方法签名，
环境结构体引用是首参数，显式参数按声明顺序排列。调用一个闭包时，builder 求值或物化一次环境，再生成
带 receiver 与显式参数的普通 `IR.Call`。

`CfgTypeMapper` 把 `ClosureType` 映射为环境结构体，并递归映射引用、指针、聚合、函数和自定义类型中的
嵌套闭包类型。它只生成 CFG 可见的类型 ID，不改写语义阶段的类型定义；完成的 CFG 函数在进入检查
插入与清理前统一规范化类型 ID。

## HIR → CFG 翻译

以下代码块展示当前接口或局部逻辑；标注为 `text` 的内容及带 `...` 的片段是示意，不是可执行实现。

### ExprLowerer.resolve_val — 核心 dispatch

```python
def resolve_val(self, expr: HIR.Expr) -> IR.Value:
    match expr:
        case HIR.Binary():   return self.resolve_binary(expr)
        case HIR.Unary():    return self.resolve_unary(expr)
        case HIR.Call():     return self.__calls.resolve_call(expr)
        case HIR.Var():      return self.resolve_var(expr)
        case HIR.Let():      return self.__stmts.translate_let(expr)
        case HIR.Defer():    return self.__stmts.translate_defer(expr)
        case HIR.If():       return self.__stmts.translate_if(expr)
        case HIR.Loop():     return self.__stmts.translate_loop(expr)
        case HIR.Match():    return self.__stmts.translate_match(expr)
        case HIR.Builtin():  return self.resolve_builtin(expr)
        ...
```

这是 dispatch 的局部示例；完整表达式分派也处理闭包、trait object、数组与聚合、系统调用和内建操作。

### 赋值翻译 (ExprLowerer.resolve_assign)

```python
def resolve_assign(self, expr: HIR.Binary) -> IR.Value:
    lhs_addr = self.__values.resolve_addr(expr.left)        # 目标地址
    rhs_val  = self.resolve_val(expr.right)                 # 源值
    if rhs_val.type_id != never_id:
        self.__memory.build_store(rhs_val, lhs_addr)        # store value → address
    return rhs_val
```

### 地址解析 (ValueLowerer.resolve_addr)

```text
def resolve_addr(self, expr: HIR.Expr) -> IR.Value:
    if not expr.is_place:
        val = self.__resolver.resolve_val(expr)
        return self.build_alloca(val, fat=False)  # rvalue → 临时变量
    match expr:
        HIR.Var()         → resolve_var_addr (取变量地址)
        HIR.FieldAccess() → resolve_field_access_addr (字段偏移)
        HIR.Unary(Deref)  → 不 load, 直接返回指针值
        HIR.TupleAccess() → resolve_tuple_access_addr (元组字段偏移)
        HIR.Ty()          → build_func_ptr (函数指针)
```

`resolve_addr_fat` 是惰性左值路径：显式 `&x` 与方法 receiver 走它；fat 模式的局部变量地址携带帧锁，
首次需要胖指针时才实体化帧锁。自然读写路径可以直接使用栈槽裸地址。

### 变量翻译

```python
def resolve_var(self, expr: HIR.Var) -> IR.Value:
    addr = self.__values.resolve_var_addr(expr)  # VarPtr 指令
    return self.__memory.build_load(addr)        # Load 指令

def resolve_var_addr(self, expr: HIR.Var, *, fat=False) -> IR.Value:
    if expr.symbol_id in self.__state.closure_capture_fields:
        return address_of_capture_field(expr.symbol_id)  # capture lookup details omitted
    var_ref = self.__state.emitter.func.local_vars[expr.symbol_id]
    return self.build_var_ptr_fat(var_ref) if fat else self.build_var_ptr_raw(var_ref)
```

## 短路逻辑 (ExprLowerer.resolve_logical)

`&&` 和 `||` 通过条件跳转实现短路求值：

```python
def resolve_logical(self, expr: HIR.Binary) -> IR.Value:
    cond_val = self.resolve_val(expr.left)
    entry_block = self.__state.emitter.current_block
    rhs_block  = self.__state.emitter.new_block("logical.rhs")
    merge_block = self.__state.emitter.new_block("logical.merge")

    if expr.op == LogicalAnd:
        # a && b: if false → short-circuit to false
        self.__state.emitter.terminate(CondBr(cond_val, rhs_block, merge_block))
        short_circuit_value = BoolLiteral(False)
    else:
        # a || b: if true → short-circuit to true
        self.__state.emitter.terminate(CondBr(cond_val, merge_block, rhs_block))
        short_circuit_value = BoolLiteral(True)

    # rhs block
    self.__state.emitter.position(rhs_block)
    rhs_val = self.resolve_val(expr.right)
    rhs_end_block = self.__state.emitter.current_block  # 嵌套逻辑后的实际 block
    if rhs_end_block.terminator is None:
        self.__state.emitter.terminate(Br(merge_block))

    # merge block
    self.__state.emitter.position(merge_block)
    result = self.__state.emitter.emit_phi([(entry_block, short_circuit_value),
                                            (rhs_end_block, rhs_val)])
    cont_block = self.__state.emitter.new_block("logical.cont")
    self.__state.emitter.terminate(Br(cont_block))
    self.__state.emitter.position(cont_block)
    return result
```

## Block 管理

每次进入 `HIR.Block` 时 `StmtLowerer` 压入一个延迟操作列表。`HIR.Defer` 把已经 lowering 为 HIR 的 action 登记到当前列表；块自然结束时先保存尾表达式值，再逆序 lowering action。`return` 展开全部活动列表，`break`/`continue` 展开到对应循环建立时记录的作用域深度，因此循环外层作用域不参与该次展开。

块与 SSA 名由 `FunctionEmitter` 统一分配：

```python
def new_block(self, label: str) -> IR.Block:
    block = IR.Block(f"{label}.{counter}")
    counter += 1
    func.blocks.append(block)
    return block

def position(self, block: IR.Block):
    self.current_block = block

def terminate(self, term: IR.Terminator):
    self.current_block.terminator = term
```

## 终止检查 (_guard_termination, Cleanup)

```text
def _guard_termination(record: CfgFunction) -> None:
    func = record.function
    for block in func.blocks:
        if block.terminator is None:
            if record.return_type == TypeCtx.void_id:
                block.terminator = Ret(record.void_value())       # 自动补 Ret
            else:
                raise CodegenError("unterminated block")          # 非 void 必须显式 return
```

## 正则化

- **Dead code elimination**：`_eliminate_dead_code` 从 entry block 开始 BFS，移除不可达 block，清理 phi 节点中来自已删除 block 的条目
- **RPO 排序**：`_sort_blocks_rpo` 按逆后序排列 block，保证 phi 节点的前驱 block 在 phi 之前定义

两段都在 `Cleanup.run()` 里逐函数执行（去死块 → RPO 排序 → 终止检查）。

## 三段 pass 的编排

`CfgPipeline` 依次运行 `CfgTranslator`、`InsertChecks`、`Cleanup`。翻译器把函数记录在 `CfgModule`，检查插入和清理 pass 处理同一 module；pipeline 返回导出的函数字典：

```python
functions = CfgPipeline(type_ctx, raw_pointers=...).run(def_points)
```
