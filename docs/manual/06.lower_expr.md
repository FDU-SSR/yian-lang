# 06 表达式 Lowering

表达式 lowering 将 AST 表达式节点翻译为 HIR（带类型标注的 AST）。

## ExprChecker

`python/yianc/analysis/lowering/expr_checker.py` — 核心 dispatch。

```python
class ExprChecker:
    def value(self, expr: AST.Expr) -> HIR.Expr:
        match expr:
            case AST.Block():    return self.check_block(expr)
            case AST.If():        return self.lower_if(expr)
            case AST.Defer():     return self.lower_defer(expr)
            case AST.Binary():    return self.__handle_binary(expr)
            case AST.Call():      return self.__call_dispatcher.handle_call(expr)
            case AST.Builtin():   return self.__builtin_dispatcher.handle(expr)
            case AST.VarDecl():   return self.lower_var_decl(expr)
            ...
```

`value()` 是 AST → HIR 的入口，按 AST 节点类型分发到不同的 handler。

`BuiltinDispatcher`（`builtin_dispatcher.py`）检查统一的 `AST.Builtin`，解析类型实参、
检查操作数并产生 `HIR.Builtin`。`BuiltinKind` 标识具体内建操作，CFG 下降再发射具体指令。

`defer` 的操作会在这里正常完成类型检查和 lowering，但 `lower_defer()` 返回的 `HIR.Defer` 自身固定为 `void`。登记点的符号可见性和跳转限制在此阶段确定；延迟操作不会被包装成普通表达式供参数或赋值使用。

## coerce() — 类型强制

```python
def coerce(self, expr: HIR.Expr, expected: int) -> HIR.Expr:
```

将 `expr` 强制为 `expected` 类型。处理规则：
- `IntLiteral` / `FloatLiteral` → 目标整数/浮点类型（修改 `type_id`）
- 取址表达式 `&e` 的 `T* → U*` → 先把被取址的 `e` coerce 到 `U`
- 指针/切片/数组到引用（`T* → T&`、`T[] → T&`）与指向数组的指针重锚定 → 生成地址值（`HIR.BitCast`）
- `ArrayType*`（指向数组的指针）→ `ElementType*`（指向首元素的指针，数组退化）
- `Tuple` / `Array` / `ArrayRepeat` → 递归 coerce 元素
- `DynValue` / `DynBuffer` → 把负载 coerce 到 pointee 类型
- 其他 → 类型必须完全匹配，否则 `AnalysisError`

`ExprChecker.lower_comptime_if` 将条件协调为 `bool` 并交给编译期求值器，只检查选中的 AST
分支，直接返回其 `HIR.Block`。结果不含 HIR 编译期条件节点。模块常量通过同一求值器解析，
在表达式使用点产生独立的值 HIR（标量、数组、`ArrayRepeat` 或常量数组索引的结果）。

原生 lowering 不设常量模式开关：字面量保留原数值，经具体 carrier 和显式 `Cast` 进入
目标类型；整数转换与运算由求值器逐步检查。成功分析在地址归一化之后强制执行
`finalize_hir_types`，把导出过程的字面量占位类型定型为具体类型，再进入可选 HIR 验证
和 CFG。

`PatternChecker` 在给定值类型与引用模式下构造结构化 HIR 模式，登记绑定符号并检查字段权限、
备选项绑定一致性和范围端点。`MatchCoverage` 在完整 HIR 上检查穷尽性与不可失败绑定。

## OpBuilder

`python/yianc/analysis/lowering/op_builder.py` — 运算符 lowering。

```python
class OpBuilder:
    def build_binary(self, span, op, left, right) -> HIR.Expr
    def build_unary(self, span, op, operand) -> HIR.Expr
```

**运算符处理流程**：
1. 检查 operand 类型是否为 builtin（整数/浮点）
2. 若是 builtin → 直接构建 `HIR.Binary` / `HIR.Unary`
3. 若 operand 标记为 `Overloaded` → 通过 `__resolve_overloaded_operator` 查找对应 trait 的 impl

**`__resolve_overloaded_operator`**：
- 查 `__OP_INFO` 表获取 `(trait_kind, method_name)`
- 调用 `method_lookup` 查找 trait impl
- 验证 impl 的 trait 与 intrinsic trait 一致
- 构建 `HIR.MethodCall`

取址 lowering 对引用解引用有专门规则：`&*r` 在 `r` 的类型是 `T&` 时折叠为 `r`，结果仍为
`T&`。该折叠不适用于裸指针 `T*`。

## assign_check — 赋值构建

`python/yianc/analysis/lowering/assign_check.py` — 赋值 Lowering 入口。

```python
def build_assign(type_ctx, coerce, span, target, value) -> HIR.Binary:
    1. check_assign_target(target, span)     # target must be an lvalue.
    2. value = coerce(value, target.type_id) # Type coercion.
    return HIR.Binary(Assign, target, value)
```

**`check_assign_target`**：检查 `target.is_place`（Var/FieldAccess/Unary(Deref) 等为 place）。

赋值对源值无额外约束：所有类型均为按位复制语义。

## 格式化模板 lowering

`yianc/src/analysis/lowering/format.an` 与 `python/yianc/analysis/lowering/format.py` 把模板展开成普通
HIR：`Formatter` 上的方法调用与 `match` 结果链，不新增 HIR/CFG 指令。每个位置先求值一次，左侧文本与
各字段按源码顺序写出；每次写入的 `Result` 进入同一条失败链，失败后不再求值后续位置。

带规格的字段在同一个块里展开：值先保存到隐藏局部，静态形状（对齐、补零、字面量宽度/精度、`f`）由
库的私有 `create_spec` 构造；动态宽度/精度各由一次 `set_*` 调用求值并立即校验，其 `Result` 用同一个
失败链包裹，因此宽度失败时精度表达式尚未求值。字段写调用接收 `T&` 与 `FormatSpec&`，编译器只检查类型
适用性，不生成按值类型分派的写函数。无规格字段同样构造默认规格。地址操作数按 storage normalization
处理；`return`/`break`/`never` 保持普通控制流，参数表达式参与 coverage 与 definite assignment。

## ExprEvaluator

`ExprEvaluator`（`python/yianc/analysis/lowering/expr_evaluator.py`）是只声明 `value` 与 `coerce` 的
Protocol，`CallDispatcher` 与 `OpBuilder` 通过它回调 `ExprChecker`。`ExprChecker` 另提供可复用的表达式求值辅助方法：

- `call_method(receiver, method_name, generics, args)` → HIR
- `call_into_iter(iterable)` → HIR
- `call_next(iterator)` → HIR
- `assign(span, target, value)` → HIR.Binary（委托 `build_assign`）
