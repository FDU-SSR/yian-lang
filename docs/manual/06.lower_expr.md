# 06 表达式 Lowering

表达式 lowering 将 AST 表达式节点翻译为 HIR（带类型标注的 AST）。

## ExprChecker

`compiler/analysis/lowering/expr_checker.py` — 核心 dispatch。

```python
class ExprChecker:
    def value(self, expr: AST.Expr) -> HIR.Expr:
        match expr:
            case AST.Block():    return self.check_block(expr)
            case AST.If():        return self.lower_if(expr)
            case AST.Defer():     return self.lower_defer(expr)
            case AST.Binary():    return self.__handle_binary(expr)
            case AST.Call():      return self.__handle_call(expr)
            case AST.BuiltinCall(): return self.__call_dispatcher.handle_builtin(expr)
            case AST.VarDecl():   return self.lower_var_decl(expr)
            ...
```

`value()` 是 AST → HIR 的入口，按 AST 节点类型分发到不同的 handler。

`defer` 的操作会在这里正常完成类型检查和 lowering，但 `lower_defer()` 返回的 `HIR.Defer` 自身固定为 `void`。登记点的符号可见性和跳转限制在此阶段确定；延迟操作不会被包装成普通表达式供参数或赋值使用。

## coerce() — 类型强制

```python
def coerce(self, expr: HIR.Expr, expected: int) -> HIR.Expr:
```

将 `expr` 强制为 `expected` 类型。处理规则：
- `IntLiteral` / `FloatLiteral` → 目标整数/浮点类型（修改 `type_id`）
- 取址表达式 `&e` 的 `T* → U*` → 先把被取址的 `e` coerce 到 `U`
- 指针/切片/数组到引用（`T* → T&`、`T[] → T&`）与指向数组的指针重锚定 → 生成地址值（`HIR.BitCast`）
- `ArrayType*`（指向数组的指针）→ `ElementType*`（指向首元素的指针，数组退化）
- `Tuple` / `Array` / `ArrayRepeat` → 递归 coerce 元素
- `DynValue` / `DynBuffer` → 把负载 coerce 到 pointee 类型
- 其他 → 类型必须完全匹配，否则 `AnalysisError`

`comptime if` 不在这里直接选择分支。它先由 `ExprChecker` 降低为 HIR，之后由中端 `ComptimeIfSpecializer` 求值并裁剪未选分支。

## OpBuilder

`compiler/analysis/lowering/op_builder.py` — 运算符 lowering。

```python
class OpBuilder:
    def build_binary(self, span, op, left, right) -> HIR.Expr
    def build_unary(self, span, op, operand) -> HIR.Expr
```

**运算符处理流程**：
1. 检查 operand 类型是否为 builtin（整数/浮点）
2. 若是 builtin → 直接构建 `HIR.Binary` / `HIR.Unary`
3. 若 operand 标记为 `Overloaded` → 通过 `__resolve_overloaded_operator` 查找对应 trait 的 impl

**`__resolve_overloaded_operator`**：
- 查 `__OP_INFO` 表获取 `(trait_kind, method_name)`
- 调用 `method_lookup` 查找 trait impl
- 验证 impl 的 trait 与 intrinsic trait 一致
- 构建 `HIR.MethodCall`

## assign_check — 赋值构建

`compiler/analysis/lowering/assign_check.py` — 赋值 Lowering 入口。

```python
def build_assign(type_ctx, coerce, span, target, value) -> HIR.Binary:
    1. check_assign_target(target, span)     # target 必须是 l-value
    2. value = coerce(value, target.type_id) # 类型强制
    return HIR.Binary(Assign, target, value)
```

**`check_assign_target`**：检查 `target.is_place`（Var/FieldAccess/Unary(Deref) 等为 place）。

赋值对源值无额外约束：所有类型均为按位复制语义。

## ExprEvaluator

`ExprEvaluator`（`compiler/analysis/lowering/expr_evaluator.py`）是只声明 `value` 与 `coerce` 的
Protocol，`CallDispatcher` 与 `OpBuilder` 通过它回调 `ExprChecker`。`ExprChecker` 另提供可复用的表达式求值辅助方法：

- `call_method(receiver, method_name, generics, args)` → HIR
- `call_into_iter(iterable)` → HIR
- `call_next(iterator)` → HIR
- `assign(span, target, value)` → HIR.Binary（委托 `build_assign`）
