# 18 错误处理

## 前端阶段错误

词法分析器和解析器分别产生 `LexError` 和 `ParseError`。文件级接口使用 `FrontendStageError` 统一承载词法、语法和脱糖错误，字段包括阶段、诊断码、消息和源码范围。类型定义位于 `yianc/src/frontend/prepare.an`。

`FrontendDriver.new(config, trace)` 加载包图与源码，`run()` 对会话中已有的源码执行前端处理。两个入口都可返回 `AnalysisError`。`FrontendSession` 将文件级错误转换为其中的 `Diagnostic`。前端错误在会话释放前把源码位置转为持有路径的记录，供调用者输出。

## 诊断模型与输出

`yianc/src/diagnostics/model.an` 定义错误码、严重性、阶段、消息和位置。`diagnostics/render.an` 从诊断生成文本，`driver/report.an` 将命令行诊断写到 stderr。中端检查使用相同的诊断模型，LSP 将编译器诊断转换为协议范围与消息。

命令行在前端初始化或处理失败时以状态码 1 退出。检查模式可收集可恢复的语义诊断，并根据检查结果设置退出状态。
