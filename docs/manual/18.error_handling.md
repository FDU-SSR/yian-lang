# 18 错误处理

## 错误类型层次

```text
Exception
  └── CompilerError          # compiler/error.py — 内部编译器错误
        ├── AnalysisError    # compiler/analysis/error.py — 语义分析错误
        ├── CodegenError     # compiler/codegen/error.py — 代码生成错误
        └── ParseError       # compiler/frontend/parse/error.py — 语法解析错误
```

## SrcSpan — 源位置追踪

```python
@dataclass
class SrcPosition:
    line: int       # 0-indexed
    col: int        # 0-indexed
    path: Path      # 源文件路径

@dataclass
class SrcSpan:
    start: SrcPosition
    end: SrcPosition
```

每个 token 和 AST 节点携带 `span`，用于错误定位。

## 错误打印 — __print_source_error

```python
def __print_source_error(span: SrcSpan, error: Exception):
    # 1. 打印错误消息
    print(f"error: {error}", file=sys.stderr)
    # 2. 打印源码位置
    print(f"--> {span.start.path}:{span.start.line+1}:{span.start.col+1}", file=sys.stderr)
    # 3. 打印对应源码行（带行号和 ^~~~ 下划线）
    source_line = read_source_line(span.start.path, span.start.line)
    print(f" {source_line}", file=sys.stderr)
    print(f" {' ' * span.start.col}{'^' * max(1, span.end.col - span.start.col)}", file=sys.stderr)
    sys.exit(-1)
```

## 各阶段错误传播

| 阶段 | 错误类型 | 处理方式 |
|------|---------|---------|
| Lex | `ParseError` | `__print_source_error` → exit(-1) |
| Parse | `ParseError` | 同上 |
| Desugar | — | 不产生新错误 |
| Resolve | `AnalysisError` | `__print_source_error` |
| TypeCheck | `AnalysisError` / `CompilerError` | `__print_source_error` / print+return 1 |
| CFG | `CodegenError` | `__print_source_error` |
| LLVM | `CodegenError` | `__print_source_error` |
| Emit | `RuntimeError` (llvmlite) | traceback → stderr |

## Traceback 打印

```python
def __print_traceback(error: Exception):
    for line in traceback.format_tb(error.__traceback__):
        print(line.rstrip(), file=sys.stderr)
```
