# 14 CLI 与构建

`compiler/main.py` — 编译入口和构建流程。

## CLI 参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `paths` (位置) | `.an` 源文件或目录 | 必需 |
| `-t` / `--target` | 输出类型: `exe`/`none`/`ll`/`bc`/`obj`/`asm` | `exe` |
| `-o` / `--output` | 输出路径 | 自动推导 |
| `-O` | 优化等级 (0-3) | `0` |
| `--profile` | 输出各阶段耗时 | — |
| `--log-spec` | 日志配置 | `""` (INFO) |
| `--log-file` | 日志输出路径 | `build/compile.log` |
| `--packages` | JSON 文件，包名→源文件根目录映射，启用 Package 模式 | — |

## 两种编译模式

### Standalone 模式（默认）

不传 `--packages`。所有源文件作为位置参数传入。import 路径按相对路径解析。

```bash
python3 -m compiler.main lib tests/array/assign.an
```

### Package 模式

通过 `--packages pkg.json` 启用。import 的第一段被解析为包名，编译器从 JSON 查找对应源文件根目录。通常由 `anx build` 自动调用。

```bash
python3 -m compiler.main --packages pkg.json file1.an file2.an ...
```

## 编译流程 (`main()`)

```python
def main(argv=None) -> int:
    args = parse_cli(argv)                   # 解析参数
    CompilerLog.init(spec, file)             # 初始化日志
    src_files = collect_an_files(paths)      # 收集 .an 文件

    token_lists  = __lex(src_files)          # Lex
    programs     = __parse(token_lists)      # Parse
    programs     = __desugar(programs)       # Desugar
    inject_prelude(src_files, programs)      # Prelude 注入

    unit_datas = [UnitData(p, ...)]          # 构建编译单元
    type_ctx = TypeCtx()                     # 创建类型上下文

    GlobalResolve(unit_datas, type_ctx).run()
    TypeCheck(unit_datas, type_ctx).run()
    def_points = type_checker.export()

    cfg_functions = __cfg(def_points, type_ctx)     # HIR → CFG
    llvm_module   = __llvm_codegen(cfg_functions)   # CFG → LLVM IR

    Emitter().emit_module(llvm_module, ...)         # 输出目标文件
```

## 输出目录

所有产物默认写入 `build/`：

```text
build/
├── tokens.txt     # Token 列表
├── ast.txt        # AST dump
├── hir.txt        # HIR dump
├── cfg.txt        # CFG dump
├── ir.ll          # LLVM IR
├── compile.log    # 日志
├── a.out          # exe
├── <name>.o       # obj
├── <name>.ll      # ll
└── <name>.s       # asm
```

## collect_an_files

递归收集 `.an` 文件：若路径为文件直接加入，若为目录递归遍历。排除 `bak/` 和 `build/`。

## __link_exe

```python
def __link_exe(obj_path, output_path, opt_level):
    cmd = [clang, obj_path, "-o", output_path, f"-O{opt_level}"]
    subprocess.run(cmd)
    obj_path.unlink()  # 清理中间 .o
```
