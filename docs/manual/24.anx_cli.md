# 24 CLI 与标准库定位

对应源文件：`anx/main.py`、`anx/scaffold.py`、`compiler/analysis/source_provenance.py`

## argparse 结构

```text
anx {new,build,run,check,test,graph} …
```

每个子命令自己声明参数，共用的两组助手：

- `__add_project_arg(p)`：可选位置参数 `project`，缺省 `.`。
- `__add_build_args(p)`：`-O {0..3}`、`--release`、`--raw-pointers`（`build`/`run`/`check`/`test` 都有）。

`run` 的程序参数**不经过 argparse**：在 `main()` 里先把 `--` 之后的部分切出来，再交给
argparse 解析剩下的：

```python
program_args: list[str] = []
if raw_argv and raw_argv[0] == "run" and "--" in raw_argv:
    split = raw_argv.index("--")
    program_args = raw_argv[split + 1:]
    raw_argv = raw_argv[:split]
```

否则 `anx run -- --help` 会被 argparse 当成 anx 自己的选项。切出来的参数挂在
`args.program_args` 上，`cmd_run` 执行时直接拼在可执行文件后面。

子命令返回 `int`（进程退出码），`main()` 用 `raise SystemExit(main())` 交出去。

## 选项白名单

anx 只透传白名单内的编译器选项，避免两边选项长期漂移：

```python
def __compiler_flags(args: argparse.Namespace) -> list[str]:
    """Compiler options whitelisted from the anx command line."""
    flags: list[str] = []
    level = args.opt
    if args.release and level is None:
        level = 3
    if level is not None:
        flags += ["-O", str(level)]
    if args.raw_pointers:
        flags.append("--raw-pointers")
    return flags
```

`-O` 缺省时**不传**——让编译器用自己的默认值，而不是 anx 替它决定。其余编译器选项（
`--dump`、`--log-spec`、`-t`…）由用户直接调编译器。

## 编译与退出码

`__do_build(project_dir, *, command, target, flags)` 是唯一的编译入口：

```python
project, root_dir = __load_project(project_dir)      # discover + load + 渲染诊断
root = project.packages[project.root_package]
if root.kind is PackageKind.LIB and command in ("build", "run"):
    print(f"error: 'anx {command}' is not supported for kind 'lib' packages: …")
    sys.exit(1)

extra_flags = ["-t", target]                          # target: "exe" | "none"
if target == "exe":
    extra_flags += ["-o", str(root_dir / "build" / "app")]

pkg_json = __write_package_map(project)               # 内容不变则不写
cmd = [*compiler_command(), "--packages", str(pkg_json), *extra_flags, *flags,
       *(str(f) for f in project.build_files())]
result = subprocess.run(cmd, cwd=str(root_dir), capture_output=True,
                        text=True, check=False, env=__compiler_env())

sys.stdout.write(result.stdout)                       # 成功路径也转发：warning 不能被吞
sys.stderr.write(result.stderr)
if result.returncode != 0:
    sys.exit(1)                                       # 归一化为 1
```

三个细节：

- **cwd 是项目根**，不是检出根：编译器的 `build/compile.log` 与 `--dump` 产物落在项目里。
- **两个流在成功路径上也转发**：编译器的 `warning:`（例如包名遮蔽本包目录的提示）不能被吞掉。
- **编译器退出码归一化为 1**。编译器的诊断路径会 `sys.exit(-1)`（即 255），直接透出会让
  脚本把「用户错误」当成别的信号。

`cmd_run` 在编译成功后才 `subprocess.run([exe, *args.program_args])`，**不捕获** stdio，
于是参数与标准输入直接透传；返回值就是程序的退出码（`Ctrl-C` → 130）。

`cmd_test` 不自己编译，交给 `anx/project_tests.py`（[25](25.anx_tests.md)）。

`cmd_graph` 不编译，只打印 `Project.describe()` 的载荷；它**总是**打印载荷，退出码 `1`
表示项目不可用或带诊断。环（`CycleError`）也渲染成一条 `AX006` 诊断放进载荷，而不是抛栈。

## 标准库定位

`yianc` 与 `anx` 用同一个函数解析标准库源码根：

```python
def resolve_stdlib_root(compiler_root: Path | None = None) -> Path:
    if compiler_root is not None:
        return stdlib_root_of(compiler_root)          # --compiler-root：检出根
    lib = os.environ.get(ENV_LIB)
    if lib:
        return Path(lib).resolve()                    # YIAN_LIB：源码根本身
    root = os.environ.get(ENV_ROOT)
    if root:
        return stdlib_root_of(Path(root))             # YIAN_ROOT：检出根
    return default_stdlib_root()                      # 本模块所在检出
```

- 包模式下编译器以 `packages["std"].sourceRoot` 为准；环境变量的作用是让 **anx** 知道该往
  `pkg.json` 里写什么。两边因此永远看到同一个根。
- 根目录**从不**从输入路径推断。一个叫 `lib` 的目录、或一份自称 `name = "std"` 的清单都不能
  换来标准库权限——`build_source_trust` 只认这个解析结果，而受限内建（指针锻造、raw ABI）
  正是靠它划边界。
- 解析结果不是目录时，两个命令都在启动阶段报错并打印**实际查找的路径**，
  而不是让 stdlib 因为「不被信任」在 `@runtime_fail` 处炸开。

`anx` 调用编译器的优先级（`compiler_command()`）：`YIANC` → `PATH` 上的 `yianc` →
`python3 -m compiler.main`。只有源码检出（`<检出>/compiler/main.py` 存在）时才会给子进程
补 `PYTHONPATH`，让回退入口在任意 cwd 下可导入。

## `anx new`

`scaffold(name, kind=…)` 生成：

```text
<name>/package.anx        name/kind/version + 空的 [dependencies]
<name>/src/main.an        仅 bin / hybrid
<name>/tests/smoke.an     一个通过的用例
<name>/tests/output/smoke.an.ans
<name>/.gitignore         build/
```

目标目录已存在时 `cmd_new` 捕获 `FileExistsError`，打印 `error: …` 并返回 1（不留 traceback）。
`--lib` 是 `--kind lib` 的简写。
