# 10 CFG IR

CFG（Control Flow Graph）IR 是 HIR 与 LLVM IR 之间的中间表示。采用 SSA（静态单赋值）形式和 basic block 结构化控制流。

## 源文件

`compiler/codegen/cfg/ir.py`

## 核心类型

### Function

```python
@dataclass
class Function:
    name: str
    type_id: int                        # 函数/方法的 type_id
    blocks: list[Block]                 # 所有 basic block
    entry: Block                        # 入口 block（也在 blocks 中）
    local_vars: dict[int, VarRef]       # symbol_id → VarRef
    params: list[int]                   # 参数 symbol_id 列表
    frame_lock: tuple[Value, Value] | None  # ⟨e_f, k_f⟩；None 表示未实体化帧锁
```

### Block

```python
@dataclass
class Block:
    label: str                          # 如 "entry", "loop.body.3"
    phis: list[Phi]                     # φ 节点
    stmts: list[Stmt]                   # 指令列表
    terminator: Terminator | None       # 终结指令
```

### Value

```python
Value = Literal | Reg

@dataclass
class Reg:
    name: str       # SSA 寄存器名，如 "%3"
    type_id: int    # 值类型
```

Literal 包含：`IntLiteral`、`FloatLiteral`、`BoolLiteral`、`CharLiteral`、`StringLiteral`。`ComptimeIf` 和 `CompileConfig` 在进入 CFG 前由中端专门化处理，不会形成 CFG 节点。

`HIR.Defer` 同样不会形成 CFG/LLVM 独立节点。CFG builder 为每个 HIR block 维护活动的延迟操作栈：正常离开 block、函数返回、循环 `break` 或 `continue` 时，在生成既有调用、赋值、`Delete` 和控制流指令前按 LIFO 展开相应范围；延迟操作本身若产生既有终结符，则停止后续展开。

### VarRef

```python
@dataclass
class VarRef:
    name: str        # 变量名
    symbol_id: int   # 符号 ID
    type_id: int     # 变量类型
```

## 指令集 (Stmt)

| 指令 | 说明 | 关键字段 |
|------|------|---------|
| `VarPtr` | 获取变量地址 | `result`, `var_ref` |
| `FieldPtr` | 结构体字段地址 | `result`, `base`, `field_index` |
| `ElementPtr` | 指针偏移 | `result`, `base`, `offset` |
| `PtrDiff` | 指针差值 | `result`, `lhs`, `rhs` |
| `Alloca` | 栈分配 | `result`, `value` |
| `Malloc` | 堆分配 | `result`, `type_id`, `size` |
| `Load` | 内存读取 | `result`, `ptr` |
| `Store` | 内存写入 | `ptr`, `value` |
| `Call` | 函数调用 | `result`, `callee_type`, `args` |
| `Invoke` | 函数指针调用 | `result`, `callee`, `args` |
| `Binary` | 二元运算 | `result`, `op`, `lhs`, `rhs` |
| `Unary` | 一元运算 | `result`, `op`, `operand` |
| `ExtractValue` | 聚合字段提取 | `result`, `base`, `field_index` |
| `Cast` | 类型转换 | `result`, `value`, `to_type` |
| `SizeOf` | 类型大小 | `result`, `type_id` |
| `Undef` | 未定义值 | `result`, `type_id` |
| `Dangling` | 悬垂指针（地址 = 对齐值） | `result`, `type_id` |
| `AggregateConstruct` | 聚合构造 | `result`, `type_id`, `fields` |
| `ArrayConstruct` | 数组构造 | `result`, `type_id`, `elements` |
| `VariantConstruct` | 枚举变体构造 | `result`, `enum_type`, `variant`, `payload_fields` |
| `FuncPtr` | 函数指针获取 | `result`, `func_type_id` |
| `PtrCmp` | 指针比较 | `result`, `op`, `lhs`, `rhs` |
| `Delete` | 内存释放 | `ptr` |
| `SysRead` | 系统调用 read | `result`, `fd`, `buf` |
| `SysWrite` | 系统调用 write | `fd`, `buf` |
| `Open` | 系统调用 open | `result`, `path`, `flags` |
| `Close` | 系统调用 close | `result`, `fd` |
| `Sqrt` | f64 平方根 | `result`, `value` |
| `MemCopy` | 字节拷贝 | `dest`, `src`, `count` |
| `ArgCount` | 读取进程参数数量 | `result` |
| `ArgBytes` | 读取进程参数字节视图 | `result`, `index` |
| `GenKey` | 帧键自增 | `result` |
| `AcquireFrameLock` | 从影子栈取帧锁槽 | `result`, `key` |
| `CheckSafeAccess` | 访问前检（live ∧ in_bounds） | `ptr`, `live` |
| `CheckViewAccess` | 切片/字符串视图检查 | `view`, `live` |
| `CheckInBounds` | 字段重锚定前提 | `ptr` |
| `CheckSliceNonEmpty` | `T[] → T&` 前的非空前提 | `ptr` |
| `CheckRefAccess` | 引用访问前检（仅 live） | `ptr` |
| `CheckElementArith` | 元素算术良构检查 | `base`, `offset` |
| `CheckElementAccess` | 合并的元素访问检查 | `base`, `offset`, `ptr`, `live` |
| `CheckRawBounds` | 裸数组越界检查 | `index`, `length` |
| `CheckPtrDiff` | 指针差前提 | `lhs`, `rhs` |
| `CheckPtrCmp` | 序比较前提 | `lhs`, `rhs` |
| `CheckDelete` | 释放前提 | `ptr` |
| `CheckRequest` | 检查请求标记 | `kind`, `operands`, `extra`, `live` |
| `LiveKnownBegin` / `LiveKnownEnd` | 刚分配窗口边界 | `root` |

## 终结符 (Terminator)

| 终结符 | 说明 | 关键字段 |
|--------|------|---------|
| `Ret` | 返回 | `value` |
| `Br` | 无条件跳转 | `target` |
| `CondBr` | 条件跳转 | `cond`, `then_block`, `else_block` |
| `Match` | 模式匹配跳转 | `value`, `arms`, `default`, `is_ref` |
| `Panic` | 运行时错误 | `message` |
| `RuntimeFail` | 固定运行时错误 | `code` |
| `ProcessExit` | 立即退出进程 | `code` |

### Phi 节点

```python
@dataclass
class Phi:
    result: Reg
    incoming: list[tuple[Block, Value]]   # (来源 block, 值)
```

```python
     | Load | Store | Call | Invoke | Binary | Unary

     | AggregateConstruct | ArrayConstruct | VariantConstruct
     | Delete | SysRead | SysWrite | Open | Close | Sqrt | MemCopy
     | ArgCount | ArgBytes
     | GenKey | AcquireFrameLock
     | CheckSafeAccess | CheckViewAccess | CheckInBounds | CheckSliceNonEmpty
     | CheckElementArith | CheckElementAccess | CheckRefAccess | CheckRawBounds
     | CheckPtrDiff | CheckPtrCmp | CheckDelete
     | CheckRequest | LiveKnownBegin | LiveKnownEnd
```
