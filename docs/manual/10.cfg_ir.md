# 10 CFG IR

CFG（Control Flow Graph）IR 是 HIR 与 LLVM IR 之间的中间表示。采用 SSA（静态单赋值）形式和 basic block 结构化控制流。

## 源文件

`compiler/codegen/cfg/ir.py`

## 核心类型

### Function

```python
@dataclass
class Function:
    name: str
    type_id: int                        # 函数/方法的 type_id
    blocks: list[Block]                 # 所有 basic block
    entry: Block                        # 入口 block（也在 blocks 中）
    local_vars: dict[int, VarRef]       # symbol_id → VarRef
    params: list[int]                   # 参数 symbol_id 列表
```

### Block

```python
@dataclass
class Block:
    label: str                          # 如 "entry", "loop.body.3"
    phis: list[Phi]                     # φ 节点
    stmts: list[Stmt]                   # 指令列表
    terminator: Terminator | None       # 终结指令
```

### Value

```python
Value = Literal | Reg

@dataclass
class Reg:
    name: str       # SSA 寄存器名，如 "%3"
    type_id: int    # 值类型
```

Literal 包含：`IntLiteral`、`FloatLiteral`、`BoolLiteral`、`CharLiteral`、`StringLiteral`、`NullptrLiteral`。

### VarRef

```python
@dataclass
class VarRef:
    name: str        # 变量名
    symbol_id: int   # 符号 ID
    type_id: int     # 变量类型
```

## 指令集 (Stmt)

| 指令 | 说明 | 关键字段 |
|------|------|---------|
| `VarPtr` | 获取变量地址 | `result`, `var_ref` |
| `FieldPtr` | 结构体字段地址 | `result`, `base`, `field_index` |
| `ElementPtr` | 指针偏移 | `result`, `base`, `offset` |
| `PtrDiff` | 指针差值 | `result`, `lhs`, `rhs` |
| `Alloca` | 栈分配 | `result`, `value` |
| `Malloc` | 堆分配 | `result`, `type_id`, `size` |
| `Load` | 内存读取 | `result`, `ptr` |
| `Store` | 内存写入 | `ptr`, `value` |
| `Call` | 函数调用 | `result`, `callee_type`, `args` |
| `Invoke` | 函数指针调用 | `result`, `callee`, `args` |
| `Binary` | 二元运算 | `result`, `op`, `lhs`, `rhs` |
| `Unary` | 一元运算 | `result`, `op`, `operand` |
| `ExtractValue` | 聚合字段提取 | `result`, `base`, `field_index` |
| `Cast` | 类型转换 | `result`, `value`, `to_type` |
| `SizeOf` | 类型大小 | `result`, `type_id` |
| `AggregateConstruct` | 聚合构造 | `result`, `type_id`, `fields` |
| `ArrayConstruct` | 数组构造 | `result`, `type_id`, `elements` |
| `VariantConstruct` | 枚举变体构造 | `result`, `enum_type`, `variant`, `payload_fields` |
| `FuncPtr` | 函数指针获取 | `result`, `func_type_id` |
| `Delete` | 内存释放 | `ptr` |
| `SysRead` | 系统调用 read | `result`, `fd`, `buf` |
| `SysWrite` | 系统调用 write | `fd`, `buf` |

## 终结符 (Terminator)

| 终结符 | 说明 | 关键字段 |
|--------|------|---------|
| `Ret` | 返回 | `value` |
| `Br` | 无条件跳转 | `target` |
| `CondBr` | 条件跳转 | `cond`, `then_block`, `else_block` |
| `Match` | 模式匹配跳转 | `value`, `arms`, `default` |
| `Panic` | 运行时错误 | `message` |

### Phi 节点

```python
@dataclass
class Phi:
    result: Reg
    incoming: list[tuple[Block, Value]]   # (来源 block, 值)
```

## Stmt type alias

```python
Stmt = VarPtr | FieldPtr | ElementPtr | PtrDiff | Alloca | Malloc
     | Load | Store | Call | Invoke | Binary | Unary
     | ExtractValue | Cast | SizeOf | AggregateConstruct
     | ArrayConstruct | VariantConstruct | FuncPtr | Delete
     | SysRead | SysWrite
```
