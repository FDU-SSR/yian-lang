# 06 · 安装与环境

## 安装

两个命令以 console scripts 形式交付：`yianc`（编译器）与 `anx`（包管理器）。

```bash
scripts/install.sh                # 默认：editable 安装，两个命令直接指向这个检出
scripts/install.sh --regular      # 非 editable：把 compiler/ 与 anx/ 拷进 site-packages
scripts/install.sh --with-deps    # 让 pip 解析依赖（否则要求 llvmlite 已可导入）
scripts/install.sh --user         # 装进用户 site-packages
scripts/install.sh --python PATH  # 指定解释器
scripts/uninstall.sh              # 卸载 yian 发行包
```

脚本会预检 Python ≥ 3.11 与 llvmlite，并在已安装 setuptools ≥ 68 时加上
`--no-build-isolation`（离线环境也能装）；装完会校验两个入口是否在 `PATH` 上。

- **editable**（默认）：改 `compiler/`、`anx/`（含新增模块）后立即生效，不必重装。
  只有改 `[project.scripts]`、依赖列表或新增顶层包时才需要重装。
- **`--regular`**：拷贝安装。注意 **`lib/` 不在发行包里**，所以运行时必须告诉工具标准库在哪
  （见下），否则两个命令都会在启动阶段报错并打印它实际查找的路径。

不安装也能用：在检出根目录下用 `python3 -m anx.main …` 与 `python3 -m compiler.main …`。
此时 `anx` 调用编译器的优先级是 `YIANC` 环境变量 → `PATH` 上的 `yianc` →
`python3 -m compiler.main`。

## 标准库在哪

`yianc` 与 `anx` 用**同一个**解析顺序定位标准库源码根（即 `lib/src`）：

| 优先级 | 方式 | 值 |
| --- | --- | --- |
| 1 | `yianc --compiler-root PATH` | 检出根，标准库取 `<PATH>/lib/src` |
| 2 | `YIAN_LIB` 环境变量 | 标准库**源码根**本身（`…/lib/src`） |
| 3 | `YIAN_ROOT` 环境变量 | 检出根，标准库取 `<YIAN_ROOT>/lib/src` |
| 4 | 默认 | 本模块所在检出（editable 安装走这条） |

```bash
# 非 editable 安装后，指向一个检出即可
export YIAN_LIB=/path/to/yian/lib/src
# 或者
export YIAN_ROOT=/path/to/yian
# 或者只给某一次编译
yianc --compiler-root /path/to/yian /path/to/yian/lib/src main.an -t none
```

包模式（`anx build` / `check` / `test`）下，标准库的源码根写进 `build/pkg.json` 的
`std.sourceRoot`，编译器以它为准；环境变量只是让 anx 知道该写什么。

根目录**从不**从输入路径推断：一个恰好叫 `lib` 的目录，或一份自称 `name = "std"` 的清单，
都不会让源码获得标准库权限（标准库是唯一被信任、可以使用受限内建的分包）。

## 环境变量一览

| 变量 | 作用 |
| --- | --- |
| `YIANC` | 指定 `anx` 调用哪个编译器可执行文件 |
| `YIAN_LIB` | 标准库源码根（`lib/src`） |
| `YIAN_ROOT` | YIAN 检出根 |
| `PYTHONPATH` | 不安装而直接跑 `python3 -m anx.main` 时需要包含检出根（在检出根目录下执行则自动满足） |

编译器的日志与调试开关（`--log-spec`、`--dump` 等）见
[编译脚本文档](../compile_script.md)。
