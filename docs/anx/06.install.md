# 06 · 安装与环境

## 安装原生工具链

冷启动脚本先用 Python 恢复编译器和固定五包配方构建 raw native `yianc`，再用 staged `yianc` 和固定七包配方构建 raw native `anx`。两个阶段成功并通过帮助检查后，脚本以可回滚的发布步骤安装命令及标准库、运行时资源，并记录构建来源、模式、源码与产物摘要：

```bash
conda run --no-capture-output -n yian-env bash scripts/bootstrap_toolchain.sh \
  --prefix "$HOME/.local" --python python
"$HOME/.local/bin/yianc" --help
"$HOME/.local/bin/anx" --help
```

构建需要 Python 3.12+、llvmlite 0.49+、LLVM 22、clang 22 和 C 工具链。安装后的 `yianc` 与 `anx` 是原生二进制，运行时不需要 Python 或源码检出。

如果已有可用的原生 `yianc` 和 `anx`，可用 warm 入口重建两个编译工具、语言服务器及共享资源。它不调用 Python，也不会退回 cold 构建：

```bash
scripts/refresh_toolchain.sh --anx "$HOME/.local/bin/anx" --yianc "$HOME/.local/bin/yianc" --prefix "$HOME/.local"
```

脚本先冻结并检查 seed 命令，再依次构建 raw/O2 的 `yianc`、`anx` 和 `yian-lsp`。完整 staging 上的初始化握手通过后才发布，并为组件、资源和产物记录摘要。若 seed 不兼容，命令会失败；需要时显式运行 cold 入口获取新 seed。

## 安装语言服务器

冷启动只安装 `yianc`、`anx` 和共享资源，不构建语言服务器。warm 刷新会一起重建两个编译工具、`anx`、共享资源和 raw/O2 语言服务器：

```bash
scripts/refresh_toolchain.sh --anx "$HOME/.local/bin/anx" \
  --yianc "$HOME/.local/bin/yianc" --prefix "$HOME/.local"
"$HOME/.local/bin/yian-lsp" --version
```

warm 刷新要求传入可用的原生 `anx` 和 `yianc` seed；它先 staging 并验证完整工具链，再完成 stdio 初始化握手后事务发布。服务端程序以 raw 模式和 `-O2` 构建；被分析源码默认使用 fat 模式。统一卸载器使用 `share/yian-lsp/` 中的摘要记录识别服务器，并在 `--lsp-only` 模式下保留 `share/yian/` 下的共享资源。

只卸载语言服务器并保留编译工具和共享资源，或移除整套受管理安装：

```bash
scripts/uninstall.sh --lsp-only --prefix "$HOME/.local"
scripts/uninstall.sh --prefix "$HOME/.local"
```

默认卸载器会移除摘要与安装记录匹配的 `yianc`、`anx`、`yian-lsp` 和共享资源；若有修改过或未受管理的服务器二进制，相关共享资源会保留。`--lsp-only` 只卸载摘要匹配的服务器并保留编译工具和共享资源。

服务器卸载会清理摘要匹配的 `.build-info` 和安装记录，空的 `share/yian-lsp/` 目录一并移除。修改过、无匹配摘要或符号链接形式的构建信息会与安装记录一起保留，卸载返回非零退出码；其他用户文件不会被删除。

## 标准库定位

共享资源包含标准库源码根 `lib/src` 与清单 `lib/package.anx`；后者参与语言服务器的输入身份。独立编译可通过 `--compiler-root PATH`、`YIAN_LIB` 或 `YIAN_ROOT` 配置；原生安装会从可执行文件所在前缀的 `share/yian` 自动定位共享资源。`anx` 包模式将标准库根写入生成的包映射，编译器按映射读取。

包归属和受限操作信任依据规范化的包映射或显式配置根目录，不从输入目录名推断。`YIAN_LIB` 与 `YIAN_ROOT` 也可用于构建工具链或指定 checkout 资源。

## 环境变量

| 变量 | 作用 |
| --- | --- |
| `YIANC` | 指定原生 `anx` 调用的编译器可执行文件 |
| `YIAN_LIB` | 标准库源码根（`lib/src`） |
| `YIAN_ROOT` | YIAN checkout 根目录 |
| `YIAN_INSTALL_PREFIX` | 测试与安装工具使用的默认前缀 |

编译器选项见[编译脚本文档](../compile_script.md)。
