# 02 · 依赖

## 声明

```toml
[package]
name = "app"

[dependencies]
mathlib = { path = "../lib" }        # 键必须等于 ../lib 清单里的 [package].name

[dev-dependencies]
testkit = { path = "../testkit" }    # 只有 `anx test` 看得见
```

- `path` 必需，相对**清单所在目录**解析为绝对路径。
- 依赖的 `kind` 不能是 `bin`（`AX015`）——bin 没有库接口。
- **不支持依赖重命名**：键就是导入名，必须等于被依赖包的规范名。这样依赖包自己的
  `from <自己包名>.… import …` 才能照常解析。
- 依赖模型是「本地路径 + 精确版本字符串」：`[dependencies]` 只有 `path`（见 [01](01.project.md)）。
  远程依赖（git/URL/registry）、版本约束与锁文件都**不在支持范围内**。

## 可见性

一个包只能导入：

1. **自己**（`from 本包名.模块 import …`）
2. 自己**直接声明**的依赖
3. **`std`**（无需声明）

传递依赖**不可见**，即使它在依赖图里：

```text
app  ──依赖──▶  libb  ──依赖──▶  libc
```

- `libb` 里 `from libc.secret import x` ✓（`libb` 声明了 `libc`）
- `app` 里 `from libc.secret import x` ✗ `E309`（`app` 没声明 `libc`）

**不提供重导出**：外观包无法把传递依赖的符号再暴露给使用者，使用方必须自己声明。

## `[dependencies]` 与 `[dev-dependencies]`

| 谁能用 | `[dependencies]` | `[dev-dependencies]` |
| --- | --- | --- |
| 本包源码 | ✅ | ❌（`E309`） |
| 本包的测试（`anx test`） | ✅ | ✅ |
| 传递依赖 | 不可见 | 不可见 |
| `anx build` / `run` / `check` 编译的文件 | ✅ | ❌（不传给编译器） |

也就是说：dev 依赖会被**解析、校验、纳入依赖图**，但普通构建既不看它、也不编译它——
即使它的源码里有语法错误，`anx build` 也不受影响。这与 Cargo 的 `[dev-dependencies]` 一致
（`cargo build` 不构建，`cargo test` 才链接）。

反过来，**项目代码不能用 dev 依赖**：

```yian
// src/main.an
from testkit.helpers import triple;   // ✗ E309：testkit 不是 app 的依赖
```

## 依赖诊断

| 情况 | 码 |
| --- | --- |
| 依赖 `path` 不存在 | `AX003` |
| 依赖目录里没有 `package.anx` | `AX004` |
| 依赖键 ≠ 被依赖包的 `name` | `AX005` |
| 同一个包名被解析到两个不同路径 | `AX007` |
| 依赖了 `kind = "bin"` 的包 | `AX015` |
| 两个包的源码根互相嵌套 | `AX013` |

环依赖（`AX006`）比较特殊：它是**致命错误**，`anx` 会直接报完整路径并退出，不会继续加载：

```text
error[AX006]: Circular dependency: libb → appa → libb
```

清单/依赖类诊断会**一次性全部报出**，并按「文件路径 → 位置 → 码」稳定排序；只要有一条，
`anx build` / `run` / `check` / `test` / `fmt` 就退出 1，不进入编译。

## 看依赖图

```bash
anx graph                     # 文本形式
anx graph --json              # 结构化载荷：包、依赖、dev 依赖、文件索引、诊断
```

`anx graph --json` 的载荷总是会被打印（即使项目有诊断），退出码 `1` 表示项目不可用或带诊断，
`0` 表示干净——脚本可以既读载荷、又按退出码分支。

```bash
anx graph --json | python3 -c "
import json, sys
d = json.load(sys.stdin)
for name, spec in d['packages'].items():
    print(name, spec['kind'], spec['dependencies'], spec['devDependencies'])
"
```
